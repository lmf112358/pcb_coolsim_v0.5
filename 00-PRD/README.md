## 需求条目索引

PRD 中定义了以下需求条目（F1-001 ~ F10-XXX）：

### 模块一：账户与项目管理（F1-001 ~ F1-XXX）
- F1-001：用户登录与认证
- F1-002：角色权限管理
- F1-003：项目 CRUD 操作
- F1-004：四级层级结构（项目→建筑→楼层→功能区域）

### 模块二：用户数据采集（F2-001 ~ F2-XXX）
- F2-001：建筑数据录入
- F2-002：功能区域数据录入
- F2-003：Excel 数据导入
- F2-004：数据校验与默认值

### 模块三：2D 可视化标注（F3-001 ~ F3-XXX）
- F3-001：2D 编辑器
- F3-002：PDF 图纸导入
- F3-003：功能区域绘制
- F3-004：热力图可视化

### 模块四：静态冷量计算（F4-001 ~ F4-XXX）
- F4-001：静态冷量计算（6 步流水线）
- F4-002：实时计算预览
- F4-003：批量计算

### 模块五：负荷分析（F5-001 ~ F5-XXX）
- F5-001：负荷分布分析
- F5-002：冷站配置与校验
- F5-003：多方案对比
- F5-004：P&ID 系统图生成

### 模块六：动态仿真负荷计算（F6-001 ~ F6-XXX）
- F6-001：气象数据驱动仿真
- F6-002：比例系数法仿真

### 模块七：8760 逐时结果可视化与基础验证（F7-001 ~ F7-XXX）

- F7-003：负荷持续时间曲线

### 模块八：报告与数据导出（F8-001 ~ F8-XXX）

- F8-002：冷站配置报告（PDF）

- F8-004：负荷计算书（Excel）

### 模块九：系统设置与全局交互（F9-001 ~ F9-XXX）
- F9-001：系统参数配置
- F9-002：用户偏好设置
- F9-003：全局交互规范

### 模块十：负荷预测（F10-001 ~ F10-XXX）
- F10-001：未来 7×24 小时预测
- F10-002：天气数据自动获取
- F10-003：生产负荷率配置
- F10-004：功能区域级粒度预测

## 验收标准索引

PRD 定义了以下验收标准（G1 ~ G12）：

| 编号 | 目标 | 衡量指标 |
|------|------|----------|
| G1 | 四级层级结构完整建模 | 项目→建筑→楼层→功能区域 CRUD 完整，单项目 1000+ 功能区域节点流畅操作 |
| G2 | 静态冷量计算精度 | 与手工 Excel 验算偏差 < 0.1% |
| G3 | 动态仿真计算精度 | 与相同输入的独立脚本验算偏差 < 1% |
| G4 | 动态仿真计算时效 | 8760h × 3 年 × 1000+ 功能区域，计算耗时 < 30 秒 |
| G5 | 输入完整性 | 功能区域缺少新风计算必需参数时给出明确默认值或拦截 |
| G6 | 2D 平面图可用 | 编辑器全流程可用，查看器渲染 100 功能区域 < 3 秒 |
| G7 | Excel 导入可用 | 10000+ 行解析 < 30 秒，错误定位到行 |
| G8 | 8760 可视化 | 逐时负荷曲线展示（约 26280 点/功能区域） |
| G9 | 冷站配置可用 | 手动配置 + 基础校验 + 多方案表格对比 |
| G10 | 报告导出可用 | 静态计算报告 PDF + 冷站配置报告 PDF + 设备清单 Excel + 负荷计算书 Excel + 仿真数据 CSV |
| G11 | 实时计算预览 | 单功能区域参数修改后 < 500ms 自动刷新该节点计算预览 |
| G12 | 负荷预测可用 | 未来 7×24 小时预测，天气 API 每小时自动更新 |
