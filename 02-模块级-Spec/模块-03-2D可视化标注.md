## 1. 模块概述

### 1.1 功能职责

本模块包含编辑场景（Canvas 画布编辑器）和查看场景（楼层详情页 2D 平面图渲染）。

**v0.5 核心功能：**
- PDF 底图导入与 Canvas 编辑器
- 矩形绘制工具（关联功能区域）
- 外墙轮廓绘制工具
- 比例尺标定
- 指北针设置
- 2D 平面图可视化（热力图 + 工艺编码双模式）
- 色块点击联动详情面板

**v0.5 简化说明：**
- 仅支持 PDF 格式（不支持 DWG/DXF）
- 使用矩形绘制 + 外墙多边形（不支持多边形框选）

## 4. 业务逻辑

### 4.1 Canvas 编辑器工作流

```
1. 用户进入 2D 编辑页
2. 检查楼层是否已有底图：
   a. 无底图：提示上传 PDF
   b. 有底图：加载底图
3. 加载平面图数据（outline, blocks, scale, compass）
4. 用户选择工具：
   a. 矩形绘制工具：在底图上拖拽绘制矩形
   b. 外墙轮廓绘制工具：沿底图描点多边形
   c. 比例尺标定工具：画线段并输入实际距离
   d. 指北针设置工具：拖拽旋转指北针
5. 用户绘制完成后：
   a. 矩形：弹出功能区域选择下拉框
   b. 外墙：点击起始点闭合
6. 用户保存：提交平面图数据到后端
7. 保存成功后返回项目工作台 Tab1
```

### 4.2 矩形绘制逻辑

```typescript
// 矩形绘制状态机
enum DrawState {
  IDLE,
  DRAWING,
  RESIZING,
  MOVING,
  SELECTING_ROOM
}

// 矩形绘制流程
const drawRectangle = (startPoint, endPoint) => {
  const rect = {
    id: generateId(),
    x: Math.min(startPoint.x, endPoint.x),
    y: Math.min(startPoint.y, endPoint.y),
    width: Math.abs(endPoint.x - startPoint.x),
    height: Math.abs(endPoint.y - startPoint.y),
    room_id: null
  };
  return rect;
};

// 关联功能区域
const associateRoom = (blockId, roomId) => {
  const block = blocks.find(b => b.id === blockId);
  block.room_id = roomId;
  block.label = rooms.find(r => r.id === roomId).room_name;
};
```

### 4.3 比例尺标定逻辑

```typescript
// 比例尺标定流程
const calibrateScale = (linePixels, lineMeters) => {
  const pixelsPerMeter = linePixels / lineMeters;
  return {
    reference_line_pixels: linePixels,
    reference_line_meters: lineMeters,
    pixels_per_meter: pixelsPerMeter
  };
};

// 像素坐标转实际坐标（米）
const pixelToMeter = (pixelCoord, scale) => {
  return {
    x: pixelCoord.x / scale.pixels_per_meter,
    y: pixelCoord.y / scale.pixels_per_meter
  };
};
```

### 4.4 热力图渲染逻辑

```typescript
// 热力图颜色映射
const getHeatmapColor = (loadValue, minLoad, maxLoad) => {
  const ratio = (loadValue - minLoad) / (maxLoad - minLoad);
  // 蓝 → 红连续渐变
  const r = Math.round(255 * ratio);
  const g = Math.round(100 * (1 - Math.abs(ratio - 0.5) * 2));
  const b = Math.round(255 * (1 - ratio));
  return `rgb(${r}, ${g}, ${b})`;
};

// 工艺要求颜色编码
const getProcessColor = (room) => {
  // 按优先级判定：温控精度 > 洁净度 > 压差
  if (room.temp_control_precision === '±1') return '#FF4D4F'; // 红
  if (room.temp_control_precision === '±2') return '#FA8C16'; // 橙
  if (room.cleanliness_level === 'ISO7') return '#FADB14';    // 黄
  if (room.cleanliness_level === 'ISO8') return '#52C41A';    // 绿
  if (room.cleanliness_level === 'ISO7.5') return '#1890FF';  // 蓝
  if (room.pressure_diff > 0) return '#722ED1';               // 紫（正压）
  return '#BFBFBF'; // 灰（负压/普通）
};
```

### 4.5 2D 平面图查看流程

```
1. 用户进入项目工作台 Tab5（2D展示）
2. 加载当前楼层的平面图数据
3. 加载功能区域的计算结果
4. 根据显示模式渲染色块：
   a. 冷量热力图模式：按 total_load 映射蓝→红渐变
   b. 工艺要求编码模式：按温控精度/洁净度/压差映射7色
5. 渲染外墙轮廓、比例尺、指北针、图例
6. 用户点击色块：联动右侧详情面板
7. 用户切换显示模式：重新渲染色块
```

## 6. 性能优化

### 6.1 Canvas 渲染优化

**目标：** 单楼层 100 个功能区域渲染 < 3 秒

**优化方案：**
- 使用 Canvas 2D 渲染（不使用 SVG）
- 离屏 Canvas 缓存静态图层（外墙、比例尺、指北针）
- 只重绘变化的图层（色块、标签）
- 使用 requestAnimationFrame 优化动画

### 6.2 热力图渲染优化

**优化方案：**
- 预计算颜色映射表
- 使用 WebGL 加速渲染（可选）
- 批量绘制色块
- 缓存渲染结果
