## 1. 功能概述

### 1.1 目的
实现冷负荷多维分析，从功能区域 / 楼层 / 建筑 / 冷量种类 / 负荷构成五个维度展示冷负荷分布，帮助用户识别高负荷区域与优化空间，并基于规则引擎自动生成分析结论与建议。本模块为**纯负荷分析**，不含冷站配置 / Cooling Station / P&ID / 水蓄冷相关内容（v0.5 已移除，通用 HVAC 词仅作物理名词）。

### 1.2 关键特性
- 五维度负荷分布分析：功能区域 / 楼层 / 建筑 / 冷量种类 / 负荷构成。
- 按冷量种类分布：堆叠柱状图 + 饼图（低温水 7/12℃、中温水 12/17℃ 各自峰值与占比）。
- 按功能区域分布：横向柱状图按峰值冷负荷排序。
- 按楼层/建筑分布：可切换展示维度。
- 柱图交互：悬停 tooltip 显示末端/新风构成占比；点击下钻至明细。
- 负荷构成分析：土建/照明/人员/设备/新风各占比饼图（合计 100%）。
- 自动分析建议：基于 §9.3 规则引擎生成结论与建议。

### 1.3 v0.5 范围说明（来自 PRD §9.1）
- 负荷分析按功能区域/楼层/建筑/冷量种类/负荷构成五个维度展开，**不支持工序维度**。
- 温度范围仅支持低温 7/12℃ 与中温 12/17℃ 两种。
- 末端负荷按功能区域级冷冻水档分配（ADR-0001），不再全归中温。

## 2. 功能详述（按 PRD 小节展开）

### 2.1 §9.2 冷负荷分布分析（F5-001 ~ F5-006）

**(1) 按冷量种类分布（F5-001）**
- 数据源：`RoomLoadByWaterTemp` 按 `water_temp_config_id` 分组聚合，低温（7/12）、中温（12/17）两条记录。
- 展示：堆叠柱状图（按楼层/建筑堆叠各水温）+ 饼图（各水温峰值与占比）。
- 口径：峰值取该水温下 `total_load` 最大值；占比 = 该水温合计 / 全部水温合计。

**(2) 按功能区域分布（F5-002）**
- 数据源：`RoomLoadByWaterTemp`（或 `RoomCalcResult` 的 `terminal_load` + 对应 `fresh_air_load`）按 `room_id` 聚合。
- 展示：横向柱状图，按峰值冷负荷降序排序；柱高 = 该功能区域峰值 `total_load`。

**(3) 按楼层/建筑分布（F5-003）**
- 数据源：`LoadSummary`（scope=floor / building），按 `floor_id` / `building_id` 聚合 `total_load`。
- 展示：维度切换器在「楼层 / 建筑」间切换；柱高 = 对应层级合计 `total_load`。

**(4) 柱图交互（F5-004、F5-005）**
- 悬停 tooltip（F5-004）：显示该柱末端负荷 `terminal_load` 与新风机负荷 `fresh_air_load` 各自占比。
- 下钻（F5-005）：点击柱条跳转至该功能区域/楼层明细视图（联动 §7.3 详情面板或独立明细表）。

**(5) 负荷构成分析（F5-006）**
- 数据源：`RoomCalcResult` 的 `civil_load`(土建)、`lighting_load`(照明)、`personnel_load`(人员)、`electric_equipment_load`(设备)、以及 `RoomLoadByWaterTemp.fresh_air_load`(新风)。
- 展示：饼图，五类占比合计 100%；可聚合到功能区域/楼层/建筑/项目层级。

### 2.2 §9.3 自动分析建议规则（F5-007）

基于启发式规则（v0.5 占位实现，v0.6 完善）自动生成结论/建议：

| 触发条件 | 建议文案 |
|----------|----------|
| 某功能区域冷指标 `cold_load_index` > 500 W/m²（来自 RoomCalcResult.cold_load_index） | "功能区域【X】冷指标偏高，建议核查设备发热/新风量" |

- 规则输入：功能区域级 `cold_load_index`（W/m²）。
- 输出位置：分析看板结论卡片；可扩展为多条规则，规则表建议配置化（待确认是否入库）。

## 3. 数据模型（引用 01-系统级-Spec/数据库设计.md §4）

| 表 | 章节 | 本模块使用字段 | 用途 |
|----|------|----------------|------|
| RoomCalcResult | §4.9 | room_id, season_id, civil_load, lighting_load, personnel_load, electric_equipment_load, terminal_load, cold_load_index | 负荷构成（土建/照明/人员/设备/末端）、冷指标（F5-006、F5-007） |
| RoomLoadByWaterTemp | §4.12 | room_id, season_id, water_temp_config_id, fresh_air_load, terminal_load, total_load | 按水温分类的末端/新风/总负荷（F5-001~F5-005） |
| LoadSummary | §4.14 | project_id, building_id, floor_id, scope, category, fresh_air_load, terminal_load, extra_load, total_load | 楼层/建筑/项目多级聚合（F5-003） |
| water_temperature_config | §4.6 | id, temp_type_name, supply_temp, return_temp | 冷量种类维度（低温/中温）（F5-001） |
| room | §4.4 | id, room_name, floor_id, area | 功能区域名称与面积（F5-002、F5-006 分母） |
| floor / building | §4.3 / §4.2 | id, floor_name / building_name | 楼层/建筑维度标签（F5-003） |

> 说明：所有聚合基于静态计算产出（`RoomLoadByWaterTemp`、`LoadSummary` 由模块四/模块六写入）。`season_id` 当前 v0.5 默认夏季；多季节对比不在本模块范围。

## 6. 待确认

1. **计划层描述与 PRD §9 不一致**：任务计划提及模块五包含「基础校验（N+1/容量/部分负荷率）」与「多方案表格对比」。但 PRD v0.5.1 §9 仅定义负荷分布分析（F5-001~F5-007）与自动建议（F5-007），**不含 N+1 / 容量 / 部分负荷率 / 多方案对比**。其中「装机容量校核」归属于模块七 §11.5（F7-022~F7-024、F7-026）。N+1 与部分负荷率未在 PRD 任何小节定义。按全局约束（与 PRD 一致、不发明未定义实体），本模块严格按 §9 编写；上述计划项是否纳入 v0.5 或推迟，需产品确认。
2. **冷站配置一律不写**：模块五为纯负荷分析，不得补回 Cooling Station / P&ID / 水蓄冷（已移除）。
3. **F5-008~F5-010 缺失**：用户故事与可追溯矩阵引用但 PRD §9 未定义，待补充 PRD 或修订矩阵。
4. **自动建议规则配置化**：§9.3 仅 1 条占位规则，规则是否持久化到配置表、是否支持多季节/多阈值，待确认（v0.6 完善）。
5. **工序维度**：PRD 明确 v0.5 不支持工序维度，相关三维交叉分析（模块七 §11.1 亦推迟）不在范围。
