## 1. 模块概述

### 1.1 用途
使用多年逐时气象数据（通常为 8760 小时 × 3 年 = 26,280 个数据点）执行动态冷负荷仿真。这为设备选型与能耗分析提供真实的年度负荷曲线。

### 1.2 核心功能
- **气象驱动仿真**：基于历史逐时气象数据
- **系数法**：用于简化计算
- 多年仿真（1-3 年）
- 单房间与汇总结果
- 基于 WebSocket 的进度跟踪
- 结果缓存与存储

### 1.3 性能要求

| 指标 | 目标 | 策略 |
|--------|--------|----------|
| 8760h × 3yr × 1000 房间 | < 30 秒 | 并行处理 + 缓存 |
| 内存占用 | < 4GB | 流式写入数据库 |
| 并发仿真 | 5 个同时进行 | Celery worker 横向扩展 |

## 2. 仿真方法

### 2.1 方法 1：气象驱动（推荐）

**方法：** 使用真实历史气象数据逐小时计算负荷。

**数据来源：**
- 历史气象 API（3 年数据）
- 手动上传（CSV/EPW 格式）

**计算流程：**
```
对于每个小时（8760 小时 × 3 年）：
    1. 获取气象数据（温度、湿度、压力）
    2. 对于每个房间：
        a. 计算焓值（使用逐时室外工况）
        b. 计算末端负荷（固定，基于设计工况）
        c. 计算新风负荷（随气象变化）
        d. 计算总负荷
    3. 汇总结果
```

**优势：**
- 最真实地反映实际工况
- 捕捉季节与日间变化
- 识别峰值负荷时刻

### 2.2 方法 2：系数法（简化）

**方法：** 对静态设计负荷施加系数乘子。

**公式：**
```
Hourly Load = Static Design Load × Hour Coefficient × Season Coefficient × Production Rate
```

**系数矩阵：**
```sql
CREATE TABLE coefficient_matrix (
    season VARCHAR(20),      -- summer, winter, transition
    hour INTEGER,            -- 0-23
    production_rate DECIMAL, -- 0.0 to 1.0
    coefficient DECIMAL      -- multiplier
);
```

**示例：**
```
夏季，第 14 小时，生产率 80%：
系数 = 0.85

若静态负荷 = 1000 kW：
逐时负荷 = 1000 × 0.85 × 1.0 × 0.8 = 680 kW
```

**优势：**
- 计算更快（无需气象数据）
- 实现更简单
- 适用于初步分析

## 4. 详细实现

### 4.1 气象驱动仿真

**核心算法：**

```python
def simulate_weather_driven(
    project_id: int,
    years: List[int],
    room_ids: Optional[List[int]] = None
) -> SimulationResult:
    """
    Execute weather-driven dynamic simulation.
    
    Args:
        project_id: Project to simulate
        years: List of years to simulate [2023, 2024, 2025]
        room_ids: Optional list of rooms (default: all)
    
    Returns:
        SimulationResult with hourly loads
    """
    # Load weather data
    weather_data = load_weather_data(project_id, years)
    
    # Load rooms
    rooms = load_rooms(project_id, room_ids)
    
    # Initialize results storage
    results = defaultdict(list)  # room_id -> hourly loads
    
    # Process each hour
    total_hours = len(weather_data)
    for hour_idx, weather in enumerate(weather_data):
        # Get outdoor conditions
        outdoor_temp = weather['dry_bulb_temp']
        outdoor_humidity = weather['relative_humidity']
        pressure = weather['atmospheric_pressure']
        
        # Calculate outdoor enthalpy (once per hour)
        outdoor_enthalpy = calculate_enthalpy(
            outdoor_temp, outdoor_humidity, pressure
        )
        
        # Process each room
        for room in rooms:
            # Calculate indoor enthalpy (constant)
            indoor_enthalpy = room['indoor_enthalpy']
            
            # Calculate enthalpy difference
            enthalpy_diff = outdoor_enthalpy - indoor_enthalpy
            
            # Fresh air load varies with weather
            fresh_air_load = calculate_fresh_air_load(
                room['fresh_air_volume'],
                enthalpy_diff
            )
            
            # Terminal load is fixed (design condition)
            terminal_load = room['terminal_load']
            
            # Total load
            total_load = terminal_load + fresh_air_load
            
            # Store result
            results[room['id']].append({
                'hour': hour_idx,
                'datetime': weather['datetime'],
                'outdoor_temp': outdoor_temp,
                'outdoor_humidity': outdoor_humidity,
                'fresh_air_load': fresh_air_load,
                'terminal_load': terminal_load,
                'total_load': total_load
            })
        
        # Update progress
        update_progress(hour_idx, total_hours)
    
    return results
```

from concurrent.futures import ProcessPoolExecutor

def simulate_parallel(weather_data, rooms, n_workers=4):
    """Parallel simulation using multiple processes."""
    
    # Split rooms into chunks
    room_chunks = np.array_split(rooms, n_workers)
    
    with ProcessPoolExecutor(max_workers=n_workers) as executor:
        futures = []
        for chunk in room_chunks:
            future = executor.submit(
                simulate_chunk, weather_data, chunk
            )
            futures.append(future)
        
        # Collect results
        results = {}
        for future in futures:
            results.update(future.result())
    
    return results

def simulate_coefficient_method(
    project_id: int,
    production_rates: Dict[str, float]  # period -> rate
) -> SimulationResult:
    """
    Execute coefficient-based simulation.
    
    Args:
        project_id: Project to simulate
        production_rates: Production rate by period
    
    Returns:
        SimulationResult with hourly loads
    """
    # Load rooms with static loads
    rooms = load_rooms_with_static_loads(project_id)
    
    # Load coefficient matrix
    coefficients = load_coefficient_matrix(project_id)
    
    # Generate 8760 hours for each year
    results = defaultdict(list)
    
    for year in range(3):  # 3 years
        for hour in range(8760):
            # Determine season
            season = get_season(hour)
            
            # Get production rate for this hour
            prod_rate = get_production_rate(hour, production_rates)
            
            # Get coefficient
            coeff = coefficients[season][hour % 24][prod_rate]
            
            # Calculate load for each room
            for room in rooms:
                hourly_load = room['static_load'] * coeff
                results[room['id']].append({
                    'hour': hour + year * 8760,
                    'coefficient': coeff,
                    'production_rate': prod_rate,
                    'total_load': hourly_load
                })
    
    return results

### 4.3 结果汇总

**汇总层级：**

```python
def aggregate_results(hourly_results, rooms):
    """
    Aggregate simulation results at multiple levels.
    """
    aggregation = {
        'hourly': {},      # Room-level hourly data
        'daily': {},       # Daily summaries
        'monthly': {},     # Monthly summaries
        'yearly': {},      # Yearly summaries
        'peak': {},        # Peak load analysis
        'duration': {}     # Duration curve data
    }
    
    for room_id, data in hourly_results.items():
        room = rooms[room_id]
        
        # Hourly aggregation (already done)
        aggregation['hourly'][room_id] = data
        
        # Daily aggregation
        daily = defaultdict(list)
        for entry in data:
            day = entry['datetime'].date()
            daily[day].append(entry['total_load'])
        
        aggregation['daily'][room_id] = {
            day: {
                'max': max(loads),
                'min': min(loads),
                'avg': sum(loads) / len(loads),
                'sum': sum(loads)
            }
            for day, loads in daily.items()
        }
        
        # Monthly aggregation
        # ... similar pattern
        
        # Peak analysis
        max_load = max(data, key=lambda x: x['total_load'])
        min_load = min(data, key=lambda x: x['total_load'])
        
        aggregation['peak'][room_id] = {
            'max_load': max_load['total_load'],
            'max_datetime': max_load['datetime'],
            'min_load': min_load['total_load'],
            'min_datetime': min_load['datetime']
        }
    
    return aggregation
```

## 5. Celery 任务实现

### 5.1 主任务

```python
# tasks.py
from celery import shared_task
from channels.layers import get_channel_layer
from asgiref.sync import async_to_sync

@shared_task(bind=True)
def run_dynamic_simulation(
    self,
    project_id: int,
    simulation_type: str,  # 'weather_driven' or 'coefficient'
    config: Dict
):
    """
    Execute dynamic simulation asynchronously.
    """
    task_id = self.request.id
    channel_layer = get_channel_layer()
    
    try:
        # Send started notification
        async_to_sync(channel_layer.group_send)(
            f'simulation_{project_id}',
            {
                'type': 'simulation_started',
                'task_id': task_id,
                'message': 'Simulation started'
            }
        )
        
        # Execute simulation
        if simulation_type == 'weather_driven':
            results = simulate_weather_driven(
                project_id,
                config['years'],
                config.get('room_ids')
            )
        else:
            results = simulate_coefficient_method(
                project_id,
                config['production_rates']
            )
        
        # Store results
        store_simulation_results(project_id, results)
        
        # Aggregate results
        aggregated = aggregate_results(results)
        store_aggregated_results(project_id, aggregated)
        
        # Send completion notification
        async_to_sync(channel_layer.group_send)(
            f'simulation_{project_id}',
            {
                'type': 'simulation_completed',
                'task_id': task_id,
                'message': 'Simulation completed',
                'result_url': f'/api/v1/calculations/dynamic/{project_id}/'
            }
        )
        
        return {
            'success': True,
            'project_id': project_id,
            'total_hours': len(results) * 8760,
            'total_rooms': len(results)
        }
    
    except Exception as e:
        # Send error notification
        async_to_sync(channel_layer.group_send)(
            f'simulation_{project_id}',
            {
                'type': 'simulation_error',
                'task_id': task_id,
                'error': str(e)
            }
        )
        raise
```

@shared_task(bind=True)
def simulate_with_progress(

                'current': step,

                'message': message

    update_progress(5, 'Loading weather data...')
    weather_data = load_weather_data(project_id, config['years'])
    update_progress(10, 'Weather data loaded')
    
    # Step 2: Load rooms (20%)
    update_progress(15, 'Loading room configurations...')
    rooms = load_rooms(project_id)
    update_progress(20, 'Rooms loaded')
    
    # Step 3: Simulation (20-90%)
    update_progress(25, 'Starting simulation...')
    results = {}
    total_hours = len(weather_data)
    
    for hour_idx, weather in enumerate(weather_data):
        # Process hour
        for room in rooms:
            # Calculate load
            pass
        
        # Update progress every 100 hours
        if hour_idx % 100 == 0:
            progress = 25 + int((hour_idx / total_hours) * 65)
            update_progress(
                progress,
                f'Processing hour {hour_idx}/{total_hours}'
            )
    
    # Step 4: Store results (90-100%)

## 9. 错误处理

| 错误 | 原因 | 处理方式 |
|-------|-------|----------|
| 缺少气象数据 | 所请求年份无数据 | 返回包含可用年份的错误 |
| 房间配置无效 | 缺少必填参数 | 跳过该房间，记录告警 |
| 计算溢出 | 极值 | 限制为最大值，告警 |
| 数据库错误 | 连接问题 | 重试 3 次，失败后报错 |
| 内存超限 | 房间过多 | 分批处理 |
