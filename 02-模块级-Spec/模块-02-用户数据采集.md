## 1. 模块概述

### 1.1 功能职责

本模块负责采集系统所需的全部输入数据，包含：
- **建筑参数数据**：功能区域面积、高度、温湿度要求、负荷指标、冷冻水档归属等
- **图纸数据**：设计院提供的楼层平面 PDF 图纸
- **层级管理**：项目→建筑→楼层→功能区域四级结构

**v0.5 核心功能：**
- 左树右详情 UI 框架 + 6 Tab 布局
- 建筑数据前端录入
- Excel 批量导入（模板下载 + 错误定位到行）
- 功能区域参数表单（7 组字段）
- 默认值继承机制（四级覆盖）
- 实时计算预览（单节点 500ms 内刷新）
- 自动保存草稿（间隔 30 秒）

class Building(models.Model):

    建筑模型

    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        db_table = 'building'
        ordering = ['project', 'building_name']
```

```

**Room 模型：**
```python
class Room(models.Model):
    """
    功能区域模型 - 最小计算单元

    PRD 引用：F2-014 ~ F2-020, F2-040 ~ F2-045
    Spec 引用：模块-02 Section 2.2, Section 6.5
    """
    id = models.BigAutoField(primary_key=True)
    floor = models.ForeignKey(
        'Floor',
        on_delete=models.CASCADE,
        related_name='rooms'
    )

    # 第一组 — 基本信息
    room_name = models.CharField(max_length=100)
    room_code = models.CharField(max_length=50, blank=True)
    area = models.DecimalField(max_digits=10, decimal_places=2)
    ceiling_height = models.DecimalField(max_digits=6, decimal_places=2)
    volume = models.DecimalField(max_digits=12, decimal_places=2, editable=False)  # 自动计算

    # 第二组 — 温湿度要求
    design_temp_text = models.CharField(max_length=50, blank=True)
    design_humidity_text = models.CharField(max_length=50, blank=True)
    temp_control_precision = models.CharField(
        max_length=10,
        choices=[
            ('±1', '±1°C'), ('±2', '±2°C'), ('±3', '±3°C'),
            ('±5', '±5°C'), ('none', '无要求')
        ],
        blank=True
    )
    indoor_calc_temp = models.DecimalField(
        max_digits=5, decimal_places=2, null=True, blank=True
    )
    indoor_calc_humidity = models.DecimalField(
        max_digits=5, decimal_places=2, null=True, blank=True
    )
    cleanliness_level = models.CharField(max_length=20, blank=True)

    # 第三组 — 负荷计算参数
    civil_load_index = models.DecimalField(max_digits=8, decimal_places=2)
    lighting_load_index = models.DecimalField(max_digits=8, decimal_places=2)
    personnel_load_index = models.DecimalField(
        max_digits=8, decimal_places=2, null=True, blank=True
    )
    personnel_count = models.IntegerField(null=True, blank=True)

    # 第四组 — 设备参数（三类拆分）
    electric_equipment_power = models.DecimalField(
        max_digits=10, decimal_places=2, null=True, blank=True
    )
    electric_equipment_coefficient = models.DecimalField(
        max_digits=5, decimal_places=4, null=True, blank=True
    )
    heated_power_with_exhaust = models.DecimalField(
        max_digits=10, decimal_places=2, null=True, blank=True
    )
    heated_coefficient_with_exhaust = models.DecimalField(
        max_digits=5, decimal_places=4, null=True, blank=True
    )
    heated_power_without_exhaust = models.DecimalField(
        max_digits=10, decimal_places=2, null=True, blank=True
    )
    heated_coefficient_without_exhaust = models.DecimalField(
        max_digits=5, decimal_places=4, null=True, blank=True
    )

    # 第五组 — 风量参数
    heat_exhaust_volume = models.DecimalField(
        max_digits=10, decimal_places=2, null=True, blank=True
    )
    acid_exhaust_volume = models.DecimalField(
        max_digits=10, decimal_places=2, null=True, blank=True
    )
    alkali_exhaust_volume = models.DecimalField(
        max_digits=10, decimal_places=2, null=True, blank=True
    )
    organic_exhaust_volume = models.DecimalField(
        max_digits=10, decimal_places=2, null=True, blank=True
    )
    dust_exhaust_volume = models.DecimalField(
        max_digits=10, decimal_places=2, null=True, blank=True
    )
    total_exhaust_volume = models.DecimalField(
        max_digits=12, decimal_places=2, editable=False, null=True, blank=True
    )  # 自动计算
    pressure_diff = models.DecimalField(
        max_digits=8, decimal_places=2, null=True, blank=True
    )
    design_air_changes = models.IntegerField(null=True, blank=True)
    supply_air_temp_diff = models.DecimalField(
        max_digits=5, decimal_places=2, null=True, blank=True
    )

    # 第六组 — 新风处理配置
    fresh_air_mode = models.CharField(
        max_length=20,
        choices=[('single', '单水温'), ('two_stage', '两阶段')],
        default='single'
    )
    fresh_air_water_config = models.ForeignKey(
        'WaterTemperatureConfig',
        on_delete=models.SET_NULL,
        null=True, blank=True,
        related_name='fresh_air_rooms'
    )
    fresh_air_water_config_stage2 = models.ForeignKey(
        'WaterTemperatureConfig',
        on_delete=models.SET_NULL,
        null=True, blank=True,
        related_name='fresh_air_rooms_stage2'
    )

    # 第七组 — 末端负荷水温归属
    terminal_water_config = models.ForeignKey(
        'WaterTemperatureConfig',
        on_delete=models.SET_NULL,
        null=True, blank=True,
        related_name='terminal_rooms'
    )

    sort_order = models.IntegerField(default=0)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        db_table = 'room'
        ordering = ['floor', 'sort_order', 'room_name']

    def save(self, *args, **kwargs):
        self.volume = self.area * self.ceiling_height
        self.total_exhaust_volume = (
            (self.heat_exhaust_volume or 0) +
            (self.acid_exhaust_volume or 0) +
            (self.alkali_exhaust_volume or 0) +
            (self.organic_exhaust_volume or 0) +
            (self.dust_exhaust_volume or 0)
        )
        super().save(*args, **kwargs)
```

## 4. 业务逻辑

### 4.1 树形结构构建流程

```
1. 前端请求项目树形结构
2. 后端查询项目下所有建筑、楼层、功能区域
3. 按 sort_order 排序
4. 构建四级树形结构
5. 应用虚拟滚动分页
6. 返回当前页节点

性能优化：
- 使用数据库索引优化查询
- 缓存树形结构（Redis）
- 增量更新（只更新变化的节点）
```

### 4.2 Excel 导入流程

```
1. 用户上传 Excel 文件
2. 后端接收文件并保存到临时目录
3. 使用 openpyxl 解析工作表
4. 验证表头列名是否匹配模板
5. 逐行解析数据：
   a. 读取楼层列，查找或创建楼层记录
   b. 读取功能区域列，查找或创建功能区域记录
   c. 验证必填字段
   d. 验证数据类型和范围
   e. 保存到数据库
6. 汇总导入结果
7. 删除临时文件
8. 返回成功/失败统计

错误处理：
- 必填字段为空：记录行号和字段名
- 类型错误：记录行号、字段名和错误信息
- 重复记录：根据 import_mode 处理（追加/覆盖）
```

### 4.3 默认值继承流程

```
1. 新建功能区域时，系统自动获取继承链：
   楼层 → 建筑 → 项目 → 系统默认

2. 按优先级查找默认值：
   a. 楼层级覆盖（DefaultConfig level='floor'）
   b. 建筑级覆盖（DefaultConfig level='building'）
   c. 项目级覆盖（DefaultConfig level='project'）
   d. 系统默认值（DefaultConfig level='system'）

3. 返回继承的默认值

4. 用户在表单中可覆盖继承值

5. 保存时记录用户显式设置的字段
```

### 4.4 实时计算预览流程

```
1. 用户修改功能区域参数
2. 前端防抖处理（500ms 内无新输入）
3. 调用预览 API
4. 后端单节点增量计算：
   a. 计算末端负荷
   b. 计算新风量
   c. 计算新风冷负荷
   d. 计算总负荷
5. 返回计算结果
6. 前端更新预览面板

优化策略：
- 只计算当前节点，不触发全量重算
- 缓存中间结果（如焓值计算）
- 使用 psychrolib 库加速焓值计算
```

### 4.5 自动保存流程

```
1. 用户在表单中修改字段
2. 前端记录变化的字段和值
3. 启动 30 秒定时器
4. 定时器触发：
   a. 收集所有未保存的变化
   b. 调用自动保存 API
   c. 后端更新数据库
   d. 返回保存状态
5. 前端显示保存状态

边界情况：
- 用户连续修改：重置定时器
- 保存失败：保留本地草稿，提示用户
- 网络断开：本地缓存，恢复后同步
```

| area | 必填，> 0 | "面积必须大于0" |
| ceiling_height | 必填，> 0 | "吊顶高度必须大于0" |

|----------|------|----------|

| 范围校验 | 数值在有效范围内 | 记录行号、字段名和有效范围 |

## 6. 性能优化

### 6.1 虚拟滚动

**目标：** 100,000+ 节点虚拟滚动 < 2 秒

**实现方案：**
```typescript
// 前端虚拟滚动实现
import { FixedSizeList as List } from 'react-window';

const TreeView = ({ nodes, height, itemSize }) => (
  <List
    height={height}
    itemCount={nodes.length}
    itemSize={itemSize}
    width="100%"
  >
    {({ index, style }) => (
      <TreeNode
        node={nodes[index]}
        style={style}
      />
    )}
  </List>
);
```

### 6.2 树形结构缓存

**缓存策略：**
- Redis 缓存项目树形结构
- 缓存 key: `project_tree:{project_id}`
- 缓存 TTL: 30 分钟
- 增量更新：只更新变化的节点

### 6.3 Excel 导入优化

**优化方案：**
- 使用 openpyxl 的 read_only 模式
- 批量插入数据库（bulk_create）
- 异步任务处理大文件（Celery）
- 进度回调（WebSocket）

### 6.4 实时预览优化

**优化方案：**
- 前端防抖处理（500ms）
- 后端缓存中间结果
- 使用 psychrolib 库加速焓值计算
- 增量计算（只计算变化的部分）
