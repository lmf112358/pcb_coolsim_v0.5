## 1. 模块概述

### 1.1 功能职责

v0.5 实现基础导出能力，支持固定模板的 PDF 报告和 Excel/CSV 数据导出。

**v0.5 核心功能：**
- 静态计算报告（PDF）
- 冷站配置报告（PDF）
- 设备清单（Excel）
- 负荷计算书（Excel）
- 仿真数据（CSV）
- 按需导出（P2，v0.5 预留）

**v0.5 范围：**
- 使用固定模板，不支持模板自定义
- 导出范围：全项目（不支持按楼层/功能区域筛选，P2）
- 导出格式：PDF、Excel、CSV
- 导出性能：PDF < 30 秒，Excel < 60 秒，CSV < 60 秒

### 1.2 核心 PRD 需求

| PRD ID | 需求描述 | 优先级 |
|--------|----------|--------|
| F8-001 | 一键生成静态冷量计算报告 PDF | P0 |
| F8-002 | 报告内容：项目概述 + 冷负荷计算 + 冷量构成分析 | P0 |
| F8-003 | 报告含引用标准清单和所有系数依据来源 | P0 |
| F8-005 | 一键生成冷站配置报告 PDF | P0 |
| F8-006 | 报告内容：制冷机组配置方案 + N+1 冗余分析 + 校验结果 | P0 |
| F8-008 | 导出设备清单 Excel | P0 |
| F8-010 | 导出负荷计算书 Excel | P0 |
| F8-012 | 导出动态仿真逐时数据 CSV | P0 |

### 2.2 数据模型

**ExportTask 模型：**
```python
class ExportTask(models.Model):
    """
    导出任务

    PRD 引用：F8-001 ~ F8-016
    Spec 引用：模块-08 Section 2.2
    """
    id = models.BigAutoField(primary_key=True)
    project = models.ForeignKey(
        'Project',
        on_delete=models.CASCADE,
        related_name='export_tasks'
    )
    export_type = models.CharField(
        max_length=50,
        choices=[
            ('static_report', '静态计算报告'),
            ('station_report', '冷站配置报告'),
            ('equipment_list', '设备清单'),
            ('load_calculation', '负荷计算书'),
            ('simulation_data', '仿真数据')
        ]
    )
    status = models.CharField(
        max_length=20,
        choices=[
            ('pending', '待处理'),
            ('processing', '处理中'),
            ('completed', '已完成'),
            ('failed', '失败')
        ],
        default='pending'
    )
    file_format = models.CharField(
        max_length=10,
        choices=[
            ('pdf', 'PDF'),
            ('xlsx', 'Excel'),
            ('csv', 'CSV')
        ]
    )
    file_path = models.CharField(max_length=500, blank=True)
    file_size = models.IntegerField(null=True, blank=True)
    error_message = models.TextField(blank=True)
    created_by = models.ForeignKey(
        'User',
        on_delete=models.SET_NULL,
        null=True
    )
    created_at = models.DateTimeField(auto_now_add=True)
    completed_at = models.DateTimeField(null=True, blank=True)

    class Meta:
        db_table = 'export_task'
        ordering = ['-created_at']
```

```python
# Excel 生成服务
class ExcelGenerator:
    """
    Excel 生成服务

    PRD 引用：F8-008 ~ F8-011
    Spec 引用：模块-08 Section 4.2
    """
    
    def generate_equipment_list(self, project_id, scheme_id, water_temp_configs):
        """
        生成设备清单
        """
        # 1. 获取冷站方案数据
        scheme = CoolingStationScheme.objects.get(id=scheme_id)
        
        # 2. 创建 Excel 工作簿
        wb = openpyxl.Workbook()
        
        # 3. 按水温系统创建 sheet
        for water_config_id in water_temp_configs:
            ws = wb.create_sheet(title=f'水温系统-{water_config_id}')
            
            # 4. 写入表头
            headers = ['设备类型', '型号', '规格', '数量', '能效参数']
            for col, header in enumerate(headers, 1):
                ws.cell(row=1, column=col, value=header)
            
            # 5. 写入数据
            config_lines = scheme.config_lines.filter(
                water_temp_config_id=water_config_id
            )
            for row, line in enumerate(config_lines, 2):
                ws.cell(row=row, column=1, value='冷机')
                ws.cell(row=row, column=2, value=line.chiller_name)
                ws.cell(row=row, column=3, value=f'{line.single_capacity_rt} RT')
                ws.cell(row=row, column=4, value=line.chiller_count)
                ws.cell(row=row, column=5, value='-')
        
        # 6. 保存文件
        file_path = self.save_file(project_id, 'equipment_list', wb)
        
        return file_path
```

### 4.3 CSV 生成流程

```python
# CSV 生成服务
class CSVGenerator:
    """
    CSV 生成服务

    PRD 引用：F8-012 ~ F8-014
    Spec 引用：模块-08 Section 4.3
    """
    
    def generate_simulation_data(self, project_id, batch_id, granularity, entity_ids):
        """
        生成仿真数据 CSV
        """
        # 1. 创建临时文件
        temp_file = tempfile.NamedTemporaryFile(
            mode='w', 
            suffix='.csv', 
            delete=False
        )
        
        # 2. 写入 CSV 头部
        headers = [
            'timestamp', 'total_load_kw', 'terminal_load_kw', 
            'fresh_air_load_kw', 'outdoor_temp'
        ]
        temp_file.write(','.join(headers) + '\n')
        
        # 3. 查询并写入数据
        if granularity == 'room':
            queryset = HourlyLoadResult.objects.filter(
                batch_id=batch_id,
                room_id__in=entity_ids
            ).order_by('timestamp')
        elif granularity == 'floor':
            queryset = HourlyLoadResult.objects.filter(
                batch_id=batch_id,
                room__floor_id__in=entity_ids
            ).order_by('timestamp')
        # ... 其他粒度 ...
        
        # 4. 批量写入（避免内存溢出）
        for result in queryset.iterator(chunk_size=1000):
            row = [
                result.timestamp.isoformat(),
                str(result.total_load_kw),
                str(result.terminal_load_kw),
                str(result.fresh_air_load_kw),
                str(result.outdoor_temp)
            ]
            temp_file.write(','.join(row) + '\n')
        
        # 5. 关闭文件并返回路径
        temp_file.close()
        return temp_file.name
```

### 4.4 异步导出流程

```python
# Celery 异步导出任务
@shared_task
def export_task(task_id):
    """
    异步导出任务

    PRD 引用：F8-001, F8-005, F8-012
    Spec 引用：模块-08 Section 4.4
    """
    try:
        # 1. 获取任务信息
        task = ExportTask.objects.get(id=task_id)
        task.status = 'processing'
        task.save()
        
        # 2. 根据导出类型调用相应服务
        if task.export_type == 'static_report':
            generator = PDFGenerator()
            file_path = generator.generate_static_report(
                task.project_id,
                task.options.get('sections', [])
            )
        elif task.export_type == 'station_report':
            generator = PDFGenerator()
            file_path = generator.generate_station_report(
                task.project_id,
                task.options.get('scheme_id'),
                task.options.get('sections', [])
            )
        elif task.export_type == 'equipment_list':
            generator = ExcelGenerator()
            file_path = generator.generate_equipment_list(
                task.project_id,
                task.options.get('scheme_id'),
                task.options.get('water_temp_configs', [])
            )
        elif task.export_type == 'simulation_data':
            generator = CSVGenerator()
            file_path = generator.generate_simulation_data(
                task.project_id,
                task.options.get('batch_id'),
                task.options.get('granularity'),
                task.options.get('entity_ids', [])
            )
        
        # 3. 更新任务状态
        task.status = 'completed'
        task.file_path = file_path
        task.file_size = os.path.getsize(file_path)
        task.completed_at = timezone.now()
        task.save()
        
        # 4. 发送通知
        send_export_completion_notification(task)
        
    except Exception as e:
        # 5. 错误处理
        task.status = 'failed'
        task.error_message = str(e)
        task.save()
        raise
```

## 6. 性能优化

### 6.1 PDF 生成优化

**目标：** PDF 生成 < 30 秒

**优化方案：**
- 使用 WeasyPrint 或 ReportLab 生成 PDF
- 预加载模板和静态资源
- 使用缓存存储常用数据
- 异步生成（Celery）

### 6.2 Excel 生成优化

**目标：** Excel 生成 < 60 秒

**优化方案：**
- 使用 openpyxl 的 write_only 模式
- 批量写入数据
- 避免逐行写入
- 异步生成（Celery）

### 6.3 CSV 生成优化

**目标：** CSV 生成 < 60 秒

**优化方案：**
- 使用流式写入
- 批量查询数据库
- 避免一次性加载所有数据到内存
- 异步生成（Celery）
