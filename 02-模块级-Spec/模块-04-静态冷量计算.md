## 1. 功能概述

### 1.1 目的

对项目中所有功能区域（Room）执行静态设计日冷负荷计算，确定极端夏季工况下的冷量需求，替代手工 Excel 计算。本模块为下游负荷分析（模块五）、动态仿真（模块六，Q_terminal 桥梁）、负荷预测（模块十）提供静态设计负荷。

### 1.2 关键特性

- 6 步计算流水线（焓值 → 末端负荷 → 风量 → 新风冷负荷 → 房间总负荷 → 多级汇总）
- 实时预览（防抖 500ms，单节点增量重算）
- 整个项目的批量计算（Celery 异步）
- 计算结果缓存
- 校验与错误报告

### 1.3 v0.5 范围说明（来自 PRD §8.1 / §15）

- **末端负荷 Q_terminal 是桥梁**，计算一次，静态与动态共用（PRD §15.4）
- **新风量 = 总排风量 + 压差渗透风量（简单加法）**，不含卫生风量与净化风量（A4 有意工程简化）
- 压差渗透系数由 PRD §8.3 唯一权威表 8 点线性插值查得
- 新风冷负荷唯一公式（定义A），ρ 统一 1.2
- 室内温湿度空值默认 26°C / 55%
- 末端负荷按功能区域级冷冻水档分配（ADR-0001，不再全归中温）
- v0.5.1 无 season_config 表（气象数据本身区分季节）

## 2. 架构设计

### 2.1 计算流水线

```
┌───────────────────────────────────────────────────────────┐
│ Step 1: 焓值计算（psychrolib）                              │
│   输入: CityConfig（室外干球/湿球/气压）, Room.indoor_calc_*  │
│   输出: RoomCalcResult.{outdoor,indoor}_enthalpy_calc, enthalpy_diff │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ Step 2: 末端负荷计算（5 项，桥梁，静态动态共用）              │
│   输入: Room.{civil,lighting,...}_load_index, Room.area      │
│   输出: RoomCalcResult.{civil,lighting,...}_load, terminal_load │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ Step 3: 风量计算（8 点查表 + 简单加法）                      │
│   输入: Room.{heat,acid,...}_exhaust_volume, Room.volume, Room.pressure_diff │
│   输出: RoomCalcResult.{total_exhaust,infiltration,fresh_air}_volume │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ Step 4: 新风冷负荷计算（按水温分类）                         │
│   输入: fresh_air_volume, 焓值, WaterTempConfig, DefaultConfig │
│   输出: RoomLoadByWaterTemp.fresh_air_load                  │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ Step 5: 房间总负荷（<0 截断为 0，与动态统一）                │
│   输入: fresh_air_load, terminal_load                       │
│   输出: RoomLoadByWaterTemp.total_load                      │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ Step 6: 多级负荷聚合（Room→Floor→Building+ExtraLoad→Project+ExtraLoad）│
│   输入: RoomLoadByWaterTemp, ExtraLoad                      │
│   输出: LoadSummary                                         │
└───────────────────────────────────────────────────────────┘
```

- Step 3（风量）独立于 Step 1/2（仅需 Room 风量参数与体积）
- Step 4（新风冷负荷）依赖 Step 1 与 Step 3
- Step 5 依赖 Step 2 与 Step 4
- Step 6 依赖 Step 5 与 ExtraLoad

## 3. 详细计算（公式权威来源：PRD §15）

### 3.1 末端负荷计算（PRD §15.1，F4-001 ~ F4-006）

**末端负荷 Q_terminal 是桥梁，计算一次，静态动态共用。**

```
土建负荷     = civil_load_index × area / 1000                                 (kW)
照明负荷     = lighting_load_index × area / 1000                              (kW)
人员负荷     = personnel_load_index × personnel_count / 1000                  (kW，空取 0)
电动设备负荷 = electric_equipment_power × electric_equipment_coefficient      (kW，空取 0，不乘 1000)
电热设备负荷 = heated_power_with × heated_coeff_with
             + heated_power_without × heated_coeff_without                    (kW，空取 0，不乘 1000)

Q_terminal = 土建 + 照明 + 人员 + 电动设备 + 电热设备
```

- 土建/照明/人员：指标 × 基数 / 1000 转 kW
- 电动/电热设备：**kW 量纲，不乘 1000**（功率已是 kW，系数无量纲）
- 字段全部直接读 Room 单表

### 3.2 风量计算（PRD §15.2 / §8.3，F4-007 ~ F4-009）

```
总排风量     = 热排风 + 酸性 + 碱性 + 有机 + 含尘（五类求和，空取 0）
压差渗透风量 = volume × k(|pressure_diff|)
新风量       = 总排风量 + 压差渗透风量    （简单加法，A4）
体积 = 面积 × 吊顶高度
```

**压差渗透风量系数表（PRD §8.3 唯一权威表，写入 DefaultConfig，可项目级覆盖）：**

| 压差 \|Pa\| | 系数 k（次/h） | 说明 |
| --- | --- | --- |
| 0 | 0.0 | 无渗透 |
| 1 | 1.0 | |
| 2 | 1.5 | |
| 3 | 2.0 | |
| 5 | 3.0 | |
| 10 | 3.5 | 正/负压对称取绝对值 |
| 15 | 4.0 | |
| > 15 | 4.0（封顶） | 极端压差异常，提示用户复核 |

> 非表内点采用线性插值。**绝不能用 k = pressure_diff/5 或 k = √(ΔP) 公式。**

查表 + 插值函数：

```python
def lookup_infiltration_coeff(pressure_diff):
    table = [(0, 0.0), (1, 1.0), (2, 1.5), (3, 2.0),
             (5, 3.0), (10, 3.5), (15, 4.0)]
    x = abs(pressure_diff)            # 正/负压对称
    if x >= 15:
        return 4.0
    for i in range(len(table) - 1):
        x0, y0 = table[i]
        x1, y1 = table[i + 1]
        if x0 <= x <= x1:
            return y0 + (y1 - y0) * (x - x0) / (x1 - x0)
    return 0.0
```

> **新风量就是简单加法，不加 MAX，不加卫生风量，不加净化风量**（A4 有意工程简化）。

### 3.3 新风冷负荷计算（PRD §15.3，F4-010 ~ F4-015）

```
Q_fresh_air = ρ × V_fresh_air × (h_outdoor − h_indoor) / 3600    (kW)

ρ = DefaultConfig.air_density（默认 1.2 kg/m³，统一 1.2）
焓值使用 psychrolib：calculate_enthalpy(dry_bulb, humidity, pressure)
```

- 室内焓 h_indoor：indoor_calc_temp（空取 26°C）、indoor_calc_humidity（空取 **55%**）、CityConfig.pressure_summer
- 室外焓 h_outdoor（静态）：CityConfig.temp_dry_ac_summer + 由湿球推算相对湿度 + CityConfig.pressure_summer
- **唯一公式（定义A）：** 焓差 = 室外焓 − 室内焓；删除"定义B 送风焓 h_s"歧义
- 新风负荷可为负；总负荷 = Q_terminal + Q_fresh_air，**< 0 截断为 0**（与动态统一）；Q_min 取 > 0 最小值

### 3.4 按冷冻水温度分类（ADR-0001，F4-020 ~ F4-023）

末端负荷与新风冷负荷**分别**按档归档：

- **末端负荷**：按 `Room.terminal_water_temp_config_id` 归入对应分类（默认中温 12/17°C，可逐区指定低温 7/12°C）。**绝不能把同一 terminal_load 复制到所有水温档。**
- **新风冷负荷**：按 fresh_air 配置归档：
  - 单水温模式（fresh_air_water_mode=single）：全量归入 `Room.fresh_air_water_temp_config_id`
  - 两阶段模式（fresh_air_water_mode=two_stage）：按比例分配到第一段 / 第二段；`h_intermediate`（中间状态焓值）预留接口，v0.5 先按比例分配

### 3.5 多级汇总（PRD §15.6，F4-024 ~ F4-027）

```
功能区域级（Room）：每个区域独立计算
    ↓
楼层级（Floor）：汇总该楼层所有区域
    ↓
建筑级（Building）：汇总所有楼层 + 该建筑级 ExtraLoad（PCW、配电室空调等）
    ↓
项目级（Project）：汇总所有建筑 + 项目级 ExtraLoad
```

每层级按 category（水温分类）汇总：

```
fresh_air_load = SUM(下级 fresh_air_load)
terminal_load  = SUM(下级 terminal_load)
extra_load     = SUM(对应层级 ExtraLoad.load_value)
total_load     = fresh_air_load + terminal_load + extra_load
```

## 4. 实时预览（F4-034 ~ F4-037）

### 4.1 设计

```
用户修改参数
        ↓
前端：防抖（500ms）
        ↓
API：POST /api/v1/rooms/{id}/preview/
        ↓
Redis 缓存检查（key=preview:{room_id}:{params_hash}, TTL 30s）
        ↓ （缓存未命中）
单节点增量重算：Step 1-5（跳过聚合）
        ↓
缓存结果（TTL 30s）
        ↓
返回预览
```

- 仅重算该选中节点，**不触发全量重算**（F4-034）
- 楼层/建筑/项目节点：聚合已有结果，非全量重算（F4-036）
- 参数校验失败显示明确错误，不执行计算（F4-037）

### 4.2 性能目标

| 场景 | 目标 | 策略 |
|------|------|------|
| 单房间预览（缓存命中） | < 100ms | Redis 缓存 |
| 缓存未命中 | < 500ms | 单节点增量重算 |
| 1000 房间批量 | < 5 秒（F4-028） | Celery 并行 |

## 5. 批量计算（Celery 异步）

```python
@celery_app.task(bind=True)
def calculate_project_static(self, project_id: int):
    """批量静态计算：对项目所有 Room 逐房执行 6 步流水线。"""
    rooms = Room.objects.filter(floor__building__project_id=project_id)
    total = rooms.count()
    completed = 0
    for room in rooms:
        try:
            with transaction.atomic():
                StaticLoadService().calculate_room(room)   # 单房原子
            completed += 1
            self.update_state(state='PROGRESS',
                              meta={'completed': completed, 'total': total})
        except Exception as e:
            log_calculation_error(room, e)                  # 单房失败跳过，不回滚其他房
    send_websocket_notification(project_id, 'calculation_complete')
```

- 单房计算在各自 atomic() 子事务内完成，单房失败仅记日志、跳过
- 聚合 aggregate() 单独 atomic()

## 6. 数据存储（表名 PascalCase）

### 6.1 结果表

- **RoomCalcResult**：房间级计算结果（焓值、末端负荷分项、风量、terminal_load 桥梁）
- **RoomLoadByWaterTemp**：按水温分类的房间级负荷（fresh_air_load / terminal_load / total_load × water_temp_config_id）
- **LoadSummary**：多级汇总（scope = floor / building / project）

### 6.2 输入表

- **Room**（单表，PRD 附录A）：负荷参数、风量参数、温湿度、新风配置、末端冷冻水档全部直存
- **CityConfig**：国标室外参数（夏季干球/湿球/气压）
- **DefaultConfig**：air_density=1.2、室内默认 26/55、压差 8 点表
- **WaterTempConfig**：冷冻水温度配置（低温 7/12、中温 12/17）
- **ExtraLoad**：额外负荷（PCW、配电室空调等）

## 7. 错误处理

| 错误 | 原因 | 处理方式 |
|------|------|----------|
| 无效湿空气状态 | 极端温度/湿度 | 使用边界值，向用户告警 |
| 缺少必填字段 | 输入不完整 | 返回校验错误（VALIDATION_ERROR，400） |
| 除零错误 | 面积/体积为零 | 使用默认值，向用户告警 |
| 计算溢出 | 极值 | 限制为最大值，向用户告警（CALCULATION_ERROR，422） |
| 资源不存在 | Room 不存在 | RESOURCE_NOT_FOUND，404 |
