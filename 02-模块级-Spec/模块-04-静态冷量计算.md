## 1. Module Overview

### 1.1 Purpose
Performs static design-day cooling load calculations for all rooms in a project. This is the core calculation engine that determines cooling requirements under worst-case summer conditions.

### 1.2 Key Features
- 6-step calculation pipeline
- Real-time preview (debounced 500ms)
- Batch calculation for entire project
- Calculation result caching
- Validation and error reporting

### 1.3 Accuracy Requirements

| Metric | Target | Validation |
|--------|--------|------------|
| Static calculation | < 0.1% deviation | Excel reference comparison |
| Real-time preview | < 500ms response | Performance testing |
| Batch (1000 rooms) | < 10 seconds | Performance testing |

## 2. Calculation Pipeline

### 2.1 Pipeline Overview

```
┌───────────────────────────────────────────────────────────┐
│ Step 1: Enthalpy Calculation                               │
│   Input: outdoor_temp, outdoor_humidity, pressure,         │
│          indoor_temp, indoor_humidity                      │
│   Output: outdoor_enthalpy, indoor_enthalpy, enthalpy_diff │
│   Library: psychrolib                                      │
└───────────────────────────┬───────────────────────────────┘
                            │
┌───────────────────────────▼───────────────────────────────┐
│ Step 2: Terminal Load Calculation                          │
│   Input: area, load_indices, equipment_power, factors      │
│   Output: civil_load, lighting_load, personnel_load,       │
│           equipment_load, terminal_load                    │
└───────────────────────────┬───────────────────────────────┘
                            │
┌───────────────────────────▼───────────────────────────────┐
│ Step 3: Air Volume Calculation                             │
│   Input: exhaust_volumes, pressure_diff, volume            │
│   Output: total_exhaust, infiltration, fresh_air,          │
│           supply_air, return_air                           │
└───────────────────────────┬───────────────────────────────┘
                            │
┌───────────────────────────▼───────────────────────────────┐
│ Step 4: Fresh Air Load Calculation                         │
│   Input: fresh_air_volume, enthalpy_diff, water_tier       │
│   Output: fresh_air_load                                   │
└───────────────────────────┬───────────────────────────────┘
                            │
┌───────────────────────────▼───────────────────────────────┐
│ Step 5: Room Total Load                                    │
│   Input: terminal_load, fresh_air_load                     │
│   Output: total_load, load_density                         │
└───────────────────────────┬───────────────────────────────┘
                            │
┌───────────────────────────▼───────────────────────────────┐
│ Step 6: Load Aggregation                                   │
│   Input: room_loads, extra_loads                           │
│   Output: floor_load, building_load, project_load          │
└───────────────────────────────────────────────────────────┘
```

### 2.2 Dependency Graph

```
Step 1 (Enthalpy) ──────────────┐
                                │
Step 2 (Terminal Load) ─────────┼──→ Step 4 (Fresh Air Load)
                                │           │
Step 3 (Air Volume) ────────────┘           │
                                            ▼
                                    Step 5 (Room Total)
                                            │
                                            ▼
                                    Step 6 (Aggregation)
```

**Note:** Steps 1 and 2 are independent and can run in parallel.

## 3. Detailed Calculations

### 3.1 Step 1: Enthalpy Calculation

**Function:** `calculate_enthalpy()`

**Formula:**
```
h = 1.006 × T + W × (2501 + 1.86 × T)

Where:
h = enthalpy (kJ/kg)
T = dry bulb temperature (°C)
W = humidity ratio (kg water / kg dry air)
```

**Implementation:**
```python
import psychrolib

def calculate_enthalpy(
    temp: float,           # °C
    humidity: float,       # %
    pressure: float        # Pa
) -> float:
    """
    Calculate moist air enthalpy.
    
    Returns: enthalpy in kJ/kg
    """
    psychrolib.SetUnitSystem(psychrolib.SI)
    
    # Get humidity ratio
    W = psychrolib.GetHumRatioFromRelHum(temp, humidity / 100, pressure)
    
    # Calculate enthalpy
    h = psychrolib.GetMoistAirEnthalpy(temp, W)
    
    return h / 1000  # Convert J/kg to kJ/kg
```

**Validation:**
```python
# Reference values for Xi'an summer conditions
assert abs(calculate_enthalpy(35.2, 45, 95920) - 76.45) < 0.1
assert abs(calculate_enthalpy(26.0, 55, 101325) - 52.34) < 0.1
```

### 3.2 Step 2: Terminal Load Calculation

**Function:** `calculate_terminal_load()`

**Formula:**
```
Terminal Load = Civil + Lighting + Personnel + Equipment

Where:
Civil = Area × Civil Index (W)
Lighting = Area × Lighting Index (W)
Personnel = Personnel Count × Personnel Load Index (W)
Equipment = Σ(Power_i × Factor_i × 1000) (W)
```

**Implementation:**
```python
def calculate_terminal_load(
    area: float,
    civil_index: float,
    lighting_index: float,
    personnel_index: float,
    personnel_count: int,
    equipment: List[Dict[str, float]]  # [{'power': kW, 'factor': 0-1}]
) -> Dict[str, float]:
    """
    Calculate terminal cooling load.
    
    Returns: dict with individual loads and total
    """
    civil = area * civil_index
    lighting = area * lighting_index
    personnel = personnel_count * personnel_index
    
    equipment_load = 0
    for eq in equipment:
        equipment_load += eq['power'] * eq['factor'] * 1000
    
    total = civil + lighting + personnel + equipment_load
    
    return {
        'civil_load': civil,
        'lighting_load': lighting,
        'personnel_load': personnel,
        'equipment_load': equipment_load,
        'terminal_load': total
    }
```

**Validation:**
```python
# Test case: 500 m² room
result = calculate_terminal_load(
    area=500,
    civil_index=50,
    lighting_index=20,
    personnel_index=120,
    personnel_count=15,
    equipment=[
        {'power': 80, 'factor': 0.8},
        {'power': 30, 'factor': 0.7},
        {'power': 20, 'factor': 0.6}
    ]
)
assert abs(result['terminal_load'] - 133800) < 0.1  # W
```

### 3.3 Step 3: Air Volume Calculation

**Function:** `calculate_air_volume()`

**Formula:**
```
Total Exhaust = Σ(Exhaust_i) (m³/h)
Infiltration = f(pressure_diff, volume) (m³/h)
Fresh Air = Total Exhaust + Infiltration (m³/h)
```

**Implementation:**
```python
def calculate_air_volume(
    heat_exhaust: float,
    acid_exhaust: float,
    alkaline_exhaust: float,
    organic_exhaust: float,
    dust_exhaust: float,
    pressure_diff: float,  # Pa (positive = positive pressure)
    volume: float          # m³
) -> Dict[str, float]:
    """
    Calculate air volumes.
    
    Returns: dict with all air volumes
    """
    total_exhaust = (
        heat_exhaust + acid_exhaust + 
        alkaline_exhaust + organic_exhaust + dust_exhaust
    )
    
    # Infiltration based on pressure difference
    # Formula: Q = k × V × √(ΔP)
    # k = infiltration coefficient (0.5 for typical building)
    k = 0.5
    infiltration = k * volume * (abs(pressure_diff) ** 0.5)
    
    # Fresh air = exhaust + infiltration
    fresh_air = total_exhaust + infiltration
    
    return {
        'total_exhaust': total_exhaust,
        'infiltration': infiltration,
        'fresh_air': fresh_air
    }
```

### 3.4 Step 4: Fresh Air Load Calculation

**Function:** `calculate_fresh_air_load()`

**Formula:**
```
Fresh Air Load = Fresh Air Volume × Air Density × Enthalpy Diff

Where:
Air Density ≈ 1.2 kg/m³ (at standard conditions)
Enthalpy Diff = Outdoor Enthalpy - Indoor Enthalpy (kJ/kg)
```

**Implementation:**
```python
def calculate_fresh_air_load(
    fresh_air_volume: float,    # m³/h
    enthalpy_diff: float,       # kJ/kg
    air_density: float = 1.2    # kg/m³
) -> float:
    """
    Calculate fresh air cooling load.
    
    Returns: load in W
    """
    # Convert m³/h to m³/s
    volume_flow = fresh_air_volume / 3600
    
    # Load (W) = Volume Flow (m³/s) × Density (kg/m³) × Enthalpy Diff (kJ/kg) × 1000
    load = volume_flow * air_density * enthalpy_diff * 1000
    
    return load
```

**Validation:**
```python
# Test: 2450 m³/h fresh air, 24.11 kJ/kg enthalpy diff
result = calculate_fresh_air_load(2450, 24.11)
assert abs(result - 19700) < 100  # W (approximately)
```

### 3.5 Step 5: Room Total Load

**Function:** `calculate_room_total_load()`

**Implementation:**
```python
def calculate_room_total_load(
    terminal_load: float,
    fresh_air_load: float,
    area: float
) -> Dict[str, float]:
    """
    Calculate room total cooling load.
    
    Returns: dict with total load and load density
    """
    total = terminal_load + fresh_air_load
    density = total / area if area > 0 else 0
    
    return {
        'total_load': total,
        'load_density': density  # W/m²
    }
```

### 3.6 Step 6: Load Aggregation

**Function:** `aggregate_loads()`

**Implementation:**
```python
def aggregate_loads(
    rooms: List[Dict],
    extra_loads: List[Dict]
) -> Dict:
    """
    Aggregate loads by floor, building, project.
    
    Returns: hierarchical load summary
    """
    # Initialize aggregation structure
    summary = {
        'by_water_tier': {},
        'by_building': {},
        'total': 0
    }
    
    # Aggregate room loads
    for room in rooms:
        tier = room['water_tier']
        building = room['building_id']
        load = room['total_load']
        
        # By water tier
        summary['by_water_tier'][tier] = \
            summary['by_water_tier'].get(tier, 0) + load
        
        # By building
        summary['by_building'][building] = \
            summary['by_building'].get(building, 0) + load
        
        # Total
        summary['total'] += load
    
    # Add extra loads
    for extra in extra_loads:
        summary['total'] += extra['load_value']
    
    return summary
```

## 4. Real-Time Preview

### 4.1 Design

```
User changes parameter
        │
        ▼
Frontend: Debounce (500ms)
        │
        ▼
API Call: POST /rooms/{id}/preview/
        │
        ▼
Redis Cache Check
        │ (cache miss)
        ▼
Execute Steps 1-5 (skip aggregation)
        │
        ▼
Cache result (TTL: 30s)
        │
        ▼
Return preview
```

### 4.2 Cache Strategy

```python
def get_preview(room_id: int, params_hash: str) -> Dict:
    """
    Get cached preview or calculate fresh.
    """
    cache_key = f"preview:{room_id}:{params_hash}"
    
    # Try cache first
    cached = redis.get(cache_key)
    if cached:
        return json.loads(cached)
    
    # Calculate fresh
    result = calculate_preview(room_id, params_hash)
    
    # Cache for 30 seconds
    redis.setex(cache_key, 30, json.dumps(result))
    
    return result
```

### 4.3 Performance Targets

| Scenario | Target | Strategy |
|----------|--------|----------|
| Single room preview | < 100ms | Redis cache |
| Cache miss | < 500ms | Lightweight calculation |
| 1000 rooms batch | < 10s | Parallel processing |

## 5. Batch Calculation

### 5.1 Async Processing

```python
@celery_app.task(bind=True)
def calculate_project_static(self, project_id: int):
    """
    Calculate static loads for entire project.
    """
    rooms = Room.objects.filter(
        floor__building__project_id=project_id
    )
    
    total = rooms.count()
    completed = 0
    
    for room in rooms:
        try:
            # Calculate for each room
            result = calculate_room_load(room)
            save_calculation_result(room, result)
            
            completed += 1
            # Update progress
            self.update_state(
                state='PROGRESS',
                meta={'completed': completed, 'total': total}
            )
            
        except Exception as e:
            # Log error, continue with next room
            log_calculation_error(room, e)
    
    # Send completion notification
    send_websocket_notification(project_id, 'calculation_complete')
```

## 7. Error Handling

### 7.1 Calculation Errors

| Error | Cause | Handling |
|-------|-------|----------|
| Invalid psychrometric state | Extreme temp/humidity | Use boundary values, warn user |
| Missing required field | Incomplete input | Return validation error |
| Division by zero | Zero area/volume | Use default, warn user |
| Overflow | Extreme values | Cap at maximum, warn user |

### 7.2 Error Response Format

```json
{
    "success": false,
    "error": {
        "code": "CALCULATION_ERROR",
        "message": "Invalid parameters for room calculation",
        "details": [
            {
                "field": "area",
                "message": "Area must be greater than 0",
                "value": -10
            }
        ],
        "room_id": 123
    }
}
```
