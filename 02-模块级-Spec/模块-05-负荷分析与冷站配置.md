## 1. 模块概述

### 1.1 功能职责

本模块实现冷负荷多维分析和冷站配置两大功能：

**负荷分析**：从功能区域/楼层/建筑/冷量种类/负荷构成五个维度展示冷负荷分布，帮助用户识别高负荷区域和优化空间。

**冷站配置**：系统自动汇总静态计算结果，用户手动配置冷机方案，系统进行基础校验，支持多方案对比与 P&ID 系统图生成。

**v0.5 范围说明（ADR-0005）：**
- 负荷分析按功能区域/楼层/建筑/冷量种类/负荷构成五个维度展开，不支持工序维度
- 冷站配置为半自动模式（系统汇总负荷 + 用户手动配置冷机 + 基础校验）
- 温度范围仅支持低温 7/12℃ 和中温 12/17℃ 两种
- **末端负荷按功能区域级冷冻水档分配**（ADR-0001，不再全归中温）
- **P&ID 系统图 SVG 自动生成 v0.5 做**；**水蓄冷容量配置 + 容量校验 v0.5 做，水蓄冷经济性（ROI）估算 v0.5 不做**

```python
class StationConfigLine(models.Model):
    """
    冷站配置行

    PRD 引用：F5-001 ~ F5-014
    Spec 引用：模块-05 Section 9.3.2
    """
    id = models.BigAutoField(primary_key=True)
    scheme = models.ForeignKey(
        'CoolingStationScheme',
        on_delete=models.CASCADE,
        related_name='config_lines'
    )
    water_temp_config = models.ForeignKey(
        'WaterTemperatureConfig',
        on_delete=models.CASCADE
    )
    load_category = models.CharField(
        max_length=50,
        choices=[
            ('FRESH_AIR', '新风负荷'),
            ('TERMINAL', '末端负荷'),
            ('PCW', 'PCW'),
            ('POWER_ROOM', '配电室空调'),
            ('FIRE_POOL', '消防池保温'),
            ('OTHER', '其他')
        ]
    )
    rated_load_kw = models.DecimalField(
        max_digits=12, decimal_places=2,
        help_text="额定负荷(kW)"
    )
    usage_coefficient = models.DecimalField(
        max_digits=5, decimal_places=4,
        default=1.0,
        help_text="取值系数"
    )
    chiller_name = models.CharField(
        max_length=100, blank=True,
        help_text="冷机名称"
    )
    single_capacity_rt = models.DecimalField(
        max_digits=10, decimal_places=2, null=True, blank=True,
        help_text="单机冷量(RT)"
    )
    chiller_count = models.IntegerField(
        null=True, blank=True,
        help_text="机组数量(台)"
    )
    design_notes = models.TextField(blank=True)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        db_table = 'station_config_line'
        ordering = ['scheme', 'water_temp_config', 'load_category']

    @property
    def usage_load_kw(self):
        """使用负荷(kW) = 额定负荷 × 取值系数"""
        return self.rated_load_kw * self.usage_coefficient

    @property
    def usage_load_rt(self):
        """使用负荷(RT) = 使用负荷(kW) / 3.517"""
        return self.usage_load_kw / 3.517

    @property
    def total_capacity_rt(self):
        """合计容量(RT) = 单机冷量(RT) × 机组数量(台)"""
        if self.single_capacity_rt and self.chiller_count:
            return self.single_capacity_rt * self.chiller_count
        return None
```

## 4. 业务逻辑

### 4.1 负荷汇总逻辑

```python
# 负荷汇总服务
def aggregate_load_by_water_temp(project_id):
    """
    按冷冻水温度汇总负荷

    PRD 引用：F5-001, F5-002, F5-003
    Spec 引用：模块-05 Section 9.3.1
    """
    # 1. 获取项目所有功能区域
    rooms = Room.objects.filter(floor__building__project_id=project_id)
    
    # 2. 按末端冷冻水档分组
    result = {}
    for room in rooms:
        water_config = room.terminal_water_config or default_medium_temp
        
        if water_config.id not in result:
            result[water_config.id] = {
                'terminal_load_kw': 0,
                'fresh_air_load_kw': 0,
                'total_load_kw': 0
            }
        
        # 3. 汇总末端负荷
        result[water_config.id]['terminal_load_kw'] += room.terminal_load_kw
        
        # 4. 汇总新风负荷
        fresh_air_config = room.fresh_air_water_config or water_config
        if fresh_air_config.id == water_config.id:
            result[water_config.id]['fresh_air_load_kw'] += room.fresh_air_load_kw
    
    # 5. 计算总计
    for config_id in result:
        result[config_id]['total_load_kw'] = (
            result[config_id]['terminal_load_kw'] +
            result[config_id]['fresh_air_load_kw']
        )
    
    return result
```

### 4.2 自动汇总逻辑（ADR-0001 修订）

```
1. 获取项目所有功能区域的静态计算结果

2. 按 water_temp_config_id 分组（低温 7/12℃ / 中温 12/17℃）

3. 每个温度范围内的汇总：
   - FRESH_AIR（新风负荷） = SUM(新风档==该档 的功能区域 fresh_air_load)
   - TERMINAL（末端负荷） = SUM(末端档==该档 的功能区域 terminal_load)
   - PCW = SUM(ExtraLoad 中 category='PCW' 的 load_value)
   - POWER_ROOM（配电室空调） = SUM(ExtraLoad 中 category='配电室空调' 的 load_value)
   - FIRE_POOL（消防池保温） = SUM(ExtraLoad 中 category='消防池保温' 的 load_value)
   - OTHER（其他） = SUM(ExtraLoad 中 category='其他' 的 load_value)

4. 生成配置表的左侧部分（只读）
```

```python
    PRD 引用：F5-025, F5-026
    Spec 引用：模块-05 Section 9.8
    """
    
    def generate_svg(self, scheme_id):
        """
        生成 P&ID SVG
        """
        # 1. 获取方案配置数据
        scheme = CoolingStationScheme.objects.get(id=scheme_id)
        config_lines = scheme.config_lines.all()
        water_storage = scheme.water_storage_configs.all()
        
        # 2. 使用模板渲染 SVG
        svg_template = self.load_template('pid_template.svg')
        
        # 3. 替换占位符
        svg_content = self.render_template(svg_template, {
            'chillers': self.extract_chillers(config_lines),
            'pumps': self.calculate_pumps(config_lines),
            'cooling_towers': self.calculate_cooling_towers(config_lines),
            'water_storage': water_storage
        })
        
        return svg_content
```

### 4.5 自动分析建议规则

```python
# 自动分析建议引擎
class SuggestionEngine:
    """
    自动分析建议引擎

    PRD 引用：F5-007, F7-021, F7-026
    Spec 引用：模块-05 Section 9.7
    """
    
    def generate_suggestions(self, project_id):
        """
        生成分析建议
        """
        suggestions = []
        
        # 1. 项目峰值 > 装机容量
        if self.check_peak_over_capacity(project_id):
            suggestions.append({
                'type': 'peak_over_capacity',
                'message': '全年峰值冷负荷超过装机容量 X RT，建议扩容或优化高负荷区域'
            })
        
        # 2. 某功能区域冷指标 > 500 W/m²
        high_load_rooms = self.check_high_load_rooms(project_id)
        for room in high_load_rooms:
            suggestions.append({
                'type': 'high_load_area',
                'message': f'功能区域【{room.room_name}】冷指标偏高，建议核查设备发热/新风量',
                'room_id': room.id
            })
        
        # 3. 全年 > 90% 时间负荷率 < 50%
        if self.check_low_load_ratio(project_id):
            suggestions.append({
                'type': 'low_load_ratio',
                'message': '装机容量偏大，全年低负荷运行时间长，建议减少台数或采用变频'
            })
        
        # 4. 单台长期低于 30% 负荷
        if self.check_single_low_load(project_id):
            suggestions.append({
                'type': 'single_low_load',
                'message': '存在单台长期低负荷运行，建议优化台数配置'
            })
        
        return suggestions
```

## 5. 校验规则

### 5.1 冷站配置校验（ADR-0004 修订）

| 编号 | 规则 | 校验逻辑 | 结果 |
|------|------|----------|------|
| V1 | 容量覆盖 | 合计容量(RT) ≥ 小计(RT) | 通过 / 失败：缺少 X RT |
| V2 | 单台故障冗余 | (合计容量 − 最大单台容量) ≥ 小计(RT) | 通过 / 警告：无冗余 |
| V3 | 运行容量占比合理 | (合计容量 − 最大单台容量) / 小计(RT) ∈ [100%, 130%] | 通过 / 警告：偏低或偏高 |
| V4 | 最小负荷率 | 小计(RT) / (机组数量 × 单机冷量) ≥ 10% | 通过 / 警告：低负荷喘振风险 |
| V5 | 蓄冷容量 | 如有蓄冷行，蓄冷容量 ≥ 设计蓄冷时长 × 蓄冷负荷 | 通过 / 失败：蓄冷不足 |

### 5.2 水蓄冷校验

| 规则 | 校验逻辑 | 错误信息 |
|------|----------|----------|
| 蓄冷容量 | storage_capacity_rt > 0 | "蓄冷容量必须大于0" |
| 设计时长 | design_duration_hours > 0 | "设计蓄冷时长必须大于0" |
| 蓄冷负荷 | storage_load_kw > 0 | "蓄冷负荷必须大于0" |
