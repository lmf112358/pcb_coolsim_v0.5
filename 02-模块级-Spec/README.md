## 模块职责

### 模块 01：账户与项目管理

- **职责**：用户认证、角色权限、项目 CRUD、四级层级结构
- **PRD 引用**：F1-001, F1-002, F1-003, F1-004
- **核心功能**：
  - JWT 认证与授权
  - 角色权限管理（HVAC 工程师、项目经理、管理员）
  - 项目 CRUD 操作
  - 四级层级结构（项目→建筑→楼层→功能区域）

### 模块 02：用户数据采集

- **职责**：建筑数据录入、功能区域数据录入、Excel 导入、数据校验
- **PRD 引用**：F2-001, F2-002, F2-003, F2-004
- **核心功能**：
  - 建筑数据表单录入
  - 功能区域数据表单录入
  - Excel 数据导入（10000+ 行 < 30 秒）
  - 数据校验与默认值处理

### 模块 03：2D 可视化标注

- **职责**：2D 编辑器、PDF 图纸导入、功能区域绘制、热力图可视化
- **PRD 引用**：F3-001, F3-002, F3-003, F3-004
- **核心功能**：
  - 2D 编辑器（Fabric.js）
  - PDF 图纸导入
  - 功能区域绘制与关联
  - 热力图可视化（100 功能区域 < 3 秒）

### 模块 04：静态冷量计算

- **职责**：静态冷量计算（6 步流水线）、实时预览、批量计算
- **PRD 引用**：F4-001, F4-002, F4-003
- **核心功能**：
  - 6 步计算流水线（焓值→末端负荷→风量→新风冷负荷→总负荷→聚合）
  - 实时计算预览（< 500ms）
  - 批量计算（1000 功能区域 < 30 秒）
  - 计算精度 < 0.1%

### 模块 05：负荷分析与冷站配置

- **职责**：负荷分布分析、冷站配置与校验、多方案对比
- **PRD 引用**：F5-001, F5-002, F5-003, F5-004
- **核心功能**：
  - 负荷分布分析（按功能区域/楼层/建筑）
  - 冷站手动配置（冷机类型/台数/容量）
  - 基础校验（N+1/容量/部分负荷率）
  - 多方案表格对比
  - P&ID 系统图生成

### 模块 06：动态仿真负荷计算

- **职责**：气象数据驱动仿真、比例系数法仿真、8760h 逐时计算
- **PRD 引用**：F6-001, F6-002, F6-003
- **核心功能**：
  - 方式一：气象数据驱动（8760h × 3 年）
  - 方式二：比例系数法
  - 8760h 逐时计算（1000+ 功能区域 < 30 秒）
  - 计算精度 < 1%

### 模块 07：8760 逐时结果可视化与基础验证

- **职责**：逐时负荷曲线展示、筛选聚合、负荷持续时间曲线、装机容量校核
- **PRD 引用**：F7-001, F7-002, F7-003, F7-004
- **核心功能**：
  - 逐时负荷曲线展示（约 26280 点/功能区域）
  - 年/月/日筛选聚合
  - 负荷持续时间曲线
  - 装机容量校核

### 模块 08：报告与数据导出

- **职责**：静态计算报告、冷站配置报告、设备清单、负荷计算书、仿真数据导出
- **PRD 引用**：F8-001, F8-002, F8-003, F8-004, F8-005
- **核心功能**：
  - 静态计算报告（PDF）
  - 冷站配置报告（PDF）
  - 设备清单（Excel）
  - 负荷计算书（Excel）
  - 仿真数据（CSV）

### 模块 09：系统设置与全局交互

- **职责**：系统参数配置、用户偏好设置、全局交互规范
- **PRD 引用**：F9-001, F9-002, F9-003
- **核心功能**：
  - 系统参数配置
  - 用户偏好设置
  - 全局交互规范

### 模块 10：负荷预测

- **职责**：未来 7×24 小时预测、天气数据自动获取、生产负荷率配置
- **PRD 引用**：F10-001, F10-002, F10-003, F10-004
- **核心功能**：
  - 未来 7×24 小时逐时预测
  - 天气数据自动获取（API 每小时更新）
  - 生产负荷率多段配置
  - 功能区域级粒度预测
