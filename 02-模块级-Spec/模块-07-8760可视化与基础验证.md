## 4. 业务逻辑

### 4.1 动态仿真触发流程

```
1. 用户点击"运行动态仿真"按钮
2. 系统检查：
   a. 该城市是否有近 3 年逐时气象数据
   b. 如缺失，提示用户先获取气象数据
3. 创建仿真批次记录（status='pending'）
4. 提交 Celery 异步任务
5. 返回批次 ID 给前端
6. 前端轮询任务状态

异步任务执行：
1. 更新状态为 'running'
2. 获取气象数据
3. 对每个功能区域：
   a. 计算末端负荷（复用静态计算结果）
   b. 计算逐时新风负荷
   c. 计算逐时总负荷
   d. 保存到 HourlyLoadResult
4. 更新进度（每处理 100 个功能区域更新一次）
5. 计算完成后：
   a. 生成极值统计
   b. 更新状态为 'completed'
   c. 发送 WebSocket 通知
```

### 4.2 逐时计算逻辑（气象数据驱动）

```python
# 气象数据驱动仿真计算
def calculate_hourly_load_weather_driven(batch_id, room_id):
    """
    气象数据驱动仿真计算

    PRD 引用：F6-001 ~ F6-007
    Spec 引用：模块-06 Section 10.2, 模块-07 Section 4.2
    """
    # 1. 获取功能区域参数
    room = Room.objects.get(id=room_id)
    
    # 2. 计算末端负荷（复用静态计算结果）
    terminal_load_kw = calculate_terminal_load(room)
    
    # 3. 获取气象数据（约 26280 条）
    weather_data = WeatherData.objects.filter(
        city=room.floor.building.project.city,
        year__in=[2024, 2025, 2026]
    ).order_by('timestamp')
    
    # 4. 批量计算逐时新风负荷
    indoor_enthalpy = calculate_enthalpy(
        room.indoor_calc_temp or 26,
        room.indoor_calc_humidity or 55,
        room.floor.building.project.city.pressure_summer
    )
    
    hourly_results = []
    for weather in weather_data:
        # 室外焓值
        outdoor_enthalpy = calculate_enthalpy(
            weather.dry_bulb_temp,
            weather.relative_humidity,
            weather.pressure
        )
        
        # 新风负荷
        fresh_air_load_kw = (
            AIR_DENSITY * room.fresh_air_volume * 
            (outdoor_enthalpy - indoor_enthalpy) / 3600
        )
        
        # 总负荷（负值截断为0）
        total_load_kw = max(0, terminal_load_kw + fresh_air_load_kw)
        
        hourly_results.append(HourlyLoadResult(
            batch_id=batch_id,
            room_id=room_id,
            timestamp=weather.timestamp,
            total_load_kw=total_load_kw,
            terminal_load_kw=terminal_load_kw,
            fresh_air_load_kw=fresh_air_load_kw,
            outdoor_temp=weather.dry_bulb_temp,
            outdoor_enthalpy=outdoor_enthalpy
        ))
    
    # 5. 批量保存
    HourlyLoadResult.objects.bulk_create(hourly_results)
```

### 4.4 降采样逻辑（LTTB 算法）

```python
# LTTB 降采样算法
def downsample_lttb(data_points, target_points):
    """
    Largest Triangle Three Buckets (LTTB) 降采样算法

    PRD 引用：F7-012, F7-014, F7-015
    Spec 引用：模块-07 Section 11.3
    """
    if len(data_points) <= target_points:
        return data_points
    
    # 1. 始终保留第一个和最后一个点
    sampled = [data_points[0]]
    
    # 2. 计算每个桶的大小
    bucket_size = (len(data_points) - 2) / (target_points - 2)
    
    # 3. 遍历每个桶
    for i in range(1, target_points - 1):
        # 计算当前桶的范围
        bucket_start = int((i - 1) * bucket_size) + 1
        bucket_end = int(i * bucket_size) + 1
        
        # 计算下一个桶的平均点
        next_bucket_start = int(i * bucket_size) + 1
        next_bucket_end = int((i + 1) * bucket_size) + 1
        next_avg_x = np.mean([p.timestamp for p in data_points[next_bucket_start:next_bucket_end]])
        next_avg_y = np.mean([p.total_load_kw for p in data_points[next_bucket_start:next_bucket_end]])
        
        # 在当前桶中选择面积最大的点
        max_area = -1
        selected_point = None
        
        for j in range(bucket_start, bucket_end):
            # 计算三角形面积
            area = abs(
                (sampled[-1].timestamp - next_avg_x) * 
                (data_points[j].total_load_kw - sampled[-1].total_load_kw) -
                (sampled[-1].timestamp - data_points[j].timestamp) * 
                (next_avg_y - sampled[-1].total_load_kw)
            ) / 2
            
            if area > max_area:
                max_area = area
                selected_point = data_points[j]
        
        sampled.append(selected_point)
    
    # 4. 保留最后一个点
    sampled.append(data_points[-1])
    
    return sampled
```

### 4.5 装机容量校验逻辑

```python
# 装机容量校验
def validate_installed_capacity(batch_id, project_id):
    """
    装机容量校验

    PRD 引用：F7-022, F7-023, F7-024, F7-025
    Spec 引用：模块-07 Section 11.5
    """
    # 1. 获取项目装机容量
    project = Project.objects.get(id=project_id)
    installed_capacity_kw = get_installed_capacity(project)
    
    # 2. 获取全年逐时数据
    hourly_data = HourlyLoadResult.objects.filter(
        batch_id=batch_id
    ).aggregate(
        max_load=Max('total_load_kw'),
        total_hours=Count('id')
    )
    
    # 3. V1: 装机容量充分性（F7-023）
    if hourly_data['max_load'] > installed_capacity_kw:
        return {
            'rule': 'F7-023',
            'status': 'failed',
            'message': '全年峰值超过装机容量',
            'details': {
                'annual_peak_kw': hourly_data['max_load'],
                'installed_capacity_kw': installed_capacity_kw
            }
        }
    
    # 4. V2: 装机容量经济性（F7-024）
    low_load_hours = HourlyLoadResult.objects.filter(
        batch_id=batch_id,
        total_load_kw__lt=installed_capacity_kw * 0.5
    ).count()
    
    if low_load_hours / hourly_data['total_hours'] > 0.9:
        return {
            'rule': 'F7-024',
            'status': 'warning',
            'message': '全年低负荷运行时间长',
            'details': {
                'low_load_hours_percentage': low_load_hours / hourly_data['total_hours']
            }
        }
    
    # 5. V3: 冷机台数匹配（F7-025）
    # ... 检查单台长期低于 30% 负荷 ...
    
    return {'rule': 'all', 'status': 'passed', 'message': '所有校验通过'}
```

## 6. 性能优化

### 6.1 大数据量图表渲染

**目标：** 约 26280 点首次渲染 < 3 秒

**优化方案：**
- 使用 ECharts LTTB 降采样策略
- 后端存储完整逐时数据，前端根据可视宽度动态降采样
- 降采样点数 2000~5000
- 缩放时重新降采样，保证细节可见
- 悬停时从完整数据中查询最近时间点的精确值

### 6.2 数据库查询优化

**优化方案：**
- 使用 TimescaleDB 超表，按时间列分块
- 建立复合索引：(batch_id, room_id, timestamp)
- 使用数据库聚合查询（GROUP BY）
- 缓存常用查询结果

### 6.3 计算性能优化

**优化方案：**
- 使用 NumPy 向量化计算
- 批量处理气象数据（避免逐条查询）
- 使用 Celery 异步任务
- 进度回调（WebSocket）
