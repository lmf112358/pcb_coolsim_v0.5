## 1. 功能概述

### 1.1 目的
对动态仿真产出的 8760 逐时（约 26280 点/功能区域，闰年 8784、平年 8760，随实际年份变化）冷量结果进行可视化与基础设计验证：逐时冷量曲线、年/月/日筛选聚合、负荷持续时间曲线，以及装机容量校核（峰值充分性 + 经济性）。

### 1.2 关键特性
- 逐时冷量曲线（约 26280 点），折线/面积图切换，静态参考线，年/月/日视图，平均/最大/最小聚合，静态 vs 动态对比，多区域叠加，悬停详情，区域缩放，图例控制，粒度切换（功能区域/楼层/建筑/项目）。
- 大数据量渲染：ECharts LTTB 降采样；首屏 < 3 秒；降采样点数 2000~5000；缩放重采样；悬停查精确值。
- 2D 热力图实时渲染（复用模块三平面图）：楼层平面图冷负荷密度蓝→红渐变，5 级分级图例，时间推进刷新 < 1 秒，参数联动，趋势自动标注。
- 基础设计验证：全年负荷持续时间曲线 + 装机容量线；峰值 ≤ 装机容量充分性校验；全年 > 90% 时间负荷率 < 50% 经济性校验；不通过红色警告 + 修改建议。
- 极值统计：功能区域/楼层/建筑/项目级最大/最小有意义/平均负荷及发生时刻，支持导出。
- 仿真数据归集与历史管理：逐时入库、批次 ID、历史回查、删除、基础统计（峰值/均值/最小/变化系数 CV）。

### 1.3 v0.5 范围说明（来自 PRD §11.1）
- 不实现：3D 建筑模型（推迟 v0.8）；逐区域温湿度达标率校验（需 RC 热模型，推迟 v0.6）；工序×冷量种类×8760h 三维交叉热力图（依赖工序维度）。
- v0.5 实现：完整 8760 逐时可视化 + 基础验证（负荷持续时间曲线 + 装机容量校核）。

## 2. 功能详述（按 PRD 小节展开）

### 2.1 §11.2 逐时冷量曲线（F7-001 ~ F7-011）
- 主图表（F7-001）：X 轴时间（约 26280 点），Y 轴冷量值 (kW)。
- 类型切换（F7-002）：折线图 / 面积图。
- 参考线（F7-003）：静态冷量标准值（取 `room_load_summary.total_load` 或 `load_summary` 静态合计）水平参考线。
- 时间筛选（F7-004）：年视图 / 月视图 / 日视图。
- 聚合切换（F7-005）：平均 / 最大 / 最小值（年/月视图下对每日或每小时聚合）。
- 静态 vs 动态对比（F7-006）：同图叠加静态标准值与动态逐时曲线。
- 多区域叠加（F7-007）：多选功能区域/楼层/建筑曲线叠加。
- 悬停（F7-008）：显示时间、冷量值、气象参数（温度/湿度，来自 weather 数据）。
- 区域缩放（F7-009）：拖拽选区放大，缩放后基于完整数据重降采样。
- 图例控制（F7-010）：点击图例显示/隐藏曲线。
- 粒度切换（F7-011）：下拉框切换查看粒度（功能区域/楼层/建筑/项目）。

### 2.2 §11.3 大数据量图表渲染（F7-012 ~ F7-016）
- 降采样（F7-012）：使用 ECharts LTTB 算法，保留波形极值特征。
- 性能（F7-013）：约 26280 点首次渲染 < 3 秒。
- 后端存储完整逐时数据，前端按可视宽度动态降采样至 2000~5000 点（F7-014）。
- 缩放重采样（F7-015）：保证细节可见。
- 精确值（F7-016）：悬停时从完整数据查询最近时间点精确值（非降采样点）。

### 2.3 §11.4 2D 热力图实时渲染（F7-017 ~ F7-021）
- 模式（F7-017）：复用模块三楼层平面图底图，功能区域以蓝→红连续渐变渲染冷负荷密度；图例可切换「连续渐变 / 5 级分级」。
- 5 级分级图例（F7-018）：<50 / 50-150 / 150-300 / 300-500 / >500 W/m²（冷指标口径 = total_load / area）。
- 时间推进刷新（F7-019）：热力图随逐时游标推进自动刷新 < 1 秒。
- 参数联动（F7-020）：选中区域实时显示冷负荷、温度、湿度等参数。
- 趋势标注（F7-021）：基于 §9.3 规则自动标注变化趋势。

### 2.4 §11.5 基础设计验证（F7-022 ~ F7-024、F7-026）
- 负荷持续时间曲线（F7-022）：全年负荷按降序排列的持续时间曲线，叠加装机容量水平标注线。
- 充分性校验（F7-023）：全年峰值 ≤ 装机容量 → 通过；否则不通过。
- 经济性校验（F7-024）：若全年 > 90% 时间负荷率（负荷/装机容量）< 50% → 提示装机偏大、不经济。
- 不通过处理（F7-026）：红色警告 + 修改建议（规则见 §9.3）。
- 装机容量来源：用户输入的项目/建筑级设计装机容量（建议字段待确认，详见 §6）。

### 2.5 §11.6 极值统计（F7-027 ~ F7-029）
- 维度（F7-027）：每个功能区域、楼层、建筑、整个项目各出一张极值统计表。
- 指标（F7-028）：最大负荷(kW)及发生时刻、最小有意义负荷(kW，>0)及发生时刻、平均负荷(kW)。最小有意义负荷取 Q > 0 的最小值（与模块六截断规则一致）。
- 导出（F7-029）：支持导出（CSV/Excel）。

### 2.6 §11.7 仿真数据归集与历史管理（F7-030 ~ F7-034）
- 入库（F7-030）：仿真数据自动写入数据库——功能区域逐时负荷、建筑逐时负荷、全厂逐时汇总。
- 批次（F7-031）：每次仿真生成唯一计算批次 ID（`batch_id`），结果按批次与项目绑定。
- 回查（F7-032）：历史仿真列表（批次 ID、运行时间、气象数据范围）可回查。
- 删除（F7-033）：支持删除历史仿真批次（级联删除该批次逐时数据）。
- 基础统计（F7-034）：各功能区域/各冷量种类的峰值/均值/最小值/变化系数 CV（CV = 标准差/均值）。

### 3.2 需扩展实体（待确认）
- **逐时仿真结果持久化表（simulation_run / simulation_result）**：PRD §11.7（F7-030）要求功能区域逐时负荷入库，但 §4 未定义对应表。模块六文本曾引用 `simulation_result`（逐时点：room_id, datetime, total_load 等）与 `simulation_summary`，但二者不在 §4 正式表清单内。待确认采用「新增 `simulation_run`（批次元数据）+ `simulation_result`（逐时点）」或并入 `load_summary` 的小时级扩展。若无此表，约 26280 点/区域的查询与降采样（F7-001~F7-016）将无法落地。
- **装机容量字段**：§11.5 充分性/经济性校验需项目或建筑级「设计装机容量」输入，§4 无对应字段，建议新增 `design_capacity` 于 project 或 building 表（待确认）。
