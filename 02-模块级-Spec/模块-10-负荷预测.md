## 1. 功能概述

模块十预测未来 7×24 小时（168 点）的冷负荷需求，帮助运营团队提前调整运行策略。
- 历史仿真回答「过去发生了什么」，负荷预测回答「未来会发生什么」。
- 基于未来天气预报 + 生产负荷率配置，使用**比例系数法**预测逐时冷负荷。
- API 模式每小时自动更新天气，预测结果持续刷新。

**v0.5 范围：**
- 天气数据：API 自动获取（每小时更新）+ 手动上传两种方式。
- 生产负荷率：多段配置（值 + 持续时长）。
- 比例系数：系统内置默认映射表 `coefficient_matrix`（ADR-0003），项目级可覆盖；v0.6 支持用户自定义。
- 预测粒度：功能区域级。
- 历史版本：保留每次预测结果，支持切换查看。

**依赖关系：**
- 依赖**静态设计负荷**（模块四 `room_load_result.total_load`，即 末端负荷 + 新风负荷）。
- 依赖**气象数据** `weather_data`（未来天气预报；表结构待 ADR-0006 补齐）。
- 与**模块六动态仿真**的关系：二者均使用逐时气象驱动范式，但预测基于「静态设计负荷 × 比例系数」，不重新做逐时焓值仿真；模块六的 `simulation_result` 数据结构（逐时 + 功能区域）可供预测结果表参考复用。

### 2.4 预测计算 — PRD §14.5 / F10-014~F10-017

| 需求 ID | 需求描述 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| F10-014 | 比例系数法：预测负荷 = 静态设计负荷(总) × 比例系数 K(T,R) | P0 | 计算正确 |
| F10-015 | 比例系数来源：系统内置统一映射表（ADR-0003），维度 室外温度×生产负荷率 | P0 | 映射正确 |
| F10-016 | 插值逻辑：非标准温度和负荷率使用线性插值 | P0 | 插值合理 |
| F10-017 | 计算粒度：每个功能区域单独计算，输出功能区域级逐时结果 | P0 | 功能区域级正确 |

**核心公式（PRD §15.8）：**
```
预测负荷 Q(t) = 静态设计负荷(总负荷) × K(T(t), R(t))
```
- `静态设计负荷` = 末端负荷 + 新风负荷（来自模块四 `room_load_result.total_load`）。
- `T(t)` = 时刻 t 室外温度（天气预报）。
- `R(t)` = 时刻 t 生产负荷率（多段配置定位）。
- `K(T, R)` = 比例系数，查 `coefficient_matrix`（ADR-0003），非标准值双线性插值。

**双线性插值示例（PRD §15.8）：** 室外 20℃、负荷率 60% → 温度落在 15~25℃ 行，负荷率 50%~80% 之间 → `K = 0.7 + (0.9 − 0.7) × (60% − 50%) / (80% − 50%) ≈ 0.767`。

```python
def forecast_load(static_design_load, outdoor_temp, production_rate, matrix):
    # 1. 定位温度区间行、负荷率列
    # 2. 双线性插值得到 K(T, R)
    k = bilinear_interpolate(matrix, outdoor_temp, production_rate)
    return static_design_load * k
```

### 2.6 历史版本保留策略 — PRD §14.7

- API 模式每小时自动更新产生一个版本；保留最近 7 天（168 个）自动版本 + 所有手动触发版本，更早的自动版本按天聚合保留每日最后一个。
- 每个版本为完整 168 点预测，存储于 `ForecastHourlyResult`（含 `fetched_at`）。

### 2.7 比例系数映射表 — PRD §14.8 / ADR-0003

系统内置统一映射表（动态仿真 §10 取「负荷率=100%」列，负荷预测使用全表）。项目级可覆盖，v0.6 支持用户自定义。

| 温度区间 | 负荷率 10% | 30% | 50% | 80% | 100% |
| --- | --- | --- | --- | --- | --- |
| < 5℃ | 0.3 | 0.4 | 0.5 | 0.7 | 0.8 |
| 5~15℃ | 0.4 | 0.5 | 0.6 | 0.8 | 0.9 |
| 15~25℃ | 0.5 | 0.6 | 0.7 | 0.9 | 1.0 |
| 25~35℃ | 0.7 | 0.8 | 0.9 | 1.0 | 1.1 |
| > 35℃ | 0.8 | 0.9 | 1.0 | 1.1 | 1.2 |

> 统一说明（ADR-0003）：合并原两套比例系数表，>35℃/100% 统一为 1.2。系数为系统默认初值，须暖通工程师校准确认。

### 4.2 定时任务（ADR-0002）

```python
# celery beat schedule
from celery.schedules import crontab
app.conf.beat_schedule = {
    'forecast-weather-hourly': {
        'task': 'tasks.update_forecast_weather',
        'schedule': crontab(minute=0),   # 每小时整点
    },
}
# tasks.update_forecast_weather: 仅对 status='active' 的场景重新拉取天气并触发重算
```
