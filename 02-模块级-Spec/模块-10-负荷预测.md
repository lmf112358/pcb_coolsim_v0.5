## 1. 模块概述

### 1.1 功能职责

本模块用于预测未来 7×24 小时的冷负荷需求，帮助运营团队提前调整冷站运行策略。

**核心价值：**
- 历史仿真回答"过去发生了什么"，负荷预测回答"未来会发生什么"
- 基于未来天气预报和生产负荷率配置，使用比例系数法预测逐时冷负荷
- 支持每小时自动更新天气数据，预测结果持续刷新

**v0.5 核心功能：**
- 预测场景管理（创建、删除、暂停/恢复、归档）
- 天气数据配置（API 自动获取 + 手动上传）
- 生产负荷率配置（多段配置）
- 预测计算（比例系数法）
- 预测结果展示（逐时曲线、统计信息、历史版本）
- 导出 CSV

**v0.5 范围：**
- 比例系数映射表：使用系统内置统一映射表（ADR-0003），项目级可覆盖，v0.6 支持用户自定义
- 预测粒度：功能区域级
- 预测周期：7×24 = 168 小时
- 历史版本：保留最近 7 天自动版本 + 所有手动版本，更早版本按天聚合保留每日最后一个

### 2.2 数据模型

**ForecastScenario 模型：**
```python
class ForecastScenario(models.Model):
    """
    预测场景

    PRD 引用：F10-001 ~ F10-004
    Spec 引用：模块-10 Section 2.2
    """
    STATUS_CHOICES = [
        ('active', '运行中'),
        ('paused', '已暂停'),
        ('archived', '已归档')
    ]

    WEATHER_SOURCE_CHOICES = [
        ('api', 'API 自动获取'),
        ('manual', '手动上传')
    ]

    id = models.BigAutoField(primary_key=True)
    project = models.ForeignKey(
        'Project',
        on_delete=models.CASCADE,
        related_name='forecast_scenarios'
    )
    name = models.CharField(
        max_length=100,
        help_text="场景名称"
    )
    status = models.CharField(
        max_length=20,
        choices=STATUS_CHOICES,
        default='active',
        help_text="场景状态"
    )
    weather_source = models.CharField(
        max_length=20,
        choices=WEATHER_SOURCE_CHOICES,
        default='api',
        help_text="天气数据来源"
    )
    start_date = models.DateField(help_text="预测开始日期")
    end_date = models.DateField(help_text="预测结束日期（默认 start_date + 7天）")
    last_calculated_at = models.DateTimeField(
        null=True,
        blank=True,
        help_text="最后计算时间"
    )
    created_by = models.ForeignKey(
        'User',
        on_delete=models.SET_NULL,
        null=True
    )
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        db_table = 'forecast_scenario'
        ordering = ['-created_at']
```

class ForecastHourlyResult(models.Model):

        max_digits=5,
        decimal_places=1,

        help_text="数据获取时间（用于版本区分）"
    )
    is_auto_version = models.BooleanField(
        default=True,
        help_text="是否为自动更新版本"

    class Meta:
        db_table = 'forecast_hourly_result'

### 4.1 预测计算流程

```python
# 预测计算引擎
class ForecastCalculator:
    """
    预测计算引擎

    PRD 引用：F10-014 ~ F10-017
    Spec 引用：模块-10 Section 4.1
    """

    def calculate_forecast(self, scenario_id, room_ids=None):
        """
        计算预测负荷
        """
        # 1. 获取场景信息
        scenario = ForecastScenario.objects.get(id=scenario_id)

        # 2. 获取天气数据
        weather_data = ForecastWeatherData.objects.filter(
            scenario=scenario
        ).order_by('timestamp')

        # 3. 获取生产负荷率配置
        production_rates = ForecastProductionRate.objects.filter(
            scenario=scenario
        ).order_by('sequence')

        # 4. 获取功能区域列表
        if room_ids:
            rooms = Room.objects.filter(id__in=room_ids)
        else:
            rooms = Room.objects.filter(
                floor__building__project=scenario.project
            )

        # 5. 获取每个功能区域的静态设计负荷
        design_loads = self._get_design_loads(rooms)

        # 6. 获取比例系数映射表
        coefficient_service = CoefficientService(scenario.project)
        coefficient_service.load_mapping()

        # 7. 逐时计算
        results = []
        for weather in weather_data:
            # 获取该时刻的生产负荷率
            prod_rate = self._get_production_rate(
                production_rates,
                weather.timestamp,
                scenario.start_date
            )

            # 计算比例系数
            coefficient = coefficient_service.get_coefficient(
                float(weather.outdoor_temp),
                float(prod_rate)
            )

            # 计算每个功能区域的预测负荷
            for room in rooms:
                design_load = design_loads[room.id]
                forecast_load = float(design_load) * coefficient

                results.append(ForecastHourlyResult(
                    scenario=scenario,
                    room=room,
                    timestamp=weather.timestamp,
                    outdoor_temp=weather.outdoor_temp,
                    production_rate=prod_rate,
                    coefficient=coefficient,
                    design_load=design_load,
                    forecast_load=forecast_load,
                    fetched_at=timezone.now(),
                    is_auto_version=True
                ))

        # 8. 批量保存结果
        ForecastHourlyResult.objects.bulk_create(results)

        # 9. 更新场景最后计算时间
        scenario.last_calculated_at = timezone.now()
        scenario.save()

        return len(results)

    def _get_production_rate(self, production_rates, timestamp, start_date):
        """获取指定时刻的生产负荷率"""
        # 计算相对于开始日期的小时数
        hours_from_start = (timestamp.date() - start_date).days * 24 + timestamp.hour

        for rate in production_rates:
            if rate.start_hour <= hours_from_start < rate.end_hour:
                return rate.production_rate

        return production_rates.last().production_rate  # 默认返回最后一段

    def _get_design_loads(self, rooms):
        """获取功能区域的静态设计负荷"""
        # 从静态计算结果中获取
        loads = {}
        for room in rooms:
            result = StaticCalculationResult.objects.filter(
                room=room
            ).order_by('-calculated_at').first()

            if result:
                loads[room.id] = result.total_load_kw
            else:
                loads[room.id] = 0

        return loads
```

### 4.2 比例系数服务

```python
# 比例系数服务
class CoefficientService:
    """
    比例系数服务

    PRD 引用：F10-014 ~ F10-016
    Spec 引用：模块-10 Section 4.2

    参考：ADR-0003 统一比例系数映射表
    """

    # 系统默认映射表（ADR-0003）
    DEFAULT_MAPPING = {
        (float('-inf'), 5): {
            10: 0.3, 30: 0.4, 50: 0.5, 80: 0.7, 100: 0.8
        },
        (5, 15): {
            10: 0.4, 30: 0.5, 50: 0.6, 80: 0.8, 100: 0.9
        },
        (15, 25): {
            10: 0.5, 30: 0.6, 50: 0.7, 80: 0.9, 100: 1.0
        },
        (25, 35): {
            10: 0.7, 30: 0.8, 50: 0.9, 80: 1.0, 100: 1.1
        },
        (35, float('inf')): {
            10: 0.8, 30: 0.9, 50: 1.0, 80: 1.1, 100: 1.2
        }
    }

    def __init__(self, project=None):
        self.project = project
        self.mapping = self.DEFAULT_MAPPING.copy()

    def load_mapping(self):
        """加载映射表（优先使用项目级覆盖）"""
        if self.project:
            # 尝试加载项目级覆盖
            project_mappings = CoefficientMapping.objects.filter(
                project=self.project
            )

            if project_mappings.exists():
                self.mapping = {}
                for m in project_mappings:
                    key = (float(m.temp_min), float(m.temp_max))
                    if key not in self.mapping:
                        self.mapping[key] = {}
                    self.mapping[key][int(m.production_rate)] = float(m.coefficient)

    def get_coefficient(self, outdoor_temp, production_rate):
        """
        获取比例系数（支持双线性插值）

        Args:
            outdoor_temp: 室外温度（°C）
            production_rate: 生产负荷率（10-100）

        Returns:
            比例系数 K(T,R)
        """
        # 1. 查找温度区间
        temp_interval = self._find_temp_interval(outdoor_temp)

        # 2. 获取该区间的系数映射
        rate_coefficients = self.mapping.get(temp_interval, {})

        if not rate_coefficients:
            return 1.0  # 默认返回 1.0

        # 3. 查找负荷率区间并插值
        coefficient = self._interpolate_by_rate(
            rate_coefficients,
            production_rate
        )

        return coefficient

    def _find_temp_interval(self, temp):
        """查找温度所在的区间"""
        for interval in self.mapping.keys():
            min_temp, max_temp = interval
            if min_temp <= temp < max_temp:
                return interval

        # 边界处理
        if temp < 5:
            return (float('-inf'), 5)
        else:
            return (35, float('inf'))

    def _interpolate_by_rate(self, rate_coefficients, target_rate):
        """
        按负荷率线性插值

        Args:
            rate_coefficients: 负荷率 -> 系数 的映射
            target_rate: 目标负荷率

        Returns:
            插值后的系数
        """
        sorted_rates = sorted(rate_coefficients.keys())

        # 精确匹配
        if target_rate in rate_coefficients:
            return rate_coefficients[target_rate]

        # 边界处理
        if target_rate <= sorted_rates[0]:
            return rate_coefficients[sorted_rates[0]]
        if target_rate >= sorted_rates[-1]:
            return rate_coefficients[sorted_rates[-1]]

        # 线性插值
        for i in range(len(sorted_rates) - 1):
            r1 = sorted_rates[i]
            r2 = sorted_rates[i + 1]

            if r1 <= target_rate <= r2:
                c1 = rate_coefficients[r1]
                c2 = rate_coefficients[r2]

                # 线性插值公式
                ratio = (target_rate - r1) / (r2 - r1)
                return c1 + (c2 - c1) * ratio

        return 1.0
```

### 4.3 历史版本管理

```python
# 历史版本管理
class VersionManager:
    """
    历史版本管理服务

    PRD 引用：F10-020
    Spec 引用：模块-10 Section 4.3

    保留策略：
    - 最近 7 天自动版本：全部保留
    - 超过 7 天自动版本：按天聚合，保留每日最后一个
    - 手动版本：全部保留
    """

    def cleanup_old_versions(self, scenario):
        """
        清理旧版本

        Args:
            scenario: 预测场景
        """
        # 1. 计算 7 天前的时间
        seven_days_ago = timezone.now() - timedelta(days=7)

        # 2. 查找需要聚合的自动版本
        old_auto_versions = ForecastHourlyResult.objects.filter(
            scenario=scenario,
            is_auto_version=True,
            fetched_at__lt=seven_days_ago
        ).values('fetched_at__date').distinct()

        # 3. 按天聚合，保留每日最后一个版本
        for date_entry in old_auto_versions:
            date = date_entry['fetched_at__date']

            # 获取该日期的所有版本时间
            versions = ForecastHourlyResult.objects.filter(
                scenario=scenario,
                is_auto_version=True,
                fetched_at__date=date
            ).values('fetched_at').distinct().order_by('-fetched_at')

            if versions.count() > 1:
                # 保留最后一个版本，删除其他版本
                keep_version = versions[0]['fetched_at']
                delete_versions = versions[1:]

                for v in delete_versions:
                    ForecastHourlyResult.objects.filter(
                        scenario=scenario,
                        is_auto_version=True,
                        fetched_at=v['fetched_at']
                    ).delete()

    def get_version_list(self, scenario):
        """
        获取版本列表

        Args:
            scenario: 预测场景

        Returns:
            版本列表，按时间倒序
        """
        versions = ForecastHourlyResult.objects.filter(
            scenario=scenario
        ).values(
            'fetched_at', 'is_auto_version'
        ).annotate(
            record_count=Count('id')
        ).order_by('-fetched_at')

        return versions
```

def update_forecast_weather():
    """
    自动更新天气数据

    PRD 引用：F10-006
    Spec 引用：模块-10 Section 4.4

    调度：Celery beat，每小时整点执行
    """
    # 1. 查找所有 active 状态的 API 模式场景
    active_scenarios = ForecastScenario.objects.filter(
        status='active',
        weather_source='api'
    )

    for scenario in active_scenarios:
        try:
            # 2. 调用气象 API 获取未来 7 天预报数据
            weather_service = WeatherFetcher()
            weather_data = weather_service.fetch_forecast(
                scenario.project.city,
                days=7
            )

            # 3. 更新天气数据
            ForecastWeatherData.objects.filter(
                scenario=scenario
            ).delete()

            ForecastWeatherData.objects.bulk_create([
                ForecastWeatherData(
                    scenario=scenario,
                    timestamp=data['timestamp'],
                    outdoor_temp=data['temp'],
                    outdoor_humidity=data['humidity'],
                    fetched_at=timezone.now(),
                    is_interpolated=False
                )
                for data in weather_data
            ])

            # 4. 自动触发重新计算
            calculate_forecast.delay(scenario.id)

            # 5. 记录日志
            logger.info(f"场景 {scenario.id} 天气数据更新成功")

        except Exception as e:
            logger.error(f"场景 {scenario.id} 天气数据更新失败: {e}")

## 6. 性能优化

### 6.1 预测计算优化

**目标：** 单功能区域预测计算 < 1 秒，100 功能区域 < 60 秒

**优化方案：**
- 批量获取设计负荷（避免 N+1 查询）
- 预加载比例系数映射表到内存
- 使用 `bulk_create` 批量保存结果
- 异步计算（Celery）

### 6.2 结果查询优化

**优化方案：**
- 复合索引：`(scenario_id, room_id, fetched_at, timestamp)`
- 使用物化视图或缓存统计信息
- 分页查询（避免一次加载 168×N 条记录）

### 6.3 历史版本优化

**优化方案：**
- 定期执行版本聚合（Celery beat，每天凌晨）
- 使用 `DELETE ... WHERE ...` 批量删除旧版本
- 监控存储空间，设置告警阈值
