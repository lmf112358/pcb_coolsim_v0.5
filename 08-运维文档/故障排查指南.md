## 1. Development Environment Issues

### 1.1 Backend Won't Start

**Symptom:**
```
Error: ModuleNotFoundError: No module named 'django'
```

**Solution:**
```bash
# Activate virtual environment
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# Install dependencies
pip install -r requirements.txt
```

**Symptom:**
```
Error: psycopg2.OperationalError: could not connect to server
```

**Solution:**
```bash
# Check PostgreSQL is running
sudo systemctl status postgresql

# Start PostgreSQL
sudo systemctl start postgresql

# Verify database exists
psql -U postgres -l

# Create database if needed
createdb coolsim
```

**Symptom:**
```
Error: redis.exceptions.ConnectionError: Error connecting to Redis
```

**Solution:**
```bash
# Check Redis is running
redis-cli ping

# Start Redis
redis-server

# Verify connection
redis-cli
127.0.0.1:6379> ping
PONG
```

### 1.2 Frontend Won't Start

**Symptom:**
```
Error: EACCES permission denied
```

**Solution:**
```bash
# Clear npm cache
npm cache clean --force

# Remove node_modules and reinstall
rm -rf node_modules package-lock.json
npm install
```

**Symptom:**
```
Error: ENOSPC: System limit for number of file watchers reached
```

**Solution (Linux):**
```bash
# Increase file watcher limit
echo fs.inotify.max_user_watches=524288 | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
```

**Symptom:**
```
TypeScript error: Module not found
```

**Solution:**
```bash
# Regenerate types
npm run generate-types

# Restart TypeScript server in VS Code
# Ctrl+Shift+P → TypeScript: Restart TS Server
```

### 1.3 Docker Issues

**Symptom:**
```
Error: ERROR: for backend Cannot start service backend
```

**Solution:**
```bash
# Check Docker logs
docker-compose logs backend

# Rebuild containers
docker-compose build --no-cache backend

# Remove old containers and rebuild
docker-compose down
docker-compose up -d --build
```

**Symptom:**
```
Error: port is already allocated
```

**Solution:**
```bash
# Find process using port
lsof -i :8000

# Kill process or change port in docker-compose.yml
ports:
  - "8001:8000"
```

## 2. Database Issues

### 2.1 Connection Problems

**Symptom:**
```
FATAL: too many connections for role
```

**Solution:**
```sql
-- Check current connections
SELECT count(*) FROM pg_stat_activity;

-- Terminate idle connections
SELECT pg_terminate_backend(pid)
FROM pg_stat_activity
WHERE state = 'idle' AND query_start < now() - interval '10 minutes';

-- Increase max connections in postgresql.conf
-- max_connections = 200
```

### 2.2 Migration Issues

**Symptom:**
```
Error: django.db.migrations.exceptions.InconsistentMigrationHistory
```

**Solution:**
```bash
# Check migration status
python manage.py showmigrations

# Fake apply problematic migration
python manage.py migrate app_name 0002 --fake

# Or reset migrations (development only!)
python manage.py migrate app_name zero
python manage.py migrate app_name
```

**Symptom:**
```
Error: relation "table_name" does not exist
```

**Solution:**
```bash
# Run migrations
python manage.py migrate

# If table should exist, check migration order
python manage.py showmigrations
```

### 2.3 Performance Issues

**Symptom:**
Slow query execution

**Solution:**
```sql
-- Check for slow queries
SELECT pid, now() - pg_stat_activity.query_start AS duration, query
FROM pg_stat_activity
WHERE (now() - pg_stat_activity.query_start) > interval '5 minutes';

-- Analyze query
EXPLAIN ANALYZE SELECT * FROM rooms WHERE floor_id = 123;

-- Add missing indexes
CREATE INDEX idx_rooms_floor_id ON rooms(floor_id);
```

## 3. Calculation Issues

### 3.1 Calculation Errors

**Symptom:**
```
CalculationError: Invalid input: negative area value
```

**Solution:**
```python
# Validate inputs before calculation
def validate_room_input(room):
    if room.area <= 0:
        raise ValueError(f"Area must be positive, got {room.area}")
    if room.height <= 0:
        raise ValueError(f"Height must be positive, got {room.height}")
```

**Symptom:**
```
PsychrometricError: Enthalpy calculation failed
```

**Solution:**
```python
# Check input ranges
# Temperature: -50°C to 60°C
# Humidity: 0% to 100%

def validate_psychrometric_inputs(temp, humidity):
    if not -50 <= temp <= 60:
        raise ValueError(f"Temperature {temp}°C out of range")
    if not 0 <= humidity <= 100:
        raise ValueError(f"Humidity {humidity}% out of range")
```

### 3.2 Numerical Issues

**Symptom:**
```
Calculation produces NaN or Infinity
```

**Solution:**
```python
import numpy as np

def safe_divide(numerator, denominator):
    """Safe division with NaN handling."""
    result = np.where(denominator != 0, numerator / denominator, 0)
    return result

# Check for NaN in results
if np.isnan(result).any():
    raise CalculationError("NaN detected in calculation")
```

**Symptom:**
Floating point precision errors

**Solution:**
```python
from decimal import Decimal, ROUND_HALF_UP

# Use Decimal for financial calculations
area = Decimal('100.50').quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)

# Round final results
result = round(calculated_value, 2)
```

### 3.3 Celery Task Issues

**Symptom:**
```
Celery task timeout
```

**Solution:**
```python
# Increase task timeout
@app.task(time_limit=600, soft_time_limit=300)
def long_running_task():
    pass

# Or split into smaller tasks
@app.task
def process_batch(batch):
    pass

# Process in batches
for batch in chunks(data, 100):
    process_batch.delay(batch)
```

**Symptom:**
```
Worker lost - connection refused
```

**Solution:**
```bash
# Check Redis connection
redis-cli ping

# Restart Celery workers
celery -A config worker -l info --purge

# Check worker status
celery -A config status
```

**Solution:**

```typescript
// Check token expiration
const token = localStorage.getItem('access_token');
```

### 4.2 State Management

**Symptom:**
```
React state not updating
```

**Solution:**
```typescript
// Use functional updates
setCount(prevCount => prevCount + 1);

// Ensure proper dependency array in useEffect
useEffect(() => {
  fetchData();
}, [dependency]); // Add dependency here
```

**Symptom:**
```
Memory leak warning
```

**Solution:**
```typescript
useEffect(() => {
  const controller = new AbortController();

  fetch('/api/data', { signal: controller.signal })
    .then(response => response.json())
    .then(data => setData(data));

  return () => {
    controller.abort(); // Cleanup on unmount
  };
}, []);
```

## 5. Production Issues

### 5.1 Application Performance

**Symptom:**
High response latency

**Solution:**
```bash
# Check slow queries
python manage.py dbshell
SELECT * FROM pg_stat_statements ORDER BY mean_time DESC LIMIT 10;

# Add caching
from django.core.cache import cache

def get_data(key):
    data = cache.get(key)
    if data is None:
        data = expensive_query()
        cache.set(key, data, timeout=300)
    return data
```

**Symptom:**
High memory usage

**Solution:**
```bash
# Check for memory leaks
ps aux | grep python

# Monitor memory usage
top -p <PID>

# Restart workers periodically
celery -A config worker --max-tasks-per-child=1000
```

### 5.2 Database Performance

**Symptom:**
Database slow or unresponsive

**Solution:**
```sql
-- Check for locks
SELECT * FROM pg_locks WHERE NOT granted;

-- Terminate blocking queries
SELECT pg_terminate_backend(pid)
FROM pg_stat_activity
WHERE state = 'active' AND query_start < now() - interval '1 hour';

-- Vacuum and analyze
VACUUM ANALYZE;
```

### 5.3 Celery Issues

**Symptom:**
Tasks stuck in queue

**Solution:**
```bash
# Check queue depth
celery -A config inspect active_queues

# Purge queue (careful!)
celery -A config purge

# Restart workers
celery -A config worker -l info --purge
```

## 6. Common Error Messages

### 6.1 Backend Errors

| Error | Cause | Solution |
|-------|-------|----------|
| `IntegrityError` | Duplicate key or constraint violation | Check unique constraints, use `get_or_create()` |
| `OperationalError` | Database connection issue | Check database status, connection pool |
| `ValidationError` | Invalid data | Check input validation, serializer rules |
| `PermissionDenied` | Missing permissions | Check user roles, object permissions |
| `ObjectDoesNotExist` | Missing object | Check object exists before access |

### 6.2 Frontend Errors

| Error | Cause | Solution |
|-------|-------|----------|
| `Network Error` | API unavailable | Check backend status, CORS settings |
| `401 Unauthorized` | Token expired | Refresh token, re-authenticate |
| `403 Forbidden` | Insufficient permissions | Check user role and permissions |
| `404 Not Found` | Resource doesn't exist | Verify URL, check if object exists |
| `500 Server Error` | Backend error | Check backend logs |

### 9.2 Caching Strategy

```python
from django.core.cache import cache

# Cache expensive calculations
def get_calculation_result(room_id):
    cache_key = f'calc_{room_id}'
    result = cache.get(cache_key)

    if result is None:
        result = expensive_calculation(room_id)
        cache.set(cache_key, result, timeout=300)  # 5 minutes

    return result

# Invalidate cache on update
def update_room(room_id, data):
    room = Room.objects.get(id=room_id)
    # Update room
    cache.delete(f'calc_{room_id}')
```
