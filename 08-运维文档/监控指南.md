## 5. Distributed Tracing

### 5.1 Jaeger Integration

```python
# tracing.py - Django middleware for tracing
from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor
from opentelemetry.exporter.jaeger.thrift import JaegerExporter

def setup_tracing():
    """Configure distributed tracing."""
    trace.set_tracer_provider(TracerProvider())

    jaeger_exporter = JaegerExporter(
        agent_host_name="jaeger",
        agent_port=6831,
    )

    trace.get_tracer_provider().add_span_processor(
        BatchSpanProcessor(jaeger_exporter)
    )
```

### 5.2 Trace Context Propagation

```python
# views.py - Example traced endpoint
from opentelemetry import trace

tracer = trace.get_tracer(__name__)

@tracer.start_as_current_span("calculate_static_load")
def calculate_static_load(request, project_id):
    """Calculate static load with distributed tracing."""
    with tracer.start_as_current_span("fetch_project"):
        project = get_project(project_id)

    with tracer.start_as_current_span("fetch_rooms"):
        rooms = get_rooms(project)

    with tracer.start_as_current_span("calculate"):
        result = perform_calculation(rooms)

    return result
```

## 6. Alerting

### 6.1 Alert Rules

```yaml
# alerting-rules.yml
groups:
  - name: coolsim-alerts
    rules:
      # High error rate
      - alert: HighErrorRate
        expr: rate(http_requests_total{status=~"5.."}[5m]) / rate(http_requests_total[5m]) > 0.05
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "High error rate detected"
          description: "Error rate is {{ $value | humanizePercentage }}"

      # High latency
      - alert: HighLatency
        expr: histogram_quantile(0.95, rate(http_request_duration_seconds_bucket[5m])) > 2
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High latency detected"
          description: "p95 latency is {{ $value }}s"

      # Celery queue backup
      - alert: CeleryQueueBackup
        expr: celery_queue_depth{queue_name="default"} > 100
        for: 10m
        labels:
          severity: warning
        annotations:
          summary: "Celery queue backup"
          description: "Queue depth is {{ $value }}"

      # Database connection issues
      - alert: DatabaseConnectionIssues
        expr: pg_stat_activity_count > 80
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High database connections"
          description: "{{ $value }} active connections"

      # High memory usage
      - alert: HighMemoryUsage
        expr: (node_memory_MemTotal_bytes - node_memory_MemAvailable_bytes) / node_memory_MemTotal_bytes > 0.9
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High memory usage"
          description: "Memory usage is {{ $value | humanizePercentage }}"

      # High CPU usage
      - alert: HighCpuUsage
        expr: rate(node_cpu_seconds_total{mode="idle"}[5m]) < 0.1
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High CPU usage"
          description: "CPU idle is {{ $value | humanizePercentage }}"
```

## 7. Health Checks

### 7.1 Health Endpoints

```python
# health/views.py
from django.http import JsonResponse
from django.db import connection
import redis
import psutil

def health_check(request):
    """Basic health check."""
    return JsonResponse({
        'status': 'healthy',
        'timestamp': timezone.now().isoformat()
    })

def readiness_check(request):
    """Readiness check with dependencies."""
    checks = {}

    # Database
    try:
        with connection.cursor() as cursor:
            cursor.execute("SELECT 1")
        checks['database'] = {'status': 'ok'}
    except Exception as e:
        checks['database'] = {'status': 'error', 'message': str(e)}

    # Redis
    try:
        r = redis.from_url(settings.REDIS_URL)
        r.ping()
        checks['redis'] = {'status': 'ok'}
    except Exception as e:
        checks['redis'] = {'status': 'error', 'message': str(e)}

    # System resources
    checks['memory'] = {
        'status': 'ok' if psutil.virtual_memory().percent < 90 else 'warning',
        'usage_percent': psutil.virtual_memory().percent
    }

    status = 'ready' if all(c['status'] in ['ok'] for c in checks.values()) else 'not_ready'
    return JsonResponse({'status': status, 'checks': checks})

def liveness_check(request):
    """Liveness check."""
    return JsonResponse({'status': 'alive'})
```

## 9. On-Call Runbook

### 9.1 Common Issues

#### High Error Rate
1. Check Grafana dashboard for error patterns
2. Review recent deployments
3. Check external service status (weather API, etc.)
4. Review application logs for error details
5. Rollback if needed

#### High Latency
1. Check database query performance
2. Review slow request traces
3. Check Celery queue depth
4. Review system resources (CPU, memory)
5. Scale services if needed

#### Database Issues
1. Check PostgreSQL logs
2. Review connection pool usage
3. Check for long-running queries
4. Review replication lag (if applicable)
5. Restart database if needed (with caution)

### 9.2 Escalation Path

| Severity | Initial Response | Escalation |
|----------|-----------------|------------|
| Critical | On-call engineer | Tech lead → CTO |
| Warning | On-call engineer | Team lead |
| Info | Team review | - |
