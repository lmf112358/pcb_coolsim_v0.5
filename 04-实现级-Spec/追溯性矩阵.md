- 本矩阵覆盖 PRD 正文全部 F*/SAC* 功能需求（共 310 条）。附录 H「用户故事索引」为 53 条用户故事（P0:46 / P1:6 / P2:1），二者视角不同：需求 ID 是逐条可验证的功能点，用户故事是场景化集合。
