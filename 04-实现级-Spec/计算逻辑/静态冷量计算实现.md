## 1. 文档概述

### 1.1 目的

本文档定义PCB冷量仿真系统的核心计算逻辑，包括计算流水线、各步骤公式、输入输出字段映射，以及公式可替换架构建议。与《数据库设计文档》配套使用——数据库设计定义"数据结构"（有什么表、什么字段），本规范定义"数据如何计算出来"（每个 `[CALC]` 和 `[RESULT]` 字段的值怎么算）。

### 1.2 适用范围

本规范覆盖 Phase 1（静态设计负荷计算）的全部计算步骤，并对 Phase 2（动态仿真）的扩展预留接口。当前为初版，部分公式尚未确认，以占位方式标注，待后续确认后填入。

### 1.3 确定性等级定义

| 等级 | 标记 | 含义 |
|------|------|------|
| 已确认 | ✅ | 公式来源明确，经Excel验证或文档确认，可直接实现 |
| 部分确认 | ⚠️ | 公式框架已有，但部分参数或方法待确认，可实现框架 + 占位 |
| 待确认 | ❓ | 公式框架未定，代码中留接口占位，待后续补充 |

### 1.4 与数据库设计文档的关系

本规范中所有输入输出字段均引用《数据库设计文档》中的表名和字段名。计算步骤的输出直接对应数据库中 `[CALC]` 和 `[RESULT]` 类型字段的值。对于计算所需但数据库中暂无对应的参数，在第4节"待确认问题清单"中列出并给出处理建议。

### 2.2 计算步骤依赖关系

Step 1（焓值）与 Step 2（末端负荷）之间无依赖，可并行计算。Step 3（风量）依赖 Step 1 的焓值结果（用于消除负荷风量计算）和 Step 2 的末端负荷结果。Step 4（新风冷负荷）依赖 Step 1 和 Step 3。Step 5 依赖 Step 2 和 Step 4。Step 6 依赖 Step 5 及 extra_load 表。

### 2.3 数据组织维度

所有计算结果按 `room_id × season_id` 维度组织。Step 4 及之后额外按 `water_temp_config_id` 维度展开（同一房间在中温水和低温水配置下各有一条记录）。最终聚合按 `floor → building → project` 逐级汇总。

## 3. 计算步骤详细说明

### 3.1 Step 1: 焓值计算

**确定性：✅ 焓值计算方法已确认（使用标准库），部分边界场景待确认（见4.1、4.11）**

#### 3.1.0 焓值计算总则

**焓值与国标参数的关系：**

焓值（kJ/kg）是湿空气的热力学状态参数，由干球温度、含湿量（或相对湿度）和大气压力共同确定。国标《工业室外空气计算参数》提供的是**输入参数**（干球温度、湿球温度、相对湿度、大气压力等），而非焓值本身。焓值是**推导值**——从国标输入参数出发，通过热力学公式计算得到。因此数据库中不预存焓值，而是在计算时实时调用焓值计算函数。

**计算库推荐：psychrolib**

推荐使用 Python 开源库 [psychrolib](https://github.com/psychrometrics/psychrolib)，该库实现了 ASHRAE Handbook of Fundamentals 中的标准湿空气热力学计算，包括饱和蒸汽压、含湿量、焓值、湿球温度转换等全部公式，无需手动实现公式链。库内部已封装饱和蒸汽压公式的选择（Hyland-Wexler公式），4.1节中的"使用哪套饱和蒸汽压公式"问题由此解决。

安装与使用示例：

```python
import psychrolib

# 设置SI单位制（温度℃、压力Pa、焓kJ/kg）
psychrolib.SetUnitSystem(psychrolib.SI)

def calculate_enthalpy(temp_dry, humidity_or_wet_bulb, pressure_hpa, 
                       input_type='rh'):
    """
    通用焓值计算函数（室内外共用）

    参数:
        temp_dry: 干球温度(℃)
        humidity_or_wet_bulb: 相对湿度(%)或湿球温度(℃)，由input_type决定
        pressure_hpa: 大气压力(hPa)
        input_type: 'rh' = 相对湿度, 'wb' = 湿球温度

    返回:
        焓值(kJ/kg)
    """
    pressure_pa = pressure_hpa * 100  # hPa → Pa

    if input_type == 'rh':
        # 室内焓值：干球温度 + 相对湿度
        return psychrolib.GetMoistAirEnthalpy(
            temp_dry,
            psychrolib.GetHumRatioFromRelHum(temp_dry, humidity_or_wet_bulb, pressure_pa),
            pressure_pa
        )
    elif input_type == 'wb':
        # 室外焓值：干球温度 + 湿球温度（库内部自动转换为含湿量）
        hum_ratio = psychrolib.GetHumRatioFromTWetBulb(
            temp_dry, humidity_or_wet_bulb, pressure_pa
        )
        return psychrolib.GetMoistAirEnthalpy(temp_dry, hum_ratio, pressure_pa)
```

**Phase 1 / Phase 2 复用说明：**

Phase 1（静态设计负荷）和 Phase 2（动态仿真）使用**完全相同的焓值计算公式**，区别仅在于输入参数的来源不同。封装为通用函数后，室内外、设计工况与逐时工况均可复用：

| 计算场景 | 干球温度来源 | 湿度参数来源 | input_type | 大气压力来源 |
|---|---|---|---|---|
| Phase 1 室内焓值 | room.indoor_calc_temp | room.indoor_calc_humidity | 'rh' | city_config.pressure_summer |
| Phase 1 室外焓值 | city_config.temp_dry_ac_summer | city_config.temp_wet_ac_summer | 'wb' | city_config.pressure_summer |
| Phase 2 室内焓值 | room.indoor_calc_temp（全年恒定） | room.indoor_calc_humidity（全年恒定） | 'rh' | weather_hourly.pressure |
| Phase 2 室外焓值 | weather_hourly.temp_dry | weather_hourly.temp_wet（或humidity） | 'wb'或'rh' | weather_hourly.pressure |

PCB厂房洁净间室内温湿度通常全年恒定（如23±2℃/55±5%），Phase 2 室内焓值可直接复用 Phase 1 的 room.indoor_calc 值，无需季节映射。待用户最终确认后如有变化再调整。

**物理公式链（参考）：**

以下为 psychrolib 内部实现的热力学公式链，列此仅供参考，代码中无需手动实现：

1. 由干球温度 T 计算饱和水蒸气分压力 Pws（Hyland-Wexler公式）
2. 由湿球温度 Tw 推导出实际水蒸气分压力 Pw（或由相对湿度 φ 直接计算 Pw = φ × Pws）
3. 计算含湿量 W = 0.62198 × Pw / (P - Pw)
4. 计算焓值 h = 1.006 × T + W × (2501 + 1.86 × T)

其中 P 为大气压力（hPa 需转换为 Pa，1 hPa = 100 Pa）。

#### 3.1.3 焓差

**输入：** outdoor_enthalpy_calc、indoor_enthalpy_calc

**输出：**

| 数据库表.字段 | 说明 |
|---|---|
| room_air_volume_result.enthalpy_diff | 焓差(kJ/kg) |

**公式：**

```
enthalpy_diff = outdoor_enthalpy_calc - indoor_enthalpy_calc
```

**歧义说明（4.2）：** 存在两套焓差定义——

- 定义A（数据库设计文档）：焓差 = 室外焓 - 室内焓
- 定义B（冷负荷公式对接问题清单）：焓差 = 室外焓 - 送风焓 h_s（MAU处理后状态）

定义B中的 h_s 通常低于室内焓值（送风温度低于室内温度），算出的负荷更大。两者物理含义不同：定义A是"新风从室外到室内状态的焓变"，定义B是"MAU将新风从室外冷却到送风状态的焓变"。

建议初版按定义A实现，代码中预留 h_s 参数接口，待确认后可切换。

### 3.2 Step 2: 末端负荷计算

**确定性：✅ 已确认**

**输入：**

| 数据库表.字段 | 说明 |
|---|---|
| room_load_parameter.civil_load_index | 土建指标(W/m²) |
| room_load_parameter.lighting_load_index | 照明指标(W/m²) |
| room_load_parameter.personnel_load_index | 人员指标(W/人) |
| room_load_parameter.personnel_count | 人数 |
| room_load_parameter.electric_equipment_power | 电动设备功率(KW) |
| room_load_parameter.electric_equipment_coefficient | 电动设备系数 |
| room_load_parameter.heated_equipment_power_with_exhaust | 有排风电热设备功率(KW) |
| room_load_parameter.heated_equipment_coefficient_with_exhaust | 有排风电热设备系数 |
| room_load_parameter.heated_equipment_power_without_exhaust | 无排风电热设备功率(KW) |
| room_load_parameter.heated_equipment_coefficient_without_exhaust | 无排风电热设备系数 |
| room.area | 房间面积(m²) |

**输出：**

| 数据库表.字段 | 说明 |
|---|---|
| room_load_result.civil_load | 土建负荷(KW) |
| room_load_result.lighting_load | 照明负荷(KW) |
| room_load_result.personnel_load | 人员负荷(KW) |
| room_load_result.electric_equipment_load | 电动设备负荷(KW) |
| room_load_result.heated_equipment_load | 电热设备负荷(KW) |
| room_load_result.terminal_load | 末端负荷合计(KW) |
| room_load_result.cold_load_index | 冷指标(W/m²) |
| room_load_result.heat_load_index | 热指标(W/m²) |

**计算公式：**

```
civil_load         = civil_load_index × room.area / 1000
lighting_load      = lighting_load_index × room.area / 1000
personnel_load     = personnel_load_index × personnel_count / 1000
electric_equipment_load = electric_equipment_power × electric_equipment_coefficient
heated_equipment_load   = heated_equipment_power_with_exhaust × heated_equipment_coefficient_with_exhaust
                      + heated_equipment_power_without_exhaust × heated_equipment_coefficient_without_exhaust

terminal_load = civil_load + lighting_load + personnel_load
              + electric_equipment_load + heated_equipment_load

cold_load_index = terminal_load / room.area × 1000
```

**说明：**

- 各项负荷 = 单项指标 × 对应基数（面积或人数）后除以1000转为 KW
- 人员、设备参数为空时，对应负荷项按 0 处理
- `heat_load_index` 的计算公式待确认（涉及冬季热负荷计算）

**待确认（4.5）：** Excel"房间风量计算表"AE列"末端负荷DCC/RCU（12/17℃）"与上述 terminal_load 数值不一致，DCC/RCU 可能只承担 terminal_load 的部分负荷，拆分逻辑待确认。

**输出：**

| 数据库表.字段 | 说明 |
|---|---|
| room_air_volume_result.total_exhaust_volume | 总排风量(m³/h) |
| room_air_volume_result.infiltration_air_volume | 压差渗透风量(m³/h) |
| room_air_volume_result.sanitary_air_volume | 卫生风量(m³/h) |
| room_air_volume_result.fresh_air_volume | 新风量(m³/h) |
| room_air_volume_result.supply_air_volume | 送风量(m³/h) |
| room_air_volume_result.return_air_volume | 回风量(m³/h) |
| room_air_volume_result.actual_air_change_rate | 实际换气次数(次/h) |
| room_air_volume_result.actual_temp_diff | 实际送风温差(℃) |

**计算公式：**

总排风量 ✅ 已确认：

```
total_exhaust_volume = heat_exhaust_volume + acid_exhaust_volume + alkali_exhaust_volume
                     + organic_exhaust_volume + dust_exhaust_volume
```

（空值的排风量项按 0 处理）

压差渗透风量 ✅ 已确认（经Excel验证）：

```
infiltration_air_volume = room.volume × k
```

k 值由压差决定，目前已验证的映射：

| pressure_diff (Pa) | k |
|---|---|
| 10 | 2 |
| 5 | 1 |

代码中可暂实现为 `k = pressure_diff / 5`，或查表方式。后续如有更多压差档位需补充。

新风量 ⚠️：

```
fresh_air_volume = total_exhaust_volume + infiltration_air_volume
```

此公式经Excel验证（背钻机区：18600 + 13609.1 = 32209.1 ✓，Tray区域：9000 + 1631 = 10631 ✓）。

注意：数据库设计文档中的公式为 `fresh_air_volume = MAX(infiltration, sanitary, 净化风量)`，与Excel实际计算不符。待确认（4.6）是否需要取 MAX 考虑卫生风量和净化风量约束。

卫生风量 ❓ 待确认（4.7）：

```
sanitary_air_volume = personnel_count × 卫生风量标准
```

卫生风量标准待确认。

送风量 ⚠️：

```
supply_air_volume = MAX(消除负荷所需风量, 净化风量)
```

消除负荷所需风量 = terminal_load × 3600 / (ρ × Cp × supply_air_temp_diff)

净化风量 = room.volume × air_change_rate（或基于面积的标准，具体待确认）

公式框架参照Excel I列（消除负荷风量）和L列（净化风量），取大值。

回风量 ✅ 已确认：

```
return_air_volume = supply_air_volume - fresh_air_volume
```

实际换气次数 ✅ 已确认：

```
actual_air_change_rate = supply_air_volume / room.volume
```

实际送风温差 ✅ 已确认：

```
actual_temp_diff = terminal_load × 3600 / (ρ × Cp × supply_air_volume)
```

| water_temperature_config.supply_temp | 供水温度(℃) |

| room_load_summary.fresh_air_carry_load | 新风带走负荷(KW) |

#### 3.4.1 中温水新风冷负荷 ⚠️

参照《冷负荷公式对接问题清单》，核心公式为空气侧焓差法：

```
fresh_air_load = ρ × fresh_air_volume × (h_w - h_s) / 3600
```

其中：

- ρ = 1.2 kg/m³（标准空气密度，常数）
- h_w = 室外空气焓值（即 outdoor_enthalpy_calc）
- h_s = MAU 处理后送风焓值

关键问题：h_s 的确定方式待确认（4.2、4.3）。

如3.1.3节所述，存在两种定义：

- 定义A（默认）：h_s = 室内焓值，即 `fresh_air_load = 1.2 × fresh_air_volume × enthalpy_diff / 3600`
- 定义B：h_s = 送风焓值（需额外确定，取决于盘管性能和水温）

#### 3.4.2 低温水新风冷负荷 ❓

Excel AB列（7/12℃低温水）的公式因房间而异，使用不同的风量和焓差值，计算逻辑尚未明确（4.4）。代码中暂留占位。

#### 3.4.3 新风带走负荷 ❓

room_load_summary.fresh_air_carry_load 对应Excel AD列"新风带走负荷"，物理含义和计算公式待确认（4.8）。

## 5. 公式可替换架构建议

### 5.1 设计原则

鉴于当前系统需求尚在完善中，多个公式待确认，系统架构需满足：

- **公式可替换：** 确认某个公式后，只需修改一处实现，不影响其他模块
- **参数可配置：** 常数和系数集中管理，不散落在业务代码中
- **占位可运行：** 待确认的公式以桩函数实现，系统整体流程可跑通
- **变更可追溯：** 公式变更有记录，便于对比不同版本的计算结果

### 5.2 整体架构

```
┌──────────────────────────────────────────────┐
│ 计算调度层 (Calculation Orchestrator)          │
│   按流水线顺序调度各计算步骤                       │
└────────────────────┬─────────────────────────┘
                     ↓
┌────────────────────┴─────────────────────────┐
│ 计算步骤层 (Calculation Steps)                 │
│   Step1_Enthalpy  Step2_TerminalLoad  ...     │
│   每个步骤定义固定接口：execute(inputs) → outputs │
└────────────────────┬─────────────────────────┘
                     ↓
┌────────────────────┴─────────────────────────┐
│ 公式实现层 (Formula Implementations)           │
│   已确认的：直接实现                              │
│   待确认的：Stub实现（返回None/默认值）            │
└────────────────────┬─────────────────────────┘
                     ↓
┌────────────────────┴─────────────────────────┐
│ 参数配置层 (Parameter Config)                  │
│   常数：3600, 1.006, 2501, 1.86, 0.62198...  │
│   工程假设：空气密度ρ=1.2, k值映射...          │
│   待确认参数：h_s, 低温水焓差...               │
└──────────────────────────────────────────────┘
```

### 5.3 计算步骤接口规范

每个计算步骤定义统一的接口：

```python
class CalcStep(ABC):
    @abstractmethod
    def get_inputs(self) -> list[str]:
        """声明依赖的数据库字段（格式：table.field）"""

    @abstractmethod
    def get_outputs(self) -> list[str]:
        """声明输出的数据库字段"""

    @abstractmethod
    def execute(self, context: CalcContext) -> dict:
        """
        执行计算
        context: 包含所有已计算字段值的上下文对象
        return: {output_field: value}
        """
```

### 5.4 公式替换机制

    def __init__(self, formula: FreshAirLoadFormula):
        self._formula = formula  # 可注入替换的公式实现

    def execute(self, context: CalcContext) -> dict:
        fresh_air_volume = context.get('room_air_volume_result.fresh_air_volume')
        h_outdoor = context.get('room_air_volume_result.outdoor_enthalpy_calc')
        h_indoor = context.get('room_air_volume_result.indoor_enthalpy_calc')

            fresh_air_volume=fresh_air_volume,
            h_outdoor=h_outdoor,
            h_indoor=h_indoor,
            water_temp_config=water_temp
        )

class FreshAirLoadFormulaA(FreshAirLoadFormula):

    RHO = 1.2  # 取自参数配置层

    def calculate(self, fresh_air_volume, h_outdoor, h_indoor, **kwargs):
        delta_h = h_outdoor - h_indoor
        return self.RHO * fresh_air_volume * delta_h / 3600

            delta_h = h_outdoor - h_supply
        return self.RHO * fresh_air_volume * delta_h / 3600

### 5.6 占位/桩模式规范

待确认的公式统一采用桩实现，遵循以下规范：

- 返回 `None` 或 `0.0`（视字段是否必填）
- 打印警告日志：`[PENDING] {step_name}: formula not confirmed, using placeholder`
- 在计算结果中标记 `is_pending = True`，便于前端展示和筛选
- 确认公式后，替换桩实现为真实公式，无需修改接口和调用方
