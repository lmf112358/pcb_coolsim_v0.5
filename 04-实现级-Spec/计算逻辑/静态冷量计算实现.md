### 2.2 计算步骤依赖关系

Step 1（焓值）与 Step 2（末端负荷）之间无依赖，可并行计算。Step 3（风量）独立于 Step 1/2（仅需 Room 的风量参数与体积）。Step 4（新风冷负荷）依赖 Step 1 和 Step 3。Step 5 依赖 Step 2 和 Step 4。Step 6 依赖 Step 5 及 ExtraLoad 表。

### 2.3 数据组织维度

所有计算结果按 `room_id` 维度组织（无 season_id，v0.5.1 不需季节表，气象数据本身区分季节）。Step 4 及之后按 `water_temp_config_id` 维度展开——**末端负荷按 Room.terminal_water_temp_config_id 归档（默认中温 12/17°C），新风负荷按 fresh_air 配置归档**（ADR-0001）。最终聚合按 `room → floor → building → project` 逐级汇总。

## 3. 计算步骤详细说明

### 3.1 Step 1: 焓值计算

**确定性：✅ 已确认（psychrolib 标准库，ASHRAE 标准，精度优于 0.1%）**

#### 3.1.0 焓值计算总则

**焓值与国标参数的关系：**

焓值（kJ/kg）是湿空气的热力学状态参数，由干球温度、含湿量（或相对湿度）和大气压力共同确定。国标《工业室外空气计算参数》提供的是**输入参数**（干球温度、湿球温度、相对湿度、大气压力等），而非焓值本身。焓值是**推导值**——从国标输入参数出发，通过热力学公式计算得到。因此数据库中不预存焓值，而是在计算时实时调用焓值计算函数。

**计算库：psychrolib**

使用 Python 开源库 [psychrolib](https://github.com/psychrometrics/psychrolib)，该库实现了 ASHRAE Handbook of Fundamentals 中的标准湿空气热力学计算，包括饱和蒸汽压公式（Hyland-Wexler）、含湿量、焓值、湿球温度转换等全部公式，无需手动实现。

安装与使用示例：

```python
import psychrolib

# 设置SI单位制（温度℃、压力Pa、焓kJ/kg）
psychrolib.SetUnitSystem(psychrolib.SI)

def calculate_enthalpy(temp_dry, humidity_or_wet_bulb, pressure_hpa,
                       input_type='rh'):
    """
    通用焓值计算函数（室内外共用）

    参数:
        temp_dry: 干球温度(℃)
        humidity_or_wet_bulb: 相对湿度(%)或湿球温度(℃)，由input_type决定
        pressure_hpa: 大气压力(hPa)
        input_type: 'rh' = 相对湿度, 'wb' = 湿球温度

    返回:
        焓值(kJ/kg)
    """
    pressure_pa = pressure_hpa * 100  # hPa → Pa

    if input_type == 'rh':
        # 室内焓值：干球温度 + 相对湿度
        return psychrolib.GetMoistAirEnthalpy(
            temp_dry,
            psychrolib.GetHumRatioFromRelHum(temp_dry, humidity_or_wet_bulb, pressure_pa),
            pressure_pa
        )
    elif input_type == 'wb':
        # 室外焓值：干球温度 + 湿球温度（库内部自动转换为含湿量）
        hum_ratio = psychrolib.GetHumRatioFromTWetBulb(
            temp_dry, humidity_or_wet_bulb, pressure_pa
        )
        return psychrolib.GetMoistAirEnthalpy(temp_dry, hum_ratio, pressure_pa)
```

**Phase 1 / Phase 2 复用说明：**

Phase 1（静态设计负荷）和 Phase 2（动态仿真）使用**完全相同的焓值计算公式**，区别仅在于输入参数的来源不同。封装为通用函数后，室内外、设计工况与逐时工况均可复用：

| 计算场景 | 干球温度来源 | 湿度参数来源 | input_type | 大气压力来源 |
|---|---|---|---|---|
| Phase 1 室内焓值 | Room.indoor_calc_temp（空取 26°C） | Room.indoor_calc_humidity（空取 55%） | 'rh' | CityConfig.pressure_summer |
| Phase 1 室外焓值 | CityConfig.temp_dry_ac_summer | CityConfig.temp_wet_ac_summer | 'wb' | CityConfig.pressure_summer |
| Phase 2 室内焓值 | Room.indoor_calc_temp（全年恒定） | Room.indoor_calc_humidity（全年恒定） | 'rh' | WeatherRecord.pressure |
| Phase 2 室外焓值 | WeatherRecord.temp_dry | WeatherRecord.temp_wet（或 humidity） | 'wb'或'rh' | WeatherRecord.pressure |

PCB 厂房洁净间室内温湿度通常全年恒定（如 23±2℃/55±5%），Phase 2 室内焓值直接复用 Phase 1 的 Room.indoor_calc 值，无需季节映射。

**物理公式链（参考）：**

psychrolib 内部实现的热力学公式链，列此仅供参考，代码中无需手动实现：

1. 由干球温度 T 计算饱和水蒸气分压力 Pws（Hyland-Wexler 公式）
2. 由湿球温度 Tw 推导出实际水蒸气分压力 Pw（或由相对湿度 φ 直接计算 Pw = φ × Pws）
3. 计算含湿量 W = 0.62198 × Pw / (P - Pw)
4. 计算焓值 h = 1.006 × T + W × (2501 + 1.86 × T)

其中 P 为大气压力（hPa 需转换为 Pa，1 hPa = 100 Pa）。

**输入：**

| 数据库表.字段 | 说明 |
|---|---|
| Room.indoor_calc_temp | 室内计算温度(℃)，空取默认 26°C |
| Room.indoor_calc_humidity | 室内计算相对湿度(%)，空取默认 **55%** |
| CityConfig.pressure_summer | 大气压力(hPa)（室内外同一压力） |

**输出：**

| 数据库表.字段 | 说明 |
|---|---|
| RoomCalcResult.indoor_enthalpy_calc | 室内计算焓值(kJ/kg) |

**计算方法：**

```python

    temp_dry=room.indoor_calc_temp or 26.0,
    humidity_or_wet_bulb=room.indoor_calc_humidity or 55.0,   # 默认 55%，不是 60%

)
```

#### 3.1.3 焓差

**输入：** outdoor_enthalpy_calc、indoor_enthalpy_calc

**输出：**

| 数据库表.字段 | 说明 |
|---|---|
| RoomCalcResult.enthalpy_diff | 焓差(kJ/kg) |

**公式：**

```
enthalpy_diff = outdoor_enthalpy_calc - indoor_enthalpy_calc
```

**唯一公式（定义A）：** 焓差 = 室外焓 − 室内焓。删除 v1.x 的"定义B 送风焓 h_s"歧义——v0.5.1 统一按定义A实现，不再保留 h_s 参数接口。

### 3.2 Step 2: 末端负荷计算（桥梁，静态动态共用）

**确定性：✅ 已确认**

末端负荷 Q_terminal 计算一次，静态和动态共用（PRD §15.4 桥梁）。

**输入（字段全部直接读 Room 单表）：**

| 数据库表.字段 | 说明 |
|---|---|
| Room.civil_load_index | 土建指标(W/m²) |
| Room.lighting_load_index | 照明指标(W/m²) |
| Room.personnel_load_index | 人员指标(W/人) |
| Room.personnel_count | 人数 |
| Room.electric_equipment_power | 电动设备功率(KW) |
| Room.electric_equipment_coefficient | 电动设备系数 |
| Room.heated_equipment_power_with_exhaust | 有排风电热设备功率(KW) |
| Room.heated_equipment_coefficient_with_exhaust | 有排风电热设备系数 |
| Room.heated_equipment_power_without_exhaust | 无排风电热设备功率(KW) |
| Room.heated_equipment_coefficient_without_exhaust | 无排风电热设备系数 |
| Room.area | 房间面积(m²) |

**输出：**

| 数据库表.字段 | 说明 |
|---|---|
| RoomCalcResult.civil_load | 土建负荷(KW) |
| RoomCalcResult.lighting_load | 照明负荷(KW) |
| RoomCalcResult.personnel_load | 人员负荷(KW) |
| RoomCalcResult.electric_equipment_load | 电动设备负荷(KW) |
| RoomCalcResult.heated_equipment_load | 电热设备负荷(KW) |
| RoomCalcResult.terminal_load | 末端负荷合计(KW) |
| RoomCalcResult.cold_load_index | 冷指标(W/m²) |

**计算公式（PRD §15.1）：**

```
civil_load              = civil_load_index × area / 1000                           (kW)
lighting_load           = lighting_load_index × area / 1000                        (kW)
personnel_load          = personnel_load_index × personnel_count / 1000            (kW，空取0)
electric_equipment_load = electric_equipment_power × electric_equipment_coefficient          (kW，空取0，不乘1000)
heated_equipment_load   = heated_equipment_power_with_exhaust × heated_equipment_coefficient_with_exhaust
                        + heated_equipment_power_without_exhaust × heated_equipment_coefficient_without_exhaust  (kW，空取0，不乘1000)

terminal_load = civil_load + lighting_load + personnel_load
              + electric_equipment_load + heated_equipment_load

cold_load_index = terminal_load / area × 1000    (W/m²)
```

**说明：**

- 土建/照明/人员：单项指标 × 对应基数（面积或人数）后除以 1000 转为 KW
- 电动设备/电热设备：**kW 量纲，不乘 1000**（功率已是 KW，系数为无量纲），空值按 0 处理
- v0.5 不计算冬季热负荷（heat_load_index 留空）

### 3.3 Step 3: 风量计算

**确定性：✅ 已确认（PRD §8.3 / §15.2 八点查表 + A4 简单加法）**

**输入（字段全部直接读 Room 单表）：**

| 数据库表.字段 | 说明 |
|---|---|
| Room.heat_exhaust_volume | 热排风量(m³/h) |
| Room.acid_exhaust_volume | 酸性排风量(m³/h) |
| Room.alkali_exhaust_volume | 碱性排风量(m³/h) |
| Room.organic_exhaust_volume | 有机排风量(m³/h) |
| Room.dust_exhaust_volume | 含尘排风量(m³/h) |
| Room.pressure_diff | 房间压差(Pa) |
| Room.volume | 房间体积(m³) = 面积 × 吊顶高度 |

**输出：**

| 数据库表.字段 | 说明 |
|---|---|
| RoomCalcResult.total_exhaust_volume | 总排风量(m³/h) |
| RoomCalcResult.infiltration_air_volume | 压差渗透风量(m³/h) |
| RoomCalcResult.fresh_air_volume | 新风量(m³/h) |

**计算公式（PRD §15.2）：**

总排风量 ✅：

```
total_exhaust_volume = heat_exhaust_volume + acid_exhaust_volume + alkali_exhaust_volume
                     + organic_exhaust_volume + dust_exhaust_volume     （空值按 0）
```

压差渗透风量 ✅（PRD §8.3 八点查表线性插值）：

```
infiltration_air_volume = Room.volume × k(|pressure_diff|)

体积 = 面积 × 吊顶高度
k 由 |pressure_diff| 查下表线性插值；正/负压按绝对值对称；>|±15| 封顶 4.0
```

**压差渗透风量系数表（唯一权威表，写入 DefaultConfig，可项目级覆盖）：**

| 压差 \|Pa\| | 系数 k（次/h，相对房间体积） | 说明 |
| --- | --- | --- |
| 0（平压） | 0.0 | 无渗透 |
| 1 | 1.0 | |
| 2 | 1.5 | |
| 3 | 2.0 | |
| 5 | 3.0 | |
| 10 | 3.5 | 正/负压对称取绝对值查表 |
| 15 | 4.0 | |
| > 15 | 4.0（封顶） | 极端压差异常，提示用户复核 |

> 非表内点采用线性插值。**绝不能用 k = pressure_diff/5 或 k = √(ΔP) 公式**（v1.x 已删除该错误实现）。

**查表 + 插值函数（伪代码）：**

```python
def lookup_infiltration_coeff(pressure_diff):
    """压差渗透系数 k：PRD §8.3 唯一权威表，8 点线性插值。"""
    table = [(0, 0.0), (1, 1.0), (2, 1.5), (3, 2.0),
             (5, 3.0), (10, 3.5), (15, 4.0)]
    x = abs(pressure_diff)            # 正/负压对称取绝对值
    if x >= 15:
        return 4.0                    # 封顶
    for i in range(len(table) - 1):
        x0, y0 = table[i]
        x1, y1 = table[i + 1]
        if x0 <= x <= x1:             # 线性插值
            return y0 + (y1 - y0) * (x - x0) / (x1 - x0)
    return 0.0

infiltration_air_volume = room.volume * lookup_infiltration_coeff(room.pressure_diff or 0)
```

新风量 ✅（PRD §15.2 / A4 简单加法）：

```
fresh_air_volume = total_exhaust_volume + infiltration_air_volume
```

> **新风量就是简单加法，不加 MAX 逻辑，不加卫生风量（sanitary_air_volume），不加净化风量**（A4 有意工程简化）。
> v1.x 中 `fresh_air_volume = MAX(infiltration, sanitary, 净化风量)`、`supply_air_volume = MAX(...)`、`return_air_volume`、`sanitary_air_volume` 等公式与字段**已全部删除**。

| RoomCalcResult.fresh_air_volume | 新风量(m³/h)（Step 3 输出） |
| RoomCalcResult.outdoor_enthalpy_calc | 室外焓值(kJ/kg) |
| RoomCalcResult.indoor_enthalpy_calc | 室内焓值(kJ/kg) |
| RoomCalcResult.enthalpy_diff | 焓差(kJ/kg) |
| Room.fresh_air_water_mode | 新风处理模式（单水温/两阶段） |
| Room.fresh_air_water_temp_config_id | 单水温档 / 两阶段第一段 |
| Room.fresh_air_water_temp_config_id_2 | 两阶段第二段（可空） |
| DefaultConfig.air_density | 空气密度 kg/m³（默认 1.2） |
| WaterTempConfig.supply_temp / return_temp | 供/回水温度(℃) |

**输出：**

| 数据库表.字段 | 说明 |
|---|---|
| RoomLoadByWaterTemp.fresh_air_load | 新风冷负荷(KW) |

#### 3.4.1 新风冷负荷公式（唯一公式：定义A，PRD §15.3）

```
Q_fresh_air = ρ × V_fresh_air × (h_outdoor - h_indoor) / 3600   (kW)

ρ = DefaultConfig.air_density（默认 1.2 kg/m³，统一 1.2，删除 1.2 vs 1.12 歧义）
h_outdoor = RoomCalcResult.outdoor_enthalpy_calc
h_indoor  = RoomCalcResult.indoor_enthalpy_calc
```

- 焓值使用 psychrolib 库计算（F4-010）
- 室外焓值：静态用国标夏季室外设计参数；动态用逐时气象数据
- 室内焓值：使用 Room.indoor_calc_temp / indoor_calc_humidity（空取默认 26°C / 55%）
- 新风负荷可为负（冬季/过渡季室外焓低于室内），允许负值参与计算

> **唯一公式（定义A）：** `Q_fresh_air = 1.2 × fresh_air_volume × (h_outdoor − h_indoor) / 3600`。
> v1.x 的"定义B 送风焓 h_s"歧义、低温水 AB 列占位、再冷负荷（fresh_air_carry_load）均已删除——v0.5.1 统一按定义A，不再保留 h_s / fresh_air_carry_load 接口。

#### 3.4.2 按水温分类归档（ADR-0001）

末端负荷与新风冷负荷**分别**按档归档（PRD §15.5 / ADR-0001）：

- **末端负荷**：按 `Room.terminal_water_temp_config_id` 归入对应水温分类（默认中温 12/17°C，可逐区指定低温 7/12°C）。**绝不能把同一 terminal_load 复制到所有水温档。**
- **新风冷负荷**：按 fresh_air 配置归档：
  - 单水温模式（fresh_air_water_mode=single）：全量归入 `Room.fresh_air_water_temp_config_id` 对应档
  - 两阶段模式（fresh_air_water_mode=two_stage）：按配置比例分配到第一段 / 第二段档；`h_intermediate`（中间状态焓值）预留接口，v0.5 先按比例分配，待暖通工程师确认后回填

**计算公式（PRD §15.3 / §15.4 负值截断，静态动态统一）：**

```
total_load = fresh_air_load + terminal_load
if total_load < 0:
    total_load = 0          # 截断为 0（与动态统一）
```

**说明：**

- 每个房间在每个水温配置下各有一条 RoomLoadByWaterTemp 记录（末端 + 新风分别归档）
- 新风负荷可为负；总负荷 < 0 时截断为 0
- 极值统计 Q_min 取 total_load > 0 的有意义最小值

**输入：**

|---|---|
| RoomLoadByWaterTemp | 房间级负荷（按水温分类） |

|---|---|
| LoadSummary.fresh_air_load | 新风冷负荷汇总(KW) |

| LoadSummary.extra_load | 额外负荷汇总(KW) |

**聚合规则（Room → Floor → Building(+ExtraLoad) → Project(+ExtraLoad)）：**

| scope | building_id | floor_id | 数据来源 |
|---|---|---|---|
| floor | 有值 | 有值 | 该楼层所有房间的 RoomLoadByWaterTemp 聚合 |

```
extra_load     = SUM(对应层级 ExtraLoad.load_value)
total_load     = fresh_air_load + terminal_load + extra_load
```

## 5. 公式可替换架构建议

### 5.1 设计原则

系统架构需满足：

- **公式可替换：** 确认某公式后，只需修改一处实现
- **参数可配置：** 常数和系数集中管理（压差系数表、air_density 等入 DefaultConfig），不散落在业务代码
- **变更可追溯：** 公式变更有记录

### 5.2 整体架构

```
┌──────────────────────────────────────────────┐
│ 计算调度层 (Calculation Orchestrator)          │
│   按流水线顺序调度各计算步骤                       │
└────────────────────┬─────────────────────────┘
                     ↓
┌────────────────────┴─────────────────────────┐
│ 计算步骤层 (Calculation Steps)                 │
│   Step1_Enthalpy  Step2_TerminalLoad  ...     │
│   每个步骤定义固定接口：execute(inputs) → outputs │
└────────────────────┬─────────────────────────┘
                     ↓
┌────────────────────┴─────────────────────────┐
│ 公式实现层 (Formula Implementations)           │
│   全部已确认，直接实现（无 Stub）                 │
└────────────────────┬─────────────────────────┘
                     ↓
┌────────────────────┴─────────────────────────┐
│ 参数配置层 (DefaultConfig)                     │
│   物理常数：CP_AIR=1.006, SEC_PER_HOUR=3600... │
│   工程参数：air_density=1.2, 压差系数 8 点表... │
└──────────────────────────────────────────────┘
```

### 5.3 计算步骤接口规范

每个计算步骤定义统一的接口：

```python
class CalcStep(ABC):
    @abstractmethod
    def get_inputs(self) -> list[str]:
        """声明依赖的数据库字段（格式：Table.field）"""

    @abstractmethod
    def get_outputs(self) -> list[str]:
        """声明输出的数据库字段"""

    @abstractmethod
    def execute(self, context: CalcContext) -> dict:
        """执行计算，返回 {output_field: value}"""
```

### 5.4 参数配置层设计（DefaultConfig）

所有常数和可调参数集中管理：

```python
CALC_PARAMS = {
    # 物理常数（不可变）
    'CONSTANTS': {
        'CP_AIR': 1.006,           # 干空气定压比热 kJ/(kg·℃)
        'SEC_PER_HOUR': 3600,      # 小时转秒
    },
    # 工程参数（存 DefaultConfig，可项目级覆盖）
    'DEFAULT_CONFIG': {
        'air_density': 1.2,        # 空气密度 kg/m³（统一 1.2）
        'indoor_default_temp': 26.0,      # 室内默认温度 ℃
        'indoor_default_humidity': 55.0,  # 室内默认湿度 %（不是 60%）
        # 压差渗透系数 8 点表（PRD §8.3 唯一权威表）
        'infiltration_coeff_table': [
            (0, 0.0), (1, 1.0), (2, 1.5), (3, 2.0),
            (5, 3.0), (10, 3.5), (15, 4.0),
        ],
    },
}
```
