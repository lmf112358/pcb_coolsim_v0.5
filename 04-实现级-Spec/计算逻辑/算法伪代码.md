## 1. 静态冷量计算算法（6步流水线）

### 1.1 总体流程

```
算法：静态冷量计算主流程

输入：
  - room_data: 房间参数数据
  - weather_data: 设计日气象数据

输出：
  - result: 静态冷量计算结果

流程：
FUNCTION CalculateStaticLoad(room_data, weather_data):
    // 步骤1：内热源计算
    internal_heat = CalculateInternalHeatSources(room_data)

    // 步骤2：围护结构计算
    envelope_load = CalculateEnvelopeLoad(room_data, weather_data)

    // 步骤3：通风负荷计算
    ventilation_load = CalculateVentilationLoad(room_data, weather_data)

    // 步骤4：工艺负荷计算
    process_load = CalculateProcessLoad(room_data)

    // 步骤5：安全系数应用
    subtotal = internal_heat + envelope_load + ventilation_load + process_load
    adjusted_load = subtotal * room_data.safety_factor

    // 步骤6：汇总到房间
    result = AggregateToRoom(adjusted_load, room_data)

    RETURN result
END FUNCTION
```

### 1.2 步骤1：内热源计算

```
算法：内热源计算

输入：
  - equipment_power: 设备总功率 (W)
  - equipment_coeff: 设备同时使用系数 (0-1)
  - lighting_power: 照明总功率 (W)
  - lighting_coeff: 照明同时使用系数 (0-1)
  - occupancy_count: 人员数量
  - occupancy_heat: 单人散热量 (W/人)
  - occupancy_coeff: 人员同时在场系数 (0-1)

输出：
  - equipment_heat: 设备散热量 (W)
  - lighting_heat: 照明散热量 (W)
  - occupancy_heat_total: 人员散热量 (W)
  - total: 总内热源散热量 (W)

流程：
FUNCTION CalculateInternalHeatSources(room_data):
    // 设备散热
    equipment_heat = room_data.equipment_power * room_data.equipment_coeff

    // 照明散热
    lighting_heat = room_data.lighting_power * room_data.lighting_coeff

    // 人员散热
    occupancy_heat_total = room_data.occupancy_count * room_data.occupancy_heat * room_data.occupancy_coeff

    total = equipment_heat + lighting_heat + occupancy_heat_total

    RETURN {
        equipment_heat,
        lighting_heat,
        occupancy_heat_total,
        total
    }
END FUNCTION
```

### 1.3 步骤2：围护结构负荷计算

```
算法：围护结构负荷计算

输入：
  - wall_area: 墙体面积 (m²)
  - wall_u_value: 墙体传热系数 (W/(m²·K))
  - roof_area: 屋顶面积 (m²)
  - roof_u_value: 屋顶传热系数 (W/(m²·K))
  - outdoor_temp: 室外设计温度 (°C)
  - indoor_temp: 室内设计温度 (°C)
  - solar_radiation: 太阳辐射强度 (W/m²)
  - shading_coeff: 遮阳系数 (0-1)
  - wall_absorptivity: 墙体吸收系数 (0-1)

输出：
  - wall_conduction: 墙体传热负荷 (W)
  - roof_conduction: 屋顶传热负荷 (W)
  - solar_gain: 太阳辐射得热 (W)
  - total: 总围护结构负荷 (W)

流程：
FUNCTION CalculateEnvelopeLoad(room_data, weather_data):
    // 温度差
    delta_t = weather_data.outdoor_temp - room_data.indoor_temp

    // 墙体传热
    wall_conduction = room_data.wall_area * room_data.wall_u_value * delta_t

    // 屋顶传热
    roof_conduction = room_data.roof_area * room_data.roof_u_value * delta_t

    // 太阳辐射得热
    solar_gain = weather_data.solar_radiation * room_data.wall_area
                * room_data.shading_coeff * room_data.wall_absorptivity

    total = wall_conduction + roof_conduction + solar_gain

    RETURN {
        wall_conduction,
        roof_conduction,
        solar_gain,
        total
    }
END FUNCTION
```

### 1.4 步骤3：通风负荷计算

```
算法：通风负荷计算

输入：
  - fresh_air_volume: 新风量 (m³/h)
  - outdoor_temp: 室外温度 (°C)
  - outdoor_humidity: 室外湿度 (%)
  - indoor_temp: 室内温度 (°C)
  - indoor_humidity: 室内湿度 (%)
  - air_density: 空气密度 (kg/m³), 默认 1.2
  - specific_heat: 空气比热容 (kJ/(kg·K)), 默认 1.005

输出：
  - sensible_heat: 显热负荷 (W)
  - latent_heat: 潜热负荷 (W)
  - total: 总通风负荷 (W)

流程：
FUNCTION CalculateVentilationLoad(room_data, weather_data):
    // 计算室外和室内焓值
    outdoor_enthalpy = CalculateMoistAirEnthalpy(
        weather_data.outdoor_temp,
        weather_data.outdoor_humidity
    )
    indoor_enthalpy = CalculateMoistAirEnthalpy(
        room_data.indoor_temp,
        room_data.indoor_humidity
    )

    // 计算含湿量
    outdoor_humidity_ratio = CalculateHumidityRatio(
        weather_data.outdoor_temp,
        weather_data.outdoor_humidity
    )
    indoor_humidity_ratio = CalculateHumidityRatio(
        room_data.indoor_temp,
        room_data.indoor_humidity
    )

    // 质量流量 (kg/s)
    mass_flow_rate = room_data.fresh_air_volume / 3600 * room_data.air_density

    // 显热负荷 (W)
    sensible_heat = mass_flow_rate * room_data.specific_heat
                  * (weather_data.outdoor_temp - room_data.indoor_temp) * 1000

    // 潜热负荷 (W)
    latent_heat = mass_flow_rate * 2500 * (outdoor_humidity_ratio - indoor_humidity_ratio) * 1000

    total = sensible_heat + latent_heat

    RETURN {
        sensible_heat,
        latent_heat,
        total
    }
END FUNCTION
```

### 1.5 步骤4：工艺负荷计算

```
算法：工艺负荷计算

输入：
  - exhaust_volume: 排风量 (m³/h)
  - exhaust_type: 排风类型 (heat/acid/alkali/organic/dust)
  - pressure_diff: 压差 (Pa)
  - process_equipment_heat: 工艺设备散热量 (W)

输出：
  - exhaust_load: 排风负荷 (W)
  - process_equipment_load: 工艺设备负荷 (W)
  - total: 总工艺负荷 (W)

流程：
FUNCTION CalculateProcessLoad(room_data):
    // 排风负荷
    IF room_data.exhaust_volume > 0 THEN
        // 计算补风带来的负荷
        makeup_air_temp = outdoor_design_temp  // 使用设计日室外温度
        exhaust_load = room_data.exhaust_volume / 3600 * room_data.air_density
                      * room_data.specific_heat * (makeup_air_temp - room_data.indoor_temp)
                      * 1000
    ELSE
        exhaust_load = 0
    END IF

    // 压差维持负荷
    IF room_data.pressure_diff > 0 THEN
        pressure_load = room_data.pressure_diff * room_data.fresh_air_volume / 3600
                       * 0.5  // 压差修正系数
    ELSE
        pressure_load = 0
    END IF

    // 工艺设备散热
    process_equipment_load = room_data.process_equipment_heat

    total = exhaust_load + pressure_load + process_equipment_load

    RETURN {
        exhaust_load,
        process_equipment_load,
        total
    }
END FUNCTION
```

### 1.7 步骤6：层级汇总

```
算法：层级汇总

输入：

输出：
  - floor_totals: 楼层汇总
  - building_totals: 建筑汇总

FUNCTION AggregateLoadResults(rooms):
    // 按楼层分组
    floors = GroupByFloor(rooms)

    FOR EACH floor IN floors:
        floor.total_load = SUM(room.total_load FOR room IN floor.rooms)
        floor.room_count = COUNT(floor.rooms)
        floor.area = SUM(room.area FOR room IN floor.rooms)
        floor.load_per_area = floor.total_load / floor.area

    // 按建筑分组
    buildings = GroupByBuilding(floors)

    FOR EACH building IN buildings:
        building.total_load = SUM(floor.total_load FOR floor IN building.floors)
        building.floor_count = COUNT(building.floors)
        building.area = SUM(floor.area FOR floor IN building.floors)
        building.load_per_area = building.total_load / building.area
    END FOR

    RETURN {
        floors,
        buildings
    }
END FUNCTION
```

## 2. 动态仿真算法

### 2.1 气象数据驱动算法（方法1）

```
算法：气象数据驱动动态仿真

输入：
  - weather_data: 8760h 气象数据（室外温度、湿度、辐射等）
  - rooms: 房间参数列表
  - years: 模拟年份列表

输出：
  - results: 逐时负荷结果

流程：
FUNCTION WeatherDrivenSimulation(weather_data, rooms, years):
    results = {}

    FOR EACH year IN years:
        year_results = []

        FOR hour = 0 TO 8759:
            outdoor_temp = weather_data[year].temperature[hour]
            outdoor_humidity = weather_data[year].humidity[hour]
            solar_radiation = weather_data[year].radiation[hour]

            hour_result = {
                hour,
                timestamp: CalculateTimestamp(year, hour),
                rooms: []
            }

            FOR EACH room IN rooms:
                // 计算新风负荷
                fresh_air_load = CalculateFreshAirLoad(
                    room,
                    outdoor_temp,
                    outdoor_humidity
                )

                // 计算末端负荷（围护结构 + 内热源）
                terminal_load = CalculateTerminalLoad(
                    room,
                    outdoor_temp,
                    solar_radiation,
                    hour  // 考虑日照角度变化
                )

                // 总负荷
                total_load = fresh_air_load + terminal_load

                // 负荷截断：负负荷处理为 0
                IF total_load < 0 THEN
                    total_load = 0
                END IF

                APPEND {
                    room_id: room.id,
                    fresh_air_load,
                    terminal_load,
                    total_load
                } TO hour_result.rooms
            END FOR

            APPEND hour_result TO year_results
        END FOR

        results[year] = year_results
    END FOR

    RETURN results
END FUNCTION

// 新风负荷计算子函数
FUNCTION CalculateFreshAirLoad(room, outdoor_temp, outdoor_humidity):
    // 使用 psychrolib 计算焓值
    outdoor_enthalpy = Psychrolib.CalcMoistAirEnthalpy(
        outdoor_temp,
        outdoor_humidity / 100  // 转换为小数
    )
    indoor_enthalpy = Psychrolib.CalcMoistAirEnthalpy(
        room.indoor_temp,
        room.indoor_humidity / 100
    )

    // 质量流量
    mass_flow = room.fresh_air_volume / 3600 * 1.2  // kg/s

    // 新风负荷 (W)
    fresh_air_load = mass_flow * (indoor_enthalpy - outdoor_enthalpy) * 1000

    RETURN fresh_air_load
END FUNCTION

// 末端负荷计算子函数
FUNCTION CalculateTerminalLoad(room, outdoor_temp, solar_radiation, hour):
    // 围护结构传热
    envelope_load = (room.wall_u * room.wall_area + room.roof_u * room.roof_area)
                  * (outdoor_temp - room.indoor_temp)

    // 太阳辐射得热（考虑日照角度）
    solar_angle_factor = CalculateSolarAngleFactor(room.orientation, hour)
    solar_gain = solar_radiation * room.window_area
               * room.shading_coeff * solar_angle_factor

    // 内热源（考虑运行时间表）
    schedule_factor = GetHourlySchedule(room.schedule, hour)
    internal_heat = room.base_internal_heat * schedule_factor

    total = envelope_load + solar_gain + internal_heat

    RETURN total
END FUNCTION
```

### 2.2 比例系数法（方法2）

```
算法：比例系数法动态仿真

输入：
  - static_results: 静态冷量计算结果
  - coefficient_mapping: 比例系数映射表
  - weather_data: 气象数据
  - production_schedule: 生产排程

输出：
  - results: 逐时负荷结果

流程：
FUNCTION CoefficientMethodSimulation(static_results, coefficient_mapping, weather_data, production_schedule):
    results = {}

    FOR EACH year IN years:
        year_results = []

        FOR hour = 0 TO 8759:
            outdoor_temp = weather_data[year].temperature[hour]

            hour_result = {
                hour,
                timestamp: CalculateTimestamp(year, hour),
                rooms: []
            }

            FOR EACH room IN static_results.rooms:
                // 获取当前小时的生产率
                production_rate = GetProductionRate(production_schedule, room.id, hour)

                // 查表获取比例系数
                coefficient = LookupCoefficient(
                    coefficient_mapping,
                    outdoor_temp,
                    production_rate
                )

                // 计算动态负荷
                base_load = room.static_total_load
                dynamic_load = base_load * coefficient

                // 分解新风和末端负荷
                fresh_air_ratio = room.static_fresh_air_load / room.static_total_load
                fresh_air_load = dynamic_load * fresh_air_ratio
                terminal_load = dynamic_load * (1 - fresh_air_ratio)

                // 负荷截断：负负荷处理为 0
                IF dynamic_load < 0 THEN
                    dynamic_load = 0
                    fresh_air_load = 0
                    terminal_load = 0
                END IF

                APPEND {
                    room_id: room.id,
                    fresh_air_load,
                    terminal_load,
                    total_load: dynamic_load
                } TO hour_result.rooms
            END FOR

            APPEND hour_result TO year_results
        END FOR

        results[year] = year_results
    END FOR

    RETURN results
END FUNCTION

// 比例系数查表（双线性插值）
FUNCTION LookupCoefficient(mapping, outdoor_temp, production_rate):
    // 找到温度区间
    temp_range = FindTemperatureRange(mapping, outdoor_temp)

    // 找到生产率区间
    rate_range = FindProductionRateRange(mapping, production_rate)

    // 获取四个角点的系数值
    c11 = mapping[temp_range.min][rate_range.min]
    c12 = mapping[temp_range.min][rate_range.max]
    c21 = mapping[temp_range.max][rate_range.min]
    c22 = mapping[temp_range.max][rate_range.max]

    // 双线性插值
    t_ratio = (outdoor_temp - temp_range.min) / (temp_range.max - temp_range.min)
    r_ratio = (production_rate - rate_range.min) / (rate_range.max - rate_range.min)

    coefficient = c11 * (1 - t_ratio) * (1 - r_ratio)
                + c12 * (1 - t_ratio) * r_ratio
                + c21 * t_ratio * (1 - r_ratio)
                + c22 * t_ratio * r_ratio

    RETURN coefficient
END FUNCTION
```

## 3. 8760h 数据聚合算法

### 3.1 数据存储策略

```
算法：8760h 数据存储

输入：
  - simulation_results: 仿真结果（逐时）
  - simulation_id: 仿真任务 ID
  - room_id: 房间 ID

输出：
  - success: 是否成功

流程：
FUNCTION Store8760hData(simulation_results, simulation_id, room_id):
    // 使用 TimescaleDB 批量插入
    batch_size = 1000
    total_hours = LENGTH(simulation_results)

    FOR i = 0 TO total_hours - 1 STEP batch_size:
        batch = simulation_results[i : MIN(i + batch_size, total_hours)]

        INSERT INTO simulation_hourly_results (simulation_task_id, room_id, datetime, total_load, fresh_air_load, terminal_load, outdoor_temp)
        VALUES (
            SELECT simulation_id, room_id, result.timestamp, result.total_load, result.fresh_air_load, result.terminal_load, result.outdoor_temp
            FROM batch AS result
        )
        ON CONFLICT (simulation_task_id, room_id, datetime) DO UPDATE SET
            total_load = EXCLUDED.total_load,
            fresh_air_load = EXCLUDED.fresh_air_load,
            terminal_load = EXCLUDED.terminal_load,
            outdoor_temp = EXCLUDED.outdoor_temp
    END FOR

    RETURN success
END FUNCTION
```

```
FUNCTION AggregateToDaily(hourly_data):

        day.fresh_air_load = SUM(hour.fresh_air_load FOR hour IN day.hours)
```

### 3.3 统计值计算

```
算法：统计值计算

输入：
  - data_points: 数据点列表

输出：
  - statistics: 统计结果

流程：
FUNCTION CalculateStatistics(data_points):
    // 峰值负荷
    peak_load = MAX(data_point.total_load FOR data_point IN data_points)
    peak_load_time = TIMESTAMP_OF(peak_load)

    // 谷值负荷
    valley_load = MIN(data_point.total_load FOR data_point IN data_points)
    valley_load_time = TIMESTAMP_OF(valley_load)

    // 平均负荷
    total_load = SUM(data_point.total_load FOR data_point IN data_points)
    data_count = COUNT(data_points)
    avg_load = total_load / data_count

    // 总用电量
    total_energy_kwh = total_load / 1000  // W 转 kW，假设每小时 1 条数据

    // 负荷率
    load_factor = avg_load / peak_load IF peak_load > 0 ELSE 0

    // 百分位数
    percentiles = CalculatePercentiles(data_points, [10, 25, 50, 75, 90, 95, 99])

    RETURN {
        peak_load,
        peak_load_time,
        valley_load,
        valley_load_time,
        avg_load,
        total_energy_kwh,
        load_factor,
        percentiles
    }
END FUNCTION

// 百分位数计算
FUNCTION CalculatePercentiles(data_points, percentiles):
    sorted_data = SORT(data_points BY total_load ASC)
    n = COUNT(sorted_data)
    result = {}

    FOR EACH percentile IN percentiles:
        index = (percentile / 100) * (n - 1)
        lower_index = FLOOR(index)
        upper_index = CEIL(index)
        fraction = index - lower_index

        value = sorted_data[lower_index].total_load * (1 - fraction)
              + sorted_data[upper_index].total_load * fraction

        result[percentile] = value
    END FOR

    RETURN result
END FUNCTION
```

## 4. 数据下采样算法（LTTB）

```
算法：最大三角形三桶算法（LTTB）

输入：
  - data: 原始数据点列表 (x, y)
  - target_count: 目标数据点数量

输出：
  - sampled: 下采样后的数据点列表

流程：
FUNCTION LTTBDownsample(data, target_count):
    n = LENGTH(data)

    // 数据量不足，直接返回
    IF n <= target_count THEN
        RETURN data
    END IF

    sampled = []
    sampled[0] = data[0]  // 保留首点

    bucket_size = (n - 2) / (target_count - 2)

    FOR i = 1 TO target_count - 2:
        // 计算下一个 bucket 的平均点
        bucket_start = FLOOR(i * bucket_size) + 1
        bucket_end = MIN(FLOOR((i + 1) * bucket_size) + 1, n - 1)

        avg_x = 0
        avg_y = 0
        FOR j = bucket_start TO bucket_end - 1:
            avg_x += data[j].x
            avg_y += data[j].y
        END FOR
        avg_x /= (bucket_end - bucket_start)
        avg_y /= (bucket_end - bucket_start)

        // 计算当前 bucket 的范围
        current_start = FLOOR((i - 1) * bucket_size) + 1
        current_end = MIN(FLOOR(i * bucket_size) + 1, n)

        // 在当前 bucket 中找到最大三角形面积的点
        max_area = -1
        selected_point = current_start
        prev_point = sampled[LENGTH(sampled) - 1]

        FOR j = current_start TO current_end - 1:
            area = CalculateTriangleArea(
                prev_point.x, prev_point.y,
                data[j].x, data[j].y,
                avg_x, avg_y
            )

            IF area > max_area THEN
                max_area = area
                selected_point = j
            END IF
        END FOR

        sampled[LENGTH(sampled)] = data[selected_point]
    END FOR

    sampled[LENGTH(sampled)] = data[n - 1]  // 保留末点

    RETURN sampled
END FUNCTION

// 三角形面积计算（向量叉积法）
FUNCTION CalculateTriangleArea(x1, y1, x2, y2, x3, y3):
    // 计算向量 AB 和 AC 的叉积
    cross_product = ABS((x1 - x3) * (y2 - y1) - (x1 - x2) * (y3 - y1))
    area = cross_product * 0.5

    RETURN area
END FUNCTION

// 数据下采样策略
FUNCTION DownsampleStrategy(data, target_count):
    n = LENGTH(data)

    IF n <= 500 THEN
        // 数据量小，不进行下采样
        RETURN data
    ELSE IF n <= 2000 THEN
        // 中等数据量，下采样到 500 点
        RETURN LTTBDownsample(data, MIN(target_count, 500))
    ELSE IF n <= 10000 THEN
        // 大数据量，下采样到 1000 点
        RETURN LTTBDownsample(data, MIN(target_count, 1000))
    ELSE
        // 超大数据量，下采样到 5000 点
        RETURN LTTBDownsample(data, MIN(target_count, 5000))
    END IF
END FUNCTION
```

## 5. 容量验证算法

```
算法：冷机容量验证

输入：
  - hourly_loads: 逐时负荷数据 (kW)
  - installed_capacity: 装机容量 (kW)
  - n_plus_one_enabled: 是否启用 N+1 冗余

输出：
  - validation_result: 验证结果

流程：
FUNCTION ValidateCapacity(hourly_loads, installed_capacity, n_plus_one_enabled):
    peak_load = MAX(hourly_loads)
    avg_load = AVERAGE(hourly_loads)

    // 基本容量检查
    capacity_passed = peak_load <= installed_capacity

    // 计算余量
    margin = (installed_capacity - peak_load) / installed_capacity * 100

    // N+1 冗余检查（如果启用）
    n_plus_one_passed = true
    IF n_plus_one_enabled THEN
        // 假设 N+1 要求余量 > 20%
        n_plus_one_passed = margin >= 20
    END IF

    // 低负荷运行时间分析
    low_load_hours = COUNT(h WHERE hourly_loads[h] < installed_capacity * 0.3)
    low_load_ratio = low_load_hours / 8760 * 100

    RETURN {
        peak_load,
        avg_load,
        capacity_passed,
        n_plus_one_passed,
        margin,
        low_load_hours,
        low_load_ratio,
        warnings: GenerateWarnings(low_load_ratio, margin)
    }
END FUNCTION

// 生成警告信息
FUNCTION GenerateWarnings(low_load_ratio, margin):
    warnings = []

    IF low_load_ratio > 50 THEN
        APPEND "低负荷运行时间超过50%，建议优化系统容量" TO warnings
    END IF

    IF margin < 10 THEN
        APPEND "容量余量不足10%，存在超负荷运行风险" TO warnings
    END IF

    IF margin > 50 THEN
        APPEND "容量余量超过50%，系统可能存在过度配置" TO warnings
    END IF

    RETURN warnings
END FUNCTION
```
