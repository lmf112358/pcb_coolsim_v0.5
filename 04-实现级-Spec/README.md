## 文档职责

### 计算逻辑

#### 静态冷量计算实现

- **职责**：详细定义静态冷量计算的算法、公式、步骤
- **PRD 引用**：F4-001, F4-002, F4-003
- **核心内容**：
  - 6 步计算流水线详细算法
  - 计算公式和参数说明
  - 输入输出字段映射
  - 精度要求（< 0.1%）
  - 确定性等级定义

#### 动态仿真计算实现

- **职责**：详细定义动态仿真计算的算法、公式、步骤
- **PRD 引用**：F6-001, F6-002, F6-003
- **核心内容**：
  - 气象数据驱动仿真算法
  - 比例系数法仿真算法
  - 8760h 逐时计算算法
  - 计算精度要求（< 1%）

#### 8760h 数据处理实现

- **职责**：详细定义 8760h 数据的存储、查询、聚合算法
- **PRD 引用**：F7-001, F7-002, F7-003, F7-004
- **核心内容**：
  - 数据存储方案
  - 数据查询优化
  - 数据聚合算法
  - 性能要求（1000+ 功能区域 < 30 秒）

#### 算法伪代码

- **职责**：提供核心算法的伪代码，便于理解和实现
- **PRD 引用**：F4-001, F6-001
- **核心内容**：
  - 静态冷量计算伪代码
  - 动态仿真计算伪代码
  - 8760h 数据聚合伪代码
