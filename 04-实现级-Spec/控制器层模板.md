## 1. 概述

控制器层由 DRF ViewSet + Serializer 组成，职责：**请求解析 -> 权限校验 -> 调用服务层 -> 统一信封返回 -> 错误码映射**。以「房间 CRUD」为例给出可复制模板。统一响应信封 `{success, data, error}`，错误码取自《API总览》附录。

---

## 2. 统一响应信封与错误码

```python
# api/responses.py
from rest_framework.response import Response


def ok_response(data, status=200):
    return Response({"success": True, "data": data}, status=status)


def error_response(code, message, status=400):
    return Response({"success": False, "error": {"code": code, "message": message}}, status=status)
```

错误码映射（节选，全量见 API总览 §附录）：

| Code | HTTP | 触发场景 |
|------|------|----------|
| VALIDATION_ERROR | 400 | 序列化器校验失败 |
| RESOURCE_NOT_FOUND | 404 | 资源不存在 |
| DUPLICATE_RESOURCE | 409 | 唯一约束冲突 |
| CALCULATION_ERROR | 422 | 计算参数非法（F4-014 等） |
| INSUFFICIENT_PERMISSIONS | 403 | 越权访问（F1-026） |

## 3. Serializer 模板

```python
# api/serializers/room.py
from rest_framework import serializers
from ...models.room import Room


class RoomSerializer(serializers.ModelSerializer):
    volume = serializers.DecimalField(max_digits=12, decimal_places=2, read_only=True)  # [CALC] 只读

    class Meta:
        model = Room
        fields = [
            "id", "floor", "room_name", "room_code", "area", "height", "volume",
            "design_temp_requirement", "design_humidity_requirement",
            "indoor_calc_temp", "indoor_calc_humidity",
            "cleanliness_level", "status", "created_at", "updated_at",
        ]
        read_only_fields = ["id", "volume", "created_at", "updated_at"]

    def validate(self, attrs):
        # 必填校验（F2-015）：area / height / room_name 由模型必填保证
        if attrs.get("area") is not None and attrs["area"] <= 0:
            raise serializers.ValidationError({"area": "面积必须为正数"})
        return attrs
```

## 4. ViewSet 模板（CRUD + 权限 + 计算动作）

```python
# api/views/room.py
from rest_framework import viewsets
from rest_framework.permissions import IsAuthenticated
from rest_framework.decorators import action
from rest_framework.response import Response
from ..serializers.room import RoomSerializer
from ...models.room import Room
from ...services.static_load import RoomStaticLoadService
from ..responses import ok_response, error_response


class RoomViewSet(viewsets.ModelViewSet):
    serializer_class = RoomSerializer
    permission_classes = [IsAuthenticated]      # F1-024/025 JWT 认证

    def get_queryset(self):
        # 项目级数据隔离（F1-026）：仅返回当前用户有权限的项目下的房间
        qs = Room.objects.all()
        floor_id = self.request.query_params.get("floor")
        if floor_id:
            qs = qs.filter(floor_id=floor_id)
        return qs.filter(floor__building__project__members=self.request.user)

    def perform_create(self, serializer):
        serializer.save()   # 保存时 volume 自动计算（见模型层模板）

    # 单房间静态计算（F4-024）：POST /api/v1/rooms/{id}/calculate-static/
    @action(detail=True, methods=["post"], url_path="calculate-static")
    def calculate_static(self, request, pk=None):
        season_id = request.data.get("season_id")
        if not season_id:
            return error_response("VALIDATION_ERROR", "season_id 必填", status=400)
        result = RoomStaticLoadService().calculate(int(pk), int(season_id))
        if not result.success:
            http = 422 if result.error_code == "CALCULATION_ERROR" else 400
            return error_response(result.error_code, result.message, status=http)
        return ok_response(result.data)
```

URL 注册（router）：

```python
router.register(r"rooms", RoomViewSet, basename="room")
```
