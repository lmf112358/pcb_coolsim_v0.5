## 1. 概述

本文档给出 Django Model 的可复制模板，字段类型严格对齐《数据库设计文档》§4 的 15 张表与字段分类（[INPUT]/[SEED]/[CALC]/[RESULT]）。工程师新建任何一张表时，先查 §2 映射表、再套用 §3~§6 约定，最后参考 §7 的 project / room 完整示例即可编码。

**奥卡姆剃刀**：本模板仅使用《数据库设计文档》已定义的字段，不引入任何新实体；如需扩展以 §8「待确认」列出。

---

## 2. 字段类型映射表

| 数据库设计类型 | 必填约定 | Django 字段 | 说明 |
|------|------|------|------|
| BIGINT PK | 是 | `models.BigAutoField(primary_key=True)` | 自增主键，禁止手动赋值 |
| BIGINT FK | 视业务 | `models.ForeignKey('Target', on_delete=..., related_name='...')` | 见 §4 关系约定 |
| VARCHAR(n) | 视业务 | `models.CharField(max_length=n)` | 必填去 `blank/null`；选填加 `blank=True, null=True` |
| DECIMAL(x,y) | 视业务 | `models.DecimalField(max_digits=x, decimal_places=y)` | 金额/负荷/温湿度统一用 Decimal，禁止 Float |
| DATETIME | 是 | `models.DateTimeField(auto_now_add=True / auto_now=True)` | created_at 用 auto_now_add，updated_at 用 auto_now |
| JSON | 否 | `models.JSONField(blank=True, null=True)` | 仅 ConversationSession 的 stage_status / draft_payload |
| TEXT | 否 | `models.TextField(blank=True, null=True)` | 长文本备注 |

**字段分类映射**（仅作注释，不建模）：

- `[INPUT]`：用户录入，序列化器必填/选填由数据库设计"必填"列决定
- `[SEED]`：系统预置（CityConfig），Model 只读，无写入接口
- `[CALC]` / `[RESULT]`：由计算服务写入，Model 层仅声明字段；计算逻辑见《计算逻辑/静态冷量计算实现.md》

## 3. 通用基类 BaseModel

所有业务表继承 BaseModel，统一主键与审计字段，禁止在各表重复定义。

```python
# models/base.py
from django.db import models


class BaseModel(models.Model):
    id = models.BigAutoField(primary_key=True)
    created_at = models.DateTimeField(auto_now_add=True, verbose_name="创建时间")
    updated_at = models.DateTimeField(auto_now=True, verbose_name="更新时间")

    class Meta:
        abstract = True
```

## 4. 外键关系约定

| 关系 | on_delete | related_name | 说明 |
|------|-----------|--------------|------|
| project -> CityConfig | `PROTECT` | `projects` | 城市为预置数据，禁止级联删除 |
| building -> project | `CASCADE` | `buildings` | 删项目级联删建筑 |
| floor -> building | `CASCADE` | `floors` | 删建筑级联删楼层 |
| room -> floor | `CASCADE` | `rooms` | 删楼层级联删房间 |
| Room -> room / SeasonConfig | `CASCADE` | `load_parameters` | 维度 (room_id, season_id) |
| ExtraLoad -> project / building(可空) / SeasonConfig | `CASCADE` | `extra_loads` | building 为空表示项目级 |
| ConversationSession -> project | `CASCADE` | `sessions` | 对话会话归属项目 |

**规则**：

- 父级删除必须 `CASCADE` 或 `PROTECT`；预置数据（CityConfig）一律 `PROTECT`。
- `related_name` 使用复数蛇形名，便于反向查询（`project.rooms.all()`）。
- 外键字段名与数据库设计一致（`project_id`、`floor_id`、`room_id`、`city_id`、`season_id`、`water_temp_config_id`、`building_id`）。

## 5. Meta 约定（ordering / indexes / unique_together）

```python
class Meta:
    db_table = "room"                       # 必须显式指定，与数据库设计表名一致
    ordering = ["room_code", "room_name"]   # 默认排序，避免无 order 的全表扫描
    verbose_name = "房间"
    verbose_name_plural = "房间"
    indexes = [
        models.Index(fields=["floor_id"], name="idx_room_floor"),
    ]
    constraints = [
        models.UniqueConstraint(
            fields=["room_id", "season_id"],
            name="uniq_room_season_load_param",
        ),
    ]
```

- `db_table` 必须显式设置，禁止依赖 Django 默认复数命名。
- 外键字段一律建普通索引（数据库设计 §5.3）。
- 维度唯一约束用 `UniqueConstraint` 实现（如 Room 的 (room_id, season_id)），不要用 `unique_together`（已废弃写法仍可运行，但优先 Constraint）。
- 业务索引命名统一前缀 `idx_<table>_<field>`。

## 6. 常用方法约定

- `__str__`：返回人类可读标识（名称 + 编号），用于 admin / 日志。
- 计算字段：只读 `[CALC]` 字段（如 room.volume）在 `save()` 中自动计算，禁止由用户传入。
- 状态字段：room.status 用 `choices` 枚举（`draft` / `active`），对话草稿写入 draft。

```python
def __str__(self):
    return f"{self.room_name}({self.room_code or '-'})"

def save(self, *args, **kwargs):
    # volume = area * height 自动计算（对应 F2-016）
    if self.area is not None and self.height is not None:
        self.volume = self.area * self.height
    super().save(*args, **kwargs)
```

## 7. 完整示例：Project 与 Room

```python
# models/project.py
from django.db import models
from .base import BaseModel
from .city import CityConfig


class Project(BaseModel):
    project_name = models.CharField(max_length=200, verbose_name="项目名称")
    project_code = models.CharField(max_length=50, blank=True, null=True, verbose_name="项目编号")
    description = models.CharField(max_length=500, blank=True, null=True, verbose_name="项目描述")
    location = models.CharField(max_length=200, blank=True, null=True, verbose_name="项目地址")
    city = models.ForeignKey(
        CityConfig, on_delete=models.PROTECT,
        related_name="projects", verbose_name="关联城市",
    )

    class Meta:
        db_table = "project"
        ordering = ["-created_at"]
        verbose_name = "项目"
        indexes = [models.Index(fields=["city_id"], name="idx_project_city")]

    def __str__(self):
        return f"{self.project_name}({self.project_code or '-'})"
```

```python
# models/room.py
from django.db import models
from .base import BaseModel
from .floor import Floor


class Room(BaseModel):
    floor = models.ForeignKey(
        Floor, on_delete=models.CASCADE,
        related_name="rooms", verbose_name="关联楼层",
    )
    room_name = models.CharField(max_length=100, verbose_name="房间名称")
    room_code = models.CharField(max_length=50, blank=True, null=True, verbose_name="房间编号")
    area = models.DecimalField(max_digits=10, decimal_places=2, verbose_name="面积")
    height = models.DecimalField(max_digits=5, decimal_places=2, verbose_name="高度")
    volume = models.DecimalField(max_digits=12, decimal_places=2, blank=True, null=True, verbose_name="体积[CALC]")
    design_temp_requirement = models.CharField(max_length=50, blank=True, null=True, verbose_name="设计温度要求")
    design_humidity_requirement = models.CharField(max_length=50, blank=True, null=True, verbose_name="设计湿度要求")
    indoor_calc_temp = models.DecimalField(max_digits=5, decimal_places=2, blank=True, null=True, verbose_name="室内计算温度")
    indoor_calc_humidity = models.DecimalField(max_digits=5, decimal_places=2, blank=True, null=True, verbose_name="室内计算相对湿度")
    cleanliness_level = models.CharField(max_length=50, blank=True, null=True, verbose_name="洁净度等级")
    description = models.CharField(max_length=500, blank=True, null=True, verbose_name="房间描述")
    status = models.CharField(
        max_length=20, default="active",
        choices=[("draft", "草稿"), ("active", "已确认")],
        verbose_name="房间状态",
    )

    class Meta:
        db_table = "room"
        ordering = ["room_code", "room_name"]
        verbose_name = "房间"
        indexes = [models.Index(fields=["floor_id"], name="idx_room_floor")]

    def __str__(self):
        return self.room_name

    def save(self, *args, **kwargs):
        if self.area is not None and self.height is not None:
            self.volume = self.area * self.height
        super().save(*args, **kwargs)
```
