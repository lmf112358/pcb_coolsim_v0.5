## 1. 架构概述

### 1.1 设计原则

| 原则 | 描述 |
|-----------|-------------|
| 关注点分离 | 前端、后端、计算引擎与数据层之间的清晰分离 |
| 单一职责 | 每个模块负责一个独立的业务领域 |
| 开闭原则 | 计算引擎支持公式扩展而无需修改核心逻辑 |
| 数据完整性 | 所有计算均可追溯至源输入，并具备清晰的审计轨迹 |
| 性能 | 支持 1000+ 房间，常见操作实现亚秒级响应 |
| 可扩展性 | 异步计算任务的水平扩展能力 |

```
┌─────────────────────────────────┐

        │
        ▼
┌─────────────────────────────────┐

│  步骤 1：焓值计算   │
│  步骤 2：末端负荷计算     │

│  步骤 4：新风负荷计算    │

│  步骤 6：负荷聚合       │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│ 存储结果                   │
│  - room_load_result             │
│  - room_air_volume_result       │

└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│ 返回响应                 │
│  - 计算结果          │
│  - 校验警告          │
│  - 实时缓存键      │
└─────────────────────────────────┘
```

### 4.2 实时预览流程

```
用户修改房间参数
        │
        ▼
┌─────────────────────────────────┐
│ 前端：防抖（500ms）      │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│ API Endpoint: /api/v1/rooms/{id}/preview/ │
│  - 轻量计算      │
│  - 仅返回受影响的值 │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│ Redis 缓存检查               │
│  - Cache key: room:{id}:params:{hash} │
│  - TTL：30 秒              │
└─────────────────────────────────┘
        │
        ▼ (cache miss)
┌─────────────────────────────────┐
│ 计算引擎              │
│  - 执行步骤 1-5            │
│  - 跳过步骤 6（聚合）    │
└─────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────┐
│ 缓存结果并返回           │
└─────────────────────────────────┘
```

## 6. 安全架构

### 6.1 认证与授权

```
┌─────────────────────────────────────────┐
│ JWT 认证流程                 │
├─────────────────────────────────────────┤
│ 1. 客户端发送凭据             │
│ 2. 服务端校验并返回：          │
│    - 访问令牌（15 分钟 TTL）          │
│    - 刷新令牌（7 天 TTL）         │
│ 3. 客户端安全存储令牌        │
│ 4. 客户端在请求头中发送访问令牌  │
│ 5. 收到 401 时客户端使用刷新令牌    │
│ 6. 若刷新令牌无效，重定向至登录│
└─────────────────────────────────────────┘
```

### 6.2 权限矩阵

| 资源 | 管理员 | 项目经理 | 工程师 | 访客 |
|----------|-------|-----|----------|--------|
| 用户管理 | CRUD | - | - | - |
| 项目（本人） | CRUD | CRUD | R | R |
| 项目（他人） | CRUD | - | - | - |
| 建筑/楼层/房间 | CRUD | CRUD | CRUD | R |
| 计算 | 执行 | 执行 | 执行 | - |
| 导出 | 全部 | 全部 | 全部 | 查看 |
| 设置 | CRUD | R | R | R |

### 6.3 数据隔离

- 在项目层级实施数据隔离，于查询层强制执行
- 用户仅可访问其所属的项目
- 项目内基于角色的访问控制
- API 端点在数据访问前校验项目成员资格

## 7. 性能架构

### 7.1 性能目标

| 操作 | 目标 | 策略 |
|-----------|--------|----------|
| 树形导航（1000 节点） | < 2s | 虚拟滚动 |
| 实时预览 | < 500ms | Redis 缓存 + 轻量计算 |
| 静态计算（1000 房间） | < 10s | 批处理 |
| 动态仿真（8760h × 3 年） | < 30s | 异步 + 并行处理 |
| 地图渲染 | < 3s | 瓦片缓存 |
| 2D 编辑器（100 房间） | < 3s | 画布优化 |

### 7.2 缓存策略

| 层 | 缓存类型 | 生存时间 | 失效 |
|-------|-----------|-----|--------------|
| 浏览器 | LocalStorage | 会话 | 手动 |
| API | Redis | 30s | 更新时 |
| 数据库 | 查询缓存 | 5min | 写入时 |
| CDN | 静态资源 | 1 年 | 版本化 |

### 7.3 数据库优化

- 对频繁查询的字段建立策略性索引
- 使用 JSONB 进行灵活配置存储
- 使用物化视图处理复杂聚合
- 使用连接池处理并发请求
- 使用只读副本处理报表查询

## 9. 监控与可观测性

### 9.1 指标采集

- **应用指标：** 请求延迟、错误率、活跃用户
- **业务指标：** 计算耗时、导出次数、用户活动
- **基础设施指标：** CPU、内存、磁盘、网络
- **数据库指标：** 查询性能、连接池、缓存命中率

### 9.2 日志策略

| 级别 | 用途 | 示例 |
|-------|---------|---------|
| DEBUG | 开发调试 | 变量取值、函数入口/出口 |
| INFO | 业务事件 | 用户登录、计算开始 |
| WARNING | 性能下降 | 慢查询、缓存未命中 |
| ERROR | 应用错误 | 计算失败、API 错误 |
| CRITICAL | 系统故障 | 数据库连接丢失 |

### 9.3 告警规则

- API 响应时间 > 2s（告警）
- API 错误率 > 5%（严重）
- 数据库连接池 > 80%（告警）
- Celery 任务失败率 > 10%（严重）
- 磁盘使用率 > 80%（告警）

## 10. 错误处理策略

### 10.1 错误分类

| 类别 | HTTP 状态码 | 示例 | 处理方式 |
|----------|-----------|---------|----------|
| 校验错误 | 400 | 输入无效 | 返回详细校验错误 |
| 认证 | 401 | 令牌无效 | 重定向至登录 |
| 授权 | 403 | 权限不足 | 显示权限拒绝 |
| 未找到 | 404 | 资源不存在 | 显示 404 页面 |
| 冲突 | 409 | 重复资源 | 显示冲突消息 |
| 计算错误 | 422 | 参数无效 | 返回特定计算错误 |
| 服务器错误 | 500 | 意外错误 | 记录错误并显示通用消息 |

### 10.2 计算错误处理

```
计算错误类型：
├── 输入校验 Errors
│   ├── 缺失必填字段
│   ├── 取值越界
│   └── 字段组合无效
├── 计算错误
│   ├── 除以零（已通过默认值处理）
│   ├── 无效焓湿状态
│   └── 溢出/下溢
└── 系统错误
    ├── 数据库连接失败
    ├── 缓存不可用
    └── 外部 API 失败
```
