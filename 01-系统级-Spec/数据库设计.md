# PCB冷量仿真系统 - 数据库设计文档

> 版本：V1.0  
> 日期：2026-06-25  
> 状态：初稿

---

## 1. 文档概述

### 1.1 目的

本文档描述PCB冷量仿真系统的数据库设计方案，用于指导后续开发实施。

### 1.2 系统简介

PCB冷量仿真系统用于计算PCB工厂各房间的冷热负荷。系统以房间为最小计算单元，核心计算公式：

```
房间总负荷 = 新风冷负荷 + 末端负荷

末端负荷 = 土建负荷 + 照明负荷 + 人员负荷 + 设备负荷（电动 + 电热）

新风冷负荷 = f(新风量, 室内外焓差)
```

负荷按不同温度的冷冻水进行分类（如低温7/12℃、中温12/17℃等），温度范围可灵活配置。

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| 字段分类 | 明确区分**用户输入字段**、**计算中间结果**、**最终计算结果** |
| 必填标识 | 区分必填字段与可选字段，允许部分字段空缺 |
| 扩展性 | 水温配置、季节配置独立存储，支持不同工厂差异化需求 |
| 通用性 | 温度范围、季节类型等均可自定义，不硬编码 |

### 1.4 字段分类约定

本文档中所有表字段按以下四种类型标注：

| 类型 | 标记 | 说明 |
|------|------|------|
| 用户输入 | `[INPUT]` | 用户手动录入的原始数据 |
| 系统预置 | `[SEED]` | 系统部署时从外部数据源批量导入的参考数据，用户不直接输入 |
| 中间结果 | `[CALC]` | 系统根据公式计算得出的中间值 |
| 最终结果 | `[RESULT]` | 最终输出的计算结果 |

## 2. 总体ER关系

```
city_config (城市配置：城市基础信息 + 国标室外设计参数) [SEED]

project (项目/工厂)
  ├── city_id → city_config (关联城市，获取国标室外参数)
  ├── building (建筑)
  │     ├── floor (楼层)
  │           └── room (房间)
  │                 ├── room_load_parameter (负荷计算参数) [INPUT]
  │                 ├── room_load_result (负荷计算结果) [CALC/RESULT]
  │                 ├── room_air_volume_parameter (风量计算参数) [INPUT]
  │                 ├── room_air_volume_result (风量计算结果) [CALC/RESULT]
  │                 └── room_load_summary (房间负荷汇总) [RESULT]
  ├── extra_load (额外负荷) [INPUT]  -- building_id有值为建筑级，为空为项目级
  ├── water_temperature_config (冷冻水温度配置) [INPUT]
  ├── season_config (季节配置) [INPUT]
  └── load_summary (多级负荷汇总) [CALC]
```

## 4. 表结构详细设计

### 4.1 project - 项目表

存储项目基本信息。

| 字段名 | 类型 | 必填 | 分类 | 说明 |
|--------|------|------|------|------|
| id | BIGINT PK | 是 | - | 主键，自增 |
| project_name | VARCHAR(200) | 是 | [INPUT] | 项目名称 |
| project_code | VARCHAR(50) | 否 | [INPUT] | 项目编号 |
| description | VARCHAR(500) | 否 | [INPUT] | 项目描述 |
| location | VARCHAR(200) | 否 | [INPUT] | 项目详细地址（如"黄埔区XX路XX号"），仅用于展示 |
| city_id | BIGINT FK | 是 | [INPUT] | 关联城市（从city_config选择，获取该城市国标室外设计参数） |
| created_at | DATETIME | 是 | - | 创建时间 |
| updated_at | DATETIME | 是 | - | 更新时间 |

**字段说明：**
- `city_id`：必填，关联城市配置表，项目选择城市后自动获取该城市的国标室外设计参数（大气压、温湿度等）和基础信息（经纬度、海拔等），是计算链路的必要前提
- `location`：非必填，项目的详细街道地址，仅用于展示和备注，不参与计算

### 4.4 room - 房间表

系统最小计算单元。

| 字段名 | 类型 | 必填 | 分类 | 说明 |
|--------|------|------|------|------|
| id | BIGINT PK | 是 | - | 主键，自增 |
| floor_id | BIGINT FK | 是 | [INPUT] | 关联楼层 |
| water_tier_id | BIGINT FK | 否 | [INPUT] | 关联冷冻水温度档位（`water_temperature_config.id`），房间末端负荷归属的水温档（ADR-0001），默认中温(12/17℃) |
| room_name | VARCHAR(100) | 是 | [INPUT] | 房间名称（如"光刻间"、"洁净走廊"） |
| room_code | VARCHAR(50) | 否 | [INPUT] | 房间编号 |
| area | DECIMAL(10,2) | 是 | [INPUT] | 房间面积(m²) |
| height | DECIMAL(5,2) | 是 | [INPUT] | 房间高度(m) |
| volume | DECIMAL(12,2) | 是 | [CALC] | 房间体积(m³)，由 area × height 自动计算 |
| **设计温湿度要求** | | | | |
| design_temp_requirement | VARCHAR(50) | 否 | [INPUT] | 设计温度要求，如"23±2"、"≤26"、"-" |
| design_humidity_requirement | VARCHAR(50) | 否 | [INPUT] | 设计相对湿度要求，如"55±5"、"-" |
| **室内计算温湿度** | | | | |
| indoor_calc_temp | DECIMAL(5,2) | 否 | [INPUT] | 室内计算温度(℃)，用于焓值等后续计算的定值 |
| indoor_calc_humidity | DECIMAL(5,2) | 否 | [INPUT] | 室内计算相对湿度(%)，用于焓值等后续计算的定值 |
| cleanliness_level | VARCHAR(50) | 否 | [INPUT] | 洁净度等级（如ISO 5、ISO 7） |
| description | VARCHAR(500) | 否 | [INPUT] | 房间描述 |
| status | VARCHAR(20) | 否 | [INPUT] | 房间状态：draft（对话草稿暂存）/active（已确认）；对话采集可先以 draft 写入，确认后转 active |
| created_at | DATETIME | 是 | - | 创建时间 |
| updated_at | DATETIME | 是 | - | 更新时间 |

**字段说明：**
- `volume` 由 `area × height` 自动计算，用于压差渗透风量计算
- `design_temp_requirement`、`design_humidity_requirement` 直接存储Excel原始文本（如"23±2"、"≤26"、"55±5"、"-"），仅用于展示和验收，不参与计算
- `indoor_calc_temp`、`indoor_calc_humidity` 为用户指定的室内计算温湿度定值，用于焓值计算、负荷计算等后续工程计算
- `water_tier_id` 房间所属冷冻水温度档位，决定末端负荷归入哪一水温档（ADR-0001）；模块-04 SQL 已引用但 §4 原缺失，本修订补列

**典型数据示例（广州市）：**

| 字段 | 数值 |
|------|------|
| city_name | 广州 |
| province | 广东 |
| station_code | 59287 |
| latitude / longitude | 23°08' / 113°20' |
| altitude | 6.6 |
| pressure_summer / pressure_winter | 1004.0 / 1019.0 |
| wind_speed_summer / wind_speed_winter | 1.7 / 1.7 |
| temp_dry_ac_summer / temp_wet_ac_summer | 34.2 / 27.8 |
| temp_dry_vent_summer | 31.8 |

**说明：**
- 数据来源：国标《工业室外空气计算参数》Excel文件（工业室外空气计算参数.xlsx），系统部署时一次性批量导入约300个城市
- 该表为系统级只读参考数据，普通用户不可编辑，创建项目时从城市下拉列表选择即可
- 字段名中的 `_summer` / `_winter` 后缀标识季节归属
- 大气压力单位为 hPa（百帕），与国标Excel一致（1 hPa = 100 Pa）
- 焓值不在此表存储，计算时根据温湿度和大气压实时计算
- 多个项目选择同一城市时共享该城市的数据
- 国标Excel中还有22个其他参数（年平均温度、极端温度、供暖期天数、风向频率等），数据已保存在Excel文件中，后续需要时可按需导入

### 4.9 room_load_result - 房间负荷计算结果表

存储负荷计算的各项结果，对应Excel"房间负荷估算表"计算结果列。

| 字段名 | 类型 | 必填 | 分类 | 说明 |
|--------|------|------|------|------|
| id | BIGINT PK | 是 | - | 主键，自增 |
| room_id | BIGINT FK | 是 | - | 关联房间 |
| season_id | BIGINT FK | 是 | - | 关联季节 |
| **中间结果** | | | | |
| civil_load | DECIMAL(10,4) | 否 | [CALC] | 土建负荷(KW) |
| lighting_load | DECIMAL(10,4) | 否 | [CALC] | 照明负荷(KW) |
| personnel_load | DECIMAL(10,4) | 否 | [CALC] | 人员负荷(KW) |

| **最终结果** | | | | |
| terminal_load | DECIMAL(10,4) | 是 | [RESULT] | 末端负荷合计(KW) |
| cold_load_index | DECIMAL(8,4) | 否 | [CALC] | 冷指标(W/m²) |

- UNIQUE(room_id, season_id)

**计算公式：**
```
civil_load = civil_load_index × area / 1000
lighting_load = lighting_load_index × area / 1000
personnel_load = personnel_load_index × personnel_count / 1000
electric_equipment_load = electric_equipment_power × electric_equipment_coefficient
heated_equipment_load = heated_equipment_power_with_exhaust × heated_equipment_coefficient_with_exhaust
                      + heated_equipment_power_without_exhaust × heated_equipment_coefficient_without_exhaust

terminal_load = civil_load + lighting_load + personnel_load
              + electric_equipment_load + heated_equipment_load
cold_load_index = terminal_load / area × 1000  (W/m²)
```

### 4.11 room_air_volume_result - 房间风量计算结果表

存储风量计算的各项结果，对应Excel"房间风量计算表"计算结果列。

| created_at | DATETIME | 是 | - | 创建时间 |
| updated_at | DATETIME | 是 | - | 更新时间 |

**约束：**
- UNIQUE(room_id, season_id)
- 本表为 8760h 逐时仿真结果的 TimescaleDB 超表（按 `room_id` + 时间 分区）；动态仿真逐时明细复用本表（ADR-0006），不另建表（PRD §19 别名 `DynamicLoadHourly` / `room_hourly_load_result` 均指向本表）；具体 `timestamp` 维度扩展与 §4.14 `load_summary` 协同确定

**计算公式：**
```
total_exhaust_volume = heat_exhaust + acid_exhaust + alkali_exhaust
                     + organic_exhaust + dust_exhaust
infiltration_air_volume = f(pressure_diff, room.volume)  -- 根据压差和房间体积计算
sanitary_air_volume = 人员数量 × 卫生风量标准
fresh_air_volume = MAX(infiltration_air_volume, sanitary_air_volume, 净化风量要求)
return_air_volume = supply_air_volume - fresh_air_volume
supply_air_volume = 消除负荷所需风量 或 净化风量要求（取大值）

indoor_enthalpy_calc = f(room.indoor_calc_temp, room.indoor_calc_humidity)
outdoor_enthalpy_calc = f(city_config 中当前季节对应的室外温湿度和大气压)
enthalpy_diff = outdoor_enthalpy_calc - indoor_enthalpy_calc
```

### 4.12 room_load_summary - 房间负荷汇总表（按水温分类）

存储按不同冷冻水温度分类的房间最终负荷结果，是系统的**核心输出表**。

| 字段名 | 类型 | 必填 | 分类 | 说明 |
|--------|------|------|------|------|
| id | BIGINT PK | 是 | - | 主键，自增 |
| room_id | BIGINT FK | 是 | - | 关联房间 |
| season_id | BIGINT FK | 是 | - | 关联季节 |
| water_temp_config_id | BIGINT FK | 是 | - | 关联冷冻水温度配置 |
| **最终结果** | | | | |
| fresh_air_load | DECIMAL(10,4) | 是 | [RESULT] | 新风冷负荷(KW) |
| fresh_air_carry_load | DECIMAL(10,4) | 否 | [CALC] | 新风带走负荷(KW) |
| terminal_load | DECIMAL(10,4) | 是 | [RESULT] | 末端负荷(KW) |
| total_load | DECIMAL(10,4) | 是 | [RESULT] | 总负荷(KW) |
| created_at | DATETIME | 是 | - | 创建时间 |
| updated_at | DATETIME | 是 | - | 更新时间 |

**约束：**
- UNIQUE(room_id, season_id, water_temp_config_id)

**计算公式：**
```
新风冷负荷 = fresh_air_volume × 空气密度 × 焓差 / 3600
           = fresh_air_volume × 1.2 × (outdoor_enthalpy - indoor_enthalpy) / 3600

```

**说明：**
- 同一房间在不同水温配置下各有一条记录（如低温7/12℃一条、中温12/17℃一条）
- `fresh_air_carry_load` 对应Excel中的"新风带走负荷"
- 此表为房间级负荷，可向上聚合到楼层、建筑、项目层级

## 6. 数据流转关系

```
用户输入阶段：
  room (面积、高度、温湿度要求、洁净度)
  season_config (季节定义：夏季/冬季/过渡季)
  city_config (城市配置：城市基础信息 + 国标10个核心室外设计参数)
      ↓
  room_load_parameter (土建指标、照明指标、人员参数、设备参数)
  room_air_volume_parameter (排风量、压差、换气次数等)
  extra_load (额外负荷：PCW、配电室空调、消防池保温等)
      ↓
计算阶段：
  室外焓值 ← 由city_config中当前季节对应的温湿度和大气压实时计算
      ↓
  room_load_result ← room_load_parameter + room.area
      ↓ 计算末端负荷 = 土建 + 照明 + 人员 + 电动设备 + 电热设备
      ↓
  room_air_volume_result ← room_air_volume_parameter + room + city_config
      ↓ 计算新风量、送风量、排风量、焓值等
      ↓
  room_load_summary ← room_air_volume_result + room_load_result + water_temperature_config + city_config
      ↓ 按水温分类计算新风冷负荷（使用当前季节对应的室外参数）
      ↓ 总负荷 = 新风冷负荷 + 末端负荷
      ↓
  load_summary ← room_load_summary + extra_load (聚合)
      ↓ 楼层汇总 ← 该楼层所有房间聚合
      ↓ 建筑汇总 ← 所有楼层汇总 + extra_load (building_id有值的记录)
      ↓ 项目汇总 ← 所有建筑汇总 + extra_load (building_id为空的记录)
```

> **对话采集通道写入语义（v0.5.1 补充）**：对话式采集（PRD §6.10）与 Tab1 树形/Excel 录入为同一数据集的两种录入通道，采用**逐区域提交 / 保存即落库**，与 Tab1 一致；⑥ 汇总预览仅做校验与确认，确认后状态标记完成。会话状态由 `conversation_session` 表持久化（F2-057 断点续采），房间草稿以 `room.status = draft` 暂存。

## 7. 扩展性设计说明

### 7.1 冷冻水温度灵活配置

不同工厂对冷冻水的温度范围定义不同：

| 工厂 | 低温 | 中温 |
|------|------|------|
| 工厂A | 7/12℃ | 12/17℃ |
| 工厂B | 7/13℃ | 13/18℃ |
| 工厂C | 5/10℃ | 10/15℃ |

通过 `water_temperature_config` 表，每个项目可独立配置自己的温度分类，无需修改表结构。

### 7.2 季节与室外参数扩展

默认支持夏季和冬季，可通过 `season_config` 表添加过渡季或其他自定义季节。

室外设计参数通过 `city_config` 表统一管理：
- 城市基础信息和10个核心国标参数存储在同一张表中，一个城市一条记录
- 国标Excel中还有22个其他参数（年平均温度、极端温度、供暖期天数、风向频率等），数据已保存在Excel文件中，后续需要时可按需导入数据库

### 7.3 排风类型扩展

当前排风类型以固定字段存储（热排风、酸性、碱性、有机、含尘）。如需扩展：
- **方式一**：在 `room_air_volume_parameter` 表中新增字段
- **方式二**：创建独立的 `room_exhaust_type` 表（排风类型字典 + 房间排风量关联表），实现完全动态配置

建议：如排风类型较为固定，使用方式一更简单；如需高度灵活，使用方式二。

### 7.4 负荷类别扩展

`load_summary` 中的 `category` 字段支持扩展新的负荷类别（如"空压机冷却"、"冷却塔散热"等），无需修改表结构。`extra_load` 的 `category` 同样支持扩展。
