## 1. 计算模块测试计划

### 1.1 概述

本文档为核心计算引擎提供详细测试用例，该引擎是 PCB-CoolSim 最关键的组件。计算精度要求：
- **静态计算：** 与参考数据偏差 < 0.1%
- **动态仿真：** 与参考数据偏差 < 1%

### 1.2 测试数据来源

1. **参考数据：** PCB工厂测试数据_西北_西安.xlsx（另有广州、胡志明两地）
2. **生成数据:** 覆盖边界情况的合成测试用例
3. **边界值:** 所有参数的最小值/最大值

## 2. 焓值计算测试（Step 1）

### 2.1 测试用例：TC-CALC-1.1 - 标准焓值计算

**目标：** 使用 psychrolib 验证焓值计算

**前置条件：**
- City: Xi'an (西安)
- 室外：35.2°C，45% RH，95920 Pa
- 室内：26°C，55% RH

**测试数据：**
```python
{
    "outdoor_temp": 35.2,  # °C
    "outdoor_humidity": 45,  # %
    "atmospheric_pressure": 95920,  # Pa
    "indoor_temp": 26.0,  # °C
    "indoor_humidity": 55  # %
}
```

**预期结果:**
```python
{
    "outdoor_enthalpy": 76.45,  # kJ/kg (±0.1)
    "indoor_enthalpy": 52.34,   # kJ/kg (±0.1)
    "enthalpy_diff": 24.11      # kJ/kg (±0.1)
}
```

**Validation Method:**
- 与 psychrolib 直接计算对比
- 与 Excel 参考值对比
- 容差：±0.1 kJ/kg
