## 文档职责

### 术语表

- **职责**：定义项目术语、公式、单位，确保团队理解一致
- **PRD 引用**：所有模块
- **核心内容**：
  - 专业术语定义
  - 计算公式说明
  - 单位换算
  - 缩写说明

### 架构决策记录

- **职责**：记录重要的架构决策，包括背景、选项、决策、后果
- **PRD 引用**：F4-001, F6-001, F5-001
- **核心内容**：
  - ADR-0001：末端负荷按房间级冷冻水档分配（推翻"全归中温"简化）
  - ADR-0002：异步任务使用 Celery + Redis
  - ADR-0003：两套比例系数表合并为一张权威表 `RatioCoefficient`（系数待校准）
  - ADR-0004：校验改为"运行容量"——**已取代（v0.5.1）**：冷站冷机容量校验作废，负荷分析装机容量校核（PRD F7-022~024）沿用运行容量原则
  - ADR-0005：已取代（v0.5.1）—— 模块五「冷站配置」移除，仅保留负荷分析
  - ADR-0006：数据库缺失实体补齐（User/Role/SimulationRun/WeatherRecord/RatioCoefficient，表名 PascalCase）
  - ADR-0007：对话式采集会话与消息表（ConversationSession/ConversationMessage），支撑 PRD §6.10 断点续采与历史回看

### 用户故事

- **职责**：定义用户故事和场景描述，帮助理解用户需求
- **PRD 引用**：F1-001 ~ F10-XXX
- **核心内容**：
  - 用户角色定义
  - 用户故事公式
  - 场景故事
  - 验收标准
