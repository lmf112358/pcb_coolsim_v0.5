# ADR-0004: Validation V3 - Operating Capacity Validation

**Status:** Accepted
**Date:** 2026-07-09
**Decision Makers:** Domain Expert, QA Lead, Architect

---

## Context

The cooling station configuration module needs to validate that the configured chillers can handle the calculated load. The validation approach evolved:

- **V1:** Total capacity >= Total load (too simplistic)
- **V2:** Capacity including backup >= Load (doesn't account for backup usage)
- **V3 (Current):** Operating capacity (excluding 1 standby) >= Load

The question is: when validating capacity vs load, should we include or exclude the backup chiller?

## Decision

**Validate "operating capacity" (total capacity minus one standby unit):**

```
Operating Capacity = Total Capacity - Capacity of largest single chiller
Validation: Operating Capacity >= Design Load
```

**Rationale:**
- In normal operation, backup chillers are offline
- System must meet load with N chillers, not N+1
- Backup is for redundancy, not normal operation

**Example:**
- 4 × 1000 RT chillers (3 operating + 1 backup)
- Total capacity: 4000 RT
- Operating capacity: 3000 RT
- Design load: 2800 RT
- Validation: 3000 >= 2800 → PASS

## Rationale

1. **Realistic:** Matches actual operating conditions
2. **Conservative:** Ensures system works without backup
3. **Industry Standard:** Aligns with HVAC design practices

## Consequences

### Positive
- More accurate validation
- Prevents undersized systems
- Clear pass/fail criteria

### Negative
- May require more chillers than V1/V2
- Users may need education on N+1 concept

### Risks
- Users may not understand "operating capacity" → Mitigated by clear UI messaging

## Alternatives Considered

### Alternative 1: V1 - Total Capacity >= Load
**Rejected:** Doesn't account for backup, can lead to undersized systems

### Alternative 2: V2 - Total Capacity Including Backup >= Load
**Rejected:** Unrealistic, backup is for emergencies only
