## 项目背景

### 项目概述

**PCB-CoolSim** 是一个基于 Web 的 PCB（印制电路板）制造工厂冷负荷计算与仿真平台。它用自动化、可视化、可协作的工具替代传统手工 Excel 计算。

### 目标用户

| 角色 | 描述 | 主要任务 |
|------|------|---------|
| **暖通工程师（HVAC Engineer）** | 核心用户，设计冷源系统 | 数据录入、计算、分析 |
| **项目经理（Project Manager）** | 管理多个冷源设计项目 | 评审、导出、汇报 |
| **系统管理员（System Admin）** | 管理系统与用户 | 配置、用户管理 |
| **查看者（Viewer）** | 评审设计成果 | 只读访问 |

### 业务领域

PCB 制造涉及多个发热显著的工序：
- **蚀刻（Etching）**：化学过程
- **电镀（Plating）**：电化学过程
- **压合（Lamination）**：高温压制
- **钻孔（Drilling）**：机械发热
- **洁净室（Clean Room）**：严格环境控制

每个工序对冷源需求不同，准确的负荷计算对以下方面至关重要：
- 设备选型（冷水机组、空调箱 AHU、风机盘管 FCU）
- 能效优化
- 工艺质量控制

## 术语表

### A

**ACH（Air Changes per Hour，换气次数）**
单位时间内房间空气被完全替换的次数，用于通风计算。

**AHU（Air Handling Unit，空调箱）**
集中式空调机组，对空气进行处理并分配。

**Area（面积）**
功能区域地面面积，单位平方米（m²），用于负荷计算。

### C

**Chiller（冷冻机/冷机）**  ⚠️ *v0.5 不实现冷站冷机选型（模块五冷站已移除），仅作通用 HVAC 术语保留*
制取冷冻水用于制冷的设备。类型：
- 离心式（Centrifugal）
- 螺杆式（Screw）
- 涡旋式（Scroll）

**Chilled Water Tier（冷冻水档）**
按水温分类：
- 低温（Low Temperature）：7/12°C 供/回水
- 中温（Mid Temperature）：12/17°C 供/回水

**City Config（城市配置）**
各城市的国标室外设计参数，含温度、湿度、大气压等。

**Clean Room（洁净室）**
具有特定洁净度等级（ISO 1-9）的受控环境房间。

**Coefficient Table（比例系数表）**
动态仿真中用于将静态负荷转换为逐时负荷的系数矩阵（ADR-0003，表名 `RatioCoefficient`）。

**Cooling Load（冷负荷）**
为维持目标环境所需移除的热量，单位 kW 或 RT（冷吨）。

**对话式采集（Conversational Data Collection）**
PRD §6.10 新增的第三种数据录入通道（与 Tab1 树形、Excel 导入并列）。系统按 SOP 六阶段主动提问，用户自然语言作答，回写同一 Room 单表。会话状态落 `ConversationSession`/`ConversationMessage`（ADR-0007），支持断点续采（F2-057）。

**CW（Cooling Water，冷却水）**
将冷水机组热量排至冷却塔的循环水。

### D

**Design Load（设计负荷）**
最不利工况（夏季设计日）下的最大冷负荷。

**Dew Point（露点）**
空气中水分开始凝结的温度。

**Dry Bulb Temperature（干球温度）**
标准温度计测量的空气温度。

**断点续采（Resume from Checkpoint）**
对话式采集的特性：会话状态服务端持久化，刷新或重开浏览器后从上次未完成节点继续（F2-057）。

### E

**Enthalpy（焓值）**
湿空气的总热含量，单位 kJ/kg，用于新风冷负荷计算。

**Extra Load（额外负荷）**
不与特定功能区域关联的冷负荷：
- PCW（工艺冷却水）
- 配电室空调
- 其他特殊负荷

**Exhaust Air（排风）**
从功能区域排出的空气，类型：
- 热排风（Heat exhaust）
- 酸性排风（Acid exhaust）
- 碱性排风（Alkaline exhaust）
- 有机排风（Organic exhaust）
- 含尘排风（Dust exhaust）

### F

**FCU（Fan Coil Unit，风机盘管）**
功能区域级别的空调末端设备。

**Floor（楼层）**
建筑层级，一栋建筑可含多个楼层。

**Fresh Air（新风）**
为通风引入室内的室外空气。

**Fresh Air Load（新风冷负荷）**
将室外新风处理到室内状态所需的冷量。公式：`Q_fresh = ρ × V_fresh × (h_outdoor − h_indoor) / 3600`，ρ=DefaultConfig.air_density 默认 1.2 kg/m³，焓值用 psychrolib。负荷可为负（冬季室外焓低于室内）；总负荷 < 0 截断为 0。

### H

**HVAC（Heating, Ventilation, Air Conditioning，暖通空调）**
建筑环境控制的机械系统总称。

### I

**Infiltration Air（渗透风）**
因压差通过建筑围护结构缝隙非预期渗入/渗出的空气。

### L

**Latent Heat（潜热）**
与空气中水分含量相关的热量。

**Load Density（负荷密度）**
单位面积的冷负荷，单位 W/m²。

### M

**Material（材质）**
影响传热的建筑材料属性。

### N

**National Standard（国标）**
中国建筑设计的国家标准：
- GB 50019：工业建筑供暖通风与空气调节设计规范
- GB 50736：民用建筑供暖通风与空气调节设计规范

### P

**PCW（Process Cooling Water，工艺冷却水）**
直接用于制造工艺的冷却水，作为 ExtraLoad 处理（项目级或建筑级）。

**PLR（Part Load Ratio，部分负荷率）**  ⚠️ *v0.5 不实现（绑定冷机容量的部分负荷率，随模块五冷站移除而搁置，v0.6 评估）*
实际负荷与冷机容量的比值。

### R

**Relative Humidity（相对湿度）**
空气中水分相对于饱和状态的百分比。

**Room（功能区域）**
系统的最小计算单元，代表工厂内的一个功能区。

**RT（Refrigeration Ton，冷吨）**
制冷量单位，1 RT = 3.517 kW。

### S

**Sensible Heat（显热）**
引起温度变化但不改变水分含量的热量。

**Simulation（仿真）**
在较长时间段（通常 8760 小时 × 多年）上逐时计算负荷的动态计算。

**Static Calculation（静态计算）**
基于最不利工况（夏季设计日）的设计负荷计算。

### T

**Terminal Load（末端负荷）**
由功能区域级设备（AHU、FCU）承担的冷负荷，包括：
- 土建负荷（Civil load）：来自建筑围护结构传热
- 照明负荷（Lighting load）：来自照明散热
- 人员负荷（Personnel load）：来自人员散热
- 设备负荷（Equipment load）：含电动设备 + 电热设备（有排风/无排风）

### V

**Volume（体积）**
功能区域体积，单位立方米（m³），计算式：面积 × 吊顶高度。

### W

**Wet Bulb Temperature（湿球温度）**
湿球温度计测量的温度，反映空气水分含量。

**Water Temperature Config（冷冻水温度配置）**
项目级的冷冻水供/回水温度配置（`WaterTempConfig` 表），预置低温 7/12°C、中温 12/17°C。

### 8

**8760 Hours（8760 小时）**
一个平年的总小时数，用于全年能耗分析。

### v0.5.1 补充术语（架构修订新增）

**末端冷冻水档（Terminal Chilled-Water Tier）**
功能区域末端负荷归属的冷冻水温度档（ADR-0001）。默认中温 12/17°C，用户可逐区指定为低温 7/12°C。存储于 `Room.terminal_water_temp_config_id`。

**温控精度（Temperature Control Precision）**
功能区域温度控制精度等级，枚举值 ±1 / ±2 / ±3 / ±5 / 无要求。参与工艺色编码判定（PRD F3-016，最高优先级）。存储于 `Room.temp_precision`。

**工艺色编码（Process Color Coding）**
2D 平面图双模式颜色编码之一（PRD F3-015/F3-016）。按优先级判定：温控精度 > 洁净度 > 压差，7 档色：①±1°C 红 ②±2°C 橙 ③ISO7 黄 ④ISO8 绿 ⑤ISO7.5 蓝 ⑥正压 紫 ⑦负压/普通 灰。SAC-6 验收依据。

**压差渗透风量（Pressure Differential Infiltration）**
因功能区域内外压差通过缝隙渗透的空气量。v0.5.1 使用 8 点查表线性插值（PRD §8.3 唯一权威表）：0Pa→0, |±1|→1.0, |±2|→1.5, |±3|→2.0, |±5|→3.0, |±10|→3.5, |±15|→4.0, >|±15| 封顶 4.0；正负压对称取绝对值。公式：`infiltration = room.volume × k(|pressure_diff|)`。

**比例系数法（Ratio Coefficient Method）**
动态仿真方式二与负荷预测共用算法（ADR-0003）。查 `RatioCoefficient` 统一权威表，动态仿真取负荷率=100% 列按室外温度查表，负荷预测用全表（温度×负荷率二维双线性插值）。

**26280**
3 年 × 8760 小时 ≈ 26280（含闰年约 26304），代表动态仿真三年逐时时间序列。每功能区域约 26280 个逐时负荷点。

**LTTB（Largest-Triangle-Three-Buckets）**
时间序列降采样算法。前端 26280 点图表渲染时用 LTTB 降采样到 2000~5000 点，保证 < 3s 渲染（NF-SAC-07）且保留波形特征。

**虚拟滚动（Virtual Scrolling）**
前端长列表性能优化技术。树形导航 100,000+ 功能区域节点（全项目合计，NF-001）使用虚拟滚动，仅渲染可视区域节点，< 2s 加载交互。

**装机容量校核（Installed Capacity Validation）**
模块七基础验证（PRD F7-022~024）。负荷持续时间曲线 + 装机容量线，校验：①充分性（全年峰值 ≤ 装机容量）；②经济性（避免全年 > 90% 时间负荷率 < 50%）。不通过红色警告 + 修改建议。

**四级继承（Four-Level Inheritance）**
默认值配置的覆盖优先级（PRD F2-041/F9-009）：功能区域显式值 > 楼层级 > 建筑级 > 项目级 > 系统默认值。

**TimescaleDB 超表（Hypertable）**
PostgreSQL 扩展 TimescaleDB 的分区表机制。`DynamicLoadHourly`（动态仿真逐时结果）与 `WeatherRecord`（逐时气象）建为超表，按时间 range 分区，支撑 26280×1000 量级数据 < 30s 查询（NF-006）。

## 领域公式

### 焓值计算
```
h = 1.006 × T + W × (2501 + 1.86 × T)

其中：
h = 焓值（kJ/kg）
T = 干球温度（°C）
W = 含湿量（kg/kg）
```

### 末端负荷（5 项，PRD §15.1）
```
末端负荷 = 土建负荷 + 照明负荷 + 人员负荷 + 电动设备负荷 + 电热设备负荷

其中：
土建负荷 = 面积 × 土建指标 / 1000
照明负荷 = 面积 × 照明指标 / 1000
人员负荷 = 人数 × 人员指标 / 1000
电动设备负荷 = 电动设备功率 × 电动设备系数
电热设备负荷 = 有排风功率 × 有排风系数 + 无排风功率 × 无排风系数
```

### 新风冷负荷（PRD §15.3）
```
新风冷负荷 = 新风量 × 空气密度 × 焓差 / 3600

其中：
新风量 = 总排风量 + 压差渗透风量（简单加法，A4 简化）
空气密度 ρ = DefaultConfig.air_density（默认 1.2 kg/m³）
焓差 = 室外焓值 − 室内焓值（可为负）
总负荷 = 末端负荷 + 新风冷负荷（< 0 截断为 0）
```
