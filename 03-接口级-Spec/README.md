## 接口职责

### API 接口

#### 认证接口

- **职责**：用户登录、Token 刷新、用户登出
- **PRD 引用**：F1-001
- **主要端点**：
  - `POST /api/v1/auth/login/` - 用户登录
  - `POST /api/v1/auth/refresh/` - Token 刷新
  - `POST /api/v1/auth/logout/` - 用户登出

#### 项目接口

- **职责**：项目 CRUD、四级层级结构操作
- **PRD 引用**：F1-003, F1-004
- **主要端点**：
  - `GET /api/v1/projects/` - 获取项目列表
  - `POST /api/v1/projects/` - 创建项目
  - `GET /api/v1/projects/{id}/` - 获取项目详情
  - `PUT /api/v1/projects/{id}/` - 更新项目
  - `DELETE /api/v1/projects/{id}/` - 删除项目

#### 房间接口

- **职责**：房间 CRUD、数据录入、Excel 导入
- **PRD 引用**：F2-001, F2-002, F2-003
- **主要端点**：
  - `GET /api/v1/rooms/` - 获取房间列表
  - `POST /api/v1/rooms/` - 创建房间
  - `GET /api/v1/rooms/{id}/` - 获取房间详情
  - `PUT /api/v1/rooms/{id}/` - 更新房间
  - `DELETE /api/v1/rooms/{id}/` - 删除房间
  - `POST /api/v1/rooms/import-excel/` - Excel 导入

#### 计算接口

- **职责**：静态冷量计算、实时预览、批量计算
- **PRD 引用**：F4-001, F4-002, F4-003
- **主要端点**：
  - `POST /api/v1/rooms/{id}/calculate-static/` - 静态冷量计算
  - `POST /api/v1/calculations/preview/` - 实时计算预览
  - `POST /api/v1/calculations/batch/` - 批量计算
  - `GET /api/v1/calculations/{id}/results/` - 获取计算结果

#### 仿真接口

- **职责**：动态仿真负荷计算、8760h 逐时计算
- **PRD 引用**：F6-001, F6-002, F6-003
- **主要端点**：
  - `POST /api/v1/projects/{id}/simulate/` - 运行动态仿真
  - `GET /api/v1/simulations/{id}/results/` - 获取仿真结果
  - `GET /api/v1/simulations/{id}/hourly-data/` - 获取逐时数据

#### 导出接口

- **职责**：报告导出、数据导出
- **PRD 引用**：F8-001, F8-003, F8-004, F8-005
- **主要端点**：
  - `POST /api/v1/exports/static-report/` - 导出静态计算报告
  - `POST /api/v1/exports/equipment-list/` - 导出设备清单
  - `POST /api/v1/exports/load-calculation-book/` - 导出负荷计算书
  - `POST /api/v1/exports/simulation-data/` - 导出仿真数据
