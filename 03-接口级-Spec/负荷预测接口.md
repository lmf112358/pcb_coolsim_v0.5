## 1. 概述

负荷预测基于未来天气预报与生产负荷率，预测未来 7×24=168 小时的逐时冷负荷（功能区域级粒度）。

**算法**：比例系数法（F10-014~F10-017）
- `预测负荷 = 静态设计负荷（RoomCalcResult.total_load） × 比例系数 K(T, R)`
- K(T, R) 来自 ADR-0003 统一映射表（维度：室外温度 T × 生产负荷率 R）
- 非标准温度和负荷率用线性插值（F10-016）

**关键机制**：
- Celery beat 每小时自动更新天气数据并重新计算预测（仅 `status=active` 场景，F10-006）
- 历史版本保留策略：最近 7 天的 168 个自动版本 + 所有手动版本（F10-020、§14.7）
- 功能区域级粒度输出（F10-017）

## 3. 数据表（4 张，PascalCase）

### 3.1 ForecastScenario（预测场景）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT PK | 是 | 主键 |
| project_id | BIGINT FK → `Project.id` | 是 | 归属项目 |
| name | VARCHAR(100) | 是 | 场景名称 |
| weather_source | enum | 是 | `api` / `manual` |
| status | enum | 是 | `active` / `paused` / `archived`，默认 active |
| start_date | DATE | 是 | 预测起始日期 |
| forecast_hours | INT | 是 | 预测时长，默认 168（7×24） |
| created_at / updated_at | TIMESTAMP | 是 | 系统维护 |

### 3.2 ForecastWeatherData（预测天气数据）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT PK | 是 | |
| scenario_id | BIGINT FK → `ForecastScenario.id` | 是 | 归属场景 |
| timestamp | TIMESTAMP | 是 | 逐时时间戳 |
| dry_bulb | DECIMAL(5,2) | 是 | 干球温度 ℃ |
| wet_bulb | DECIMAL(5,2) | 否 | 湿球温度 |
| humidity | DECIMAL(5,2) | 否 | 相对湿度 |
| source | enum | 是 | `api` / `manual` |
| fetched_at | TIMESTAMP | 是 | 拉取/上传时间（版本区分） |

### 3.3 ForecastProductionRate（生产负荷率，多段配置）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT PK | 是 | |
| scenario_id | BIGINT FK | 是 | 归属场景 |
| segment_index | INT | 是 | 段序号（从 0） |
| production_rate | DECIMAL(5,2) | 是 | 生产负荷率 10~100（%） |
| duration_hours | INT | 是 | 持续时长（小时） |
| start_hour | INT | 是 | 起始小时（0~167） |

> 校验（F10-012）：各段 `duration_hours` 之和应等于 168；不等时返回警告。默认值（F10-013）：1 段 100%、168 小时。

### 3.4 ForecastHourlyResult（预测逐时结果，功能区域级）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGINT PK | 是 | |
| scenario_id | BIGINT FK | 是 | 归属场景 |
| room_id | BIGINT FK → `Room.id` | 是 | 功能区域 |
| timestamp | TIMESTAMP | 是 | 逐时时间戳 |
| outdoor_temp | DECIMAL(5,2) | 是 | 室外温度 |
| production_rate | DECIMAL(5,2) | 是 | 该小时对应的生产负荷率 |
| coefficient_k | DECIMAL(5,4) | 是 | 查表得到的比例系数 |
| forecast_load_kw | DECIMAL(12,4) | 是 | 预测负荷 kW |
| fetched_at | TIMESTAMP | 是 | 计算批次时间（版本区分） |

**索引**：`(scenario_id, fetched_at)` 复合索引（见索引设计.md），支撑历史版本查询。

## 4. 场景管理端点

### 4.1 POST /api/v1/projects/{projectId}/forecast-scenarios

创建预测场景（F10-001）。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 场景名称 |
| weather_source | enum | 是 | `api` / `manual` |
| start_date | string(date) | 否 | 默认=今天 |
| forecast_hours | int | 否 | 默认 168 |

```json
{
  "name": "下周运行预测",
  "weather_source": "api",
  "start_date": "2026-07-15",
  "forecast_hours": 168
}
```

**响应 201**

```json
{
  "success": true,
  "data": {
    "id": 1,
    "project_id": 1,
    "name": "下周运行预测",
    "weather_source": "api",
    "status": "active",
    "start_date": "2026-07-15",
    "forecast_hours": 168,
    "production_rates": [
      { "segment_index": 0, "production_rate": 100.0, "duration_hours": 168, "start_hour": 0 }
    ],
    "created_at": "2026-07-14T10:00:00Z"
  }
}
```

**副作用**：创建时预置 1 段 100%/168h 的生产负荷率（F10-013）。若 `weather_source=api`，立即派发 Celery 任务拉取未来 7 天天气；并注册到 Celery beat 每小时调度（F10-006）。

**错误码**：`400 VALIDATION_ERROR`、`404 RESOURCE_NOT_FOUND`（projectId 不存在）、`403 INSUFFICIENT_PERMISSIONS`。

### 4.2 GET /api/v1/projects/{projectId}/forecast-scenarios

**查询参数**：`status`(enum)、`page`、`page_size`。

**响应 200**：`items[]{id, name, weather_source, status, start_date, forecast_hours, last_run_at, last_fetched_at}` + pagination。

### 4.3 PUT /api/v1/forecast-scenarios/{id}

更新场景配置（F10-002 范围内的可编辑字段）。`archived` 状态的场景不可编辑（F10-004）。

**请求体**：`name`(可选)、`start_date`(可选)、`forecast_hours`(可选)。

**响应 200**：返回更新后的场景。

**错误码**：`400 VALIDATION_ERROR`、`404 RESOURCE_NOT_FOUND`、`409 CONFLICT`（archived 状态不可编辑）。

### 4.4 DELETE /api/v1/forecast-scenarios/{id}

删除场景，级联删除天气数据、负荷率配置、预测结果（F10-002）。NF-015 二次确认。

**响应 204**：No Content。

**错误码**：`404 RESOURCE_NOT_FOUND`、`403 INSUFFICIENT_PERMISSIONS`。

### 4.5 PUT /api/v1/forecast-scenarios/{id}/status

更新场景状态（F10-003/F10-004）。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | enum | 是 | `active` / `paused` / `archived` |

**响应 200**

```json
{
  "success": true,
  "data": {
    "id": 1,
    "status": "paused",
    "auto_update_enabled": false,
    "updated_at": "2026-07-14T10:00:00Z"
  }
}
```

**行为**：
- `active`：注册到 Celery beat 每小时调度，自动更新天气并重算（F10-006）。
- `paused`：停止自动更新，保留既有结果，可手动触发 run（F10-003）。
- `archived`：只读，不参与自动更新，不可编辑（F10-004）。

**错误码**：`400 VALIDATION_ERROR`（枚举非法）、`404 RESOURCE_NOT_FOUND`。

## 7. 预测计算端点

### 7.1 POST /api/v1/forecast-scenarios/{id}/run

手动触发预测计算（F10-009，manual 模式必需；active 模式每小时自动触发）。

**请求**：无 body（使用当前天气数据与生产负荷率配置）。

**响应 202**（异步）

```json
{
  "success": true,
  "data": {
    "task_id": "forecast-run-20260714-001",
    "scenario_id": 1,
    "status": "processing",
    "message": "Forecast calculation started (135 rooms × 168 hours)",
    "websocket_url": "ws://localhost:8000/ws/tasks/forecast-run-20260714-001"
  }
}
```

**计算链路**：
```
for each room, for each hour t (0..167):
  1. T(t) = ForecastWeatherData.outdoor_temp
  2. R(t) = ForecastProductionRate（按 start_hour 匹配段）
  3. K(t) = 查 ADR-0003 统一表，维度 T × R；非标准点线性插值
  4. forecast_load(t) = RoomCalcResult.total_load × K(t)
  5. 写入 ForecastHourlyResult（fetched_at = 当前批次时间）
```

**前置校验**：场景须有天气数据与至少一段生产负荷率。

**错误码**：`422 CALCULATION_ERROR`（缺前置数据）、`404 RESOURCE_NOT_FOUND`。

### 7.2 GET /api/v1/forecast-scenarios/{id}/results

获取预测结果（支持按功能区域/楼层/建筑筛选，F10-018）。

**查询参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| room_id | int | 指定房间 |
| building_id | int | 指定建筑 |
| floor_id | int | 指定楼层 |
| aggregation | enum | `hourly`（默认）/ `daily` |
| fetched_at | datetime | 指定历史版本时间戳；省略=最新 |

**响应 200**

```json
{
  "success": true,
  "data": {
    "scenario_id": 1,
    "fetched_at": "2026-07-14T10:00:00Z",
    "is_latest": true,
    "summary": {
      "peak_load_kw": 12500.50,
      "peak_load_timestamp": "2026-07-16T14:00:00Z",
      "valley_load_kw": 2100.30,
      "valley_load_timestamp": "2026-07-16T04:00:00Z",
      "avg_load_kw": 6800.20,
      "total_energy_kwh": 11424000
    },
    "series": [
      {
        "room_id": 1, "room_name": "内层曝光区",
        "points": [
          { "timestamp": "2026-07-15T00:00:00Z", "outdoor_temp": 26.5, "production_rate": 100.0, "coefficient_k": 0.85, "forecast_load_kw": 176.0 }

      }

  }

```

> 极值统计（F10-019）：peak/valley/avg 及发生时刻。

**错误码**：`404 RESOURCE_NOT_FOUND`（尚无结果）。

### 7.3 GET /api/v1/forecast-scenarios/{id}/results/versions

获取历史版本列表（F10-020）。

**响应 200**

```json
{
  "success": true,
  "data": {
    "scenario_id": 1,
    "versions": [
      { "fetched_at": "2026-07-14T10:00:00Z", "source": "api", "is_auto": true, "weather_range": "2026-07-15~2026-07-21", "record_count": 22680 },
      { "fetched_at": "2026-07-14T09:00:00Z", "source": "api", "is_auto": true, "weather_range": "2026-07-15~2026-07-21", "record_count": 22680 },
      { "fetched_at": "2026-07-13T15:00:00Z", "source": "manual", "is_auto": false, "weather_range": "2026-07-14~2026-07-20", "record_count": 22680 }
    ],
    "retention_policy": "最近 7 天自动版本（168 个）+ 所有手动版本"
  }
}
```

**保留策略（§14.7）**：
- 自动版本（Celery beat 每小时产生）：保留最近 7 天 = 168 个版本，超出按 FIFO 清理。
- 手动版本（用户点击 run 触发）：永久保留。

**错误码**：`404 RESOURCE_NOT_FOUND`。

### 7.4 GET /api/v1/forecast-scenarios/{id}/results/export

导出预测结果 CSV（F10-021）。

**查询参数**：`room_id`(可选)、`building_id`(可选)、`fetched_at`(可选，指定版本)。

**响应 202**（异步）：`{task_id, download_url}`。

**CSV 列**：`timestamp, project_id, building_id, floor_id, room_id, room_name, outdoor_temp, production_rate, coefficient_k, forecast_load_kw`。

**错误码**：`404 RESOURCE_NOT_FOUND`、`500 EXPORT_FAILED`。

## 8. 自动更新调度（Celery beat）

- Celery beat 每小时整点扫描所有 `status=active` 且 `weather_source=api` 的场景。
- 对每个场景：
  1. 调用气象 API 获取未来 7 天逐时预报（168 条），写入 `ForecastWeatherData`。
  2. 触发预测计算（同 §7.1 链路），结果写入 `ForecastHourlyResult`（新 `fetched_at`）。
  3. 清理超过 7 天的自动版本（保留手动版本）。
- 失败重试：单场景失败不影响其他场景；失败状态可查询（`last_fetched_at`、`quality_status`）。
