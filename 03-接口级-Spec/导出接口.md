## 1. 概述

导入导出接口提供 Excel 模板下载、批量导入、报告/数据导出能力。所有端点的 `projectId` 需与当前用户项目权限匹配。

### 1.1 端点总览（附录D 权威清单）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/import/template` | 下载 Excel 导入模板（附录A 列结构） |
| POST | `/api/v1/import/excel/{projectId}` | 上传 Excel 批量导入（错误定位到行） |
| GET | `/api/v1/export/static/{projectId}` | 导出静态计算报告 PDF |
| GET | `/api/v1/export/equipment/{projectId}` | 导出设备清单 Excel |
| GET | `/api/v1/export/calc-book/{projectId}` | 导出负荷计算书 Excel |
| GET | `/api/v1/export/dynamic/{projectId}` | 导出动态仿真逐时数据 CSV |

## 2. 导入接口

### 2.1 GET /api/v1/import/template

下载 Excel 导入模板（F2-032/F2-033）。模板列结构严格对齐 PRD附录A，含表头说明行和示例数据行。

**请求**：无 body。可选 query 参数 `lang=zh|en`（默认 zh）。

**响应 200**：文件流，`Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`，`Content-Disposition: attachment; filename="room_import_template.xlsx"`。

**模板列结构（附录A，对齐 Room 单表字段）**

| 列 | 内容 | 对应字段 | 必填 |
|----|------|----------|------|
| A | 楼层名称 | `Floor.floor_name` | 是 |
| B | 功能区域名称 | `Room.room_name` | 是 |
| C | 面积 (m²) | `Room.area` | 是 |
| D | 吊顶高度 (m) | `Room.height` | 是 |
| E | 设计温度要求 | `Room.design_temp_requirement` | 否 |
| F | 设计相对湿度要求 | `Room.design_humidity_requirement` | 否 |
| G | 温控精度 | `Room.temp_precision`（±1/±2/±3/±5/无） | 否 |
| H | 室内计算温度 (°C) | `Room.indoor_calc_temp` | 否 |
| I | 室内计算相对湿度 (%) | `Room.indoor_calc_humidity` | 否 |
| J | 洁净度等级 | `Room.cleanliness_level` | 否 |
| K | 土建指标 (W/m²) | `Room.civil_load_index` | 是 |
| L | 照明指标 (W/m²) | `Room.lighting_load_index` | 是 |
| M | 人员指标 (W/人) | `Room.personnel_load_index` | 否 |
| N | 人数 | `Room.personnel_count` | 否 |
| O~T | 电动/电热设备功率与系数 | `Room.electric_*`/`heated_*` | 否 |
| U~Y | 五类排风量 | `Room.*_exhaust_volume` | 否 |
| Z | 送风温差 (°C) | `Room.supply_air_temp_diff` | 否 |
| AA | 换气次数 (次/h) | `Room.air_change_rate` | 否 |
| AB | 功能区域压差 (Pa) | `Room.pressure_diff` | 否 |
| AC | 新风冷冻水选择 | `Room.fresh_air_water_mode`（single/dual） | 否 |
| AD | 单水温档 / 第一段档 | `Room.fresh_air_water_temp_config_id` | 否 |
| AE | 两阶段第二段档 | `Room.fresh_air_water_temp_config_id_2` | 否 |
| AF | 末端冷冻水档 | `Room.terminal_water_temp_config_id`（空=中温默认） | 否 |

**错误码**：`500 EXPORT_FAILED`（模板生成失败）。

### 2.2 POST /api/v1/import/excel/{projectId}

上传 Excel 批量导入功能区域（F2-034~F2-039）。系统解析工作表，按「楼层→功能区域」自动建立层级结构。

**请求**：`multipart/form-data`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | file | 是 | .xlsx / .xls 文件 |
| mode | enum | 否 | `append`（追加，默认）/ `overwrite`（覆盖，需二次确认） |
| dry_run | bool | 否 | true=仅校验预览不写入；false=校验通过即写入 |

**响应 200**（校验通过并写入）

```json
{
  "success": true,
  "data": {
    "project_id": 1,
    "total_rows": 1200,
    "success_count": 1198,
    "failed_count": 2,
    "created_floors": 5,
    "created_rooms": 1198,
    "errors": [
      { "row": 45, "field": "area", "value": "-10", "reason": "面积必须大于 0" },
      { "row": 102, "field": "civil_load_index", "value": "", "reason": "必填字段缺失" }
    ],
    "imported_at": "2026-07-14T10:00:00Z"
  }
}
```

**行为**：
- 解析按行校验：必填校验、范围校验、重复校验、类型校验（F2-036）。
- 错误定位到具体行和字段（F2-035），错误行跳过，正确行继续写入。
- `mode=overwrite` 需前端二次确认（F2-037），覆盖前清空项目下既有 Floor/Room。
- 性能：10000+ 行解析 < 30 秒（F2-038）。
- 写入 Room 单表（含 `temp_precision`、`fresh_air_water_mode`、`terminal_water_temp_config_id` 等新字段）。

**错误码**

| HTTP | code | 触发条件 |
|------|------|----------|
| 400 | VALIDATION_ERROR | 文件格式非 xlsx/xls，或 file 字段缺失 |
| 404 | RESOURCE_NOT_FOUND | projectId 不存在 |
| 403 | INSUFFICIENT_PERMISSIONS | 无写权限 |
| 409 | CONFLICT | `mode=overwrite` 但未传确认标识 |
| 422 | IMPORT_ERROR | 文件解析失败（如格式损坏） |
| 500 | INTERNAL_ERROR | 写入过程异常 |

> 导入产出的数据与 Tab1 树形/对话采集为同一 Room 数据集，三通道互不覆盖（F2-061）。

## 3. 导出接口

### 3.1 GET /api/v1/export/static/{projectId}

导出静态计算报告 PDF（F8-001、F8-003、F8-004、SAC-17）。异步生成，完成后通过 `download` 端点或 WebSocket 通知。

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| building_ids | string | 否 | 逗号分隔的建筑 ID，限定范围 |
| include_details | bool | 否 | 是否含逐房间明细，默认 true |
| language | enum | 否 | `zh`（默认）/ `en` |

**响应 202**（异步）

```json
{
  "success": true,
  "data": {
    "task_id": "export-static-20260714-001",
    "status": "processing",
    "message": "Static report generation started",
    "estimated_time_seconds": 30,
    "download_url": "/api/v1/exports/download/export-static-20260714-001"
  }
}
```

**报告内容**：项目概述 + 冷负荷计算（方法/边界/各功能区域明细/汇总）+ 冷量构成分析 + 引用标准清单与系数依据来源；支持在线预览。**数据来源**：`RoomCalcResult`、`RoomLoadByWaterTemp`、`LoadSummary`、`ExtraLoad`、`WaterTempConfig`。

**性能**：NF-011 PDF < 30 秒。

**错误码**：`404 RESOURCE_NOT_FOUND`、`403 INSUFFICIENT_PERMISSIONS`、`422 CALCULATION_ERROR`（尚无计算结果）、`500 EXPORT_FAILED`。

### 3.2 GET /api/v1/export/equipment/{projectId}

导出设备清单 Excel（F8-008/F8-009）。按水温系统分 sheet。

**查询参数**：`building_ids`(string,可选)。

**响应 202**：同 §3.1 结构，`download_url` 指向生成的 xlsx。

**内容**：水泵/冷却塔/AHU 等型号/规格/数量/能效参数；按水温系统（低温/中温）分 sheet。

**性能**：NF-011 Excel < 10 秒。

**错误码**：同 §3.1。

### 3.3 GET /api/v1/export/calc-book/{projectId}（明确）

导出负荷计算书 Excel（F8-010~F8-013，对齐设计院冷热负荷计算书格式）。

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| building_ids | string | 否 | 限定建筑 |
| water_temp_config_id | int | 否 | 限定水温档 |

**响应 202**：同 §3.1 结构。

**内容**（对齐附录A 计算书列映射）：
- 封面：项目信息、城市国标参数、计算依据标准
- 逐房间明细表：基本信息（面积/高度/温湿度/精度）+ 负荷分项（土建/照明/人员/电动/电热）+ 风量（五类排风/渗透/新风/送回风）+ 焓值 + 按水温档的末端/新风/总负荷
- 汇总表：按楼层/建筑/项目分级，按水温档分类（ADR-0001）
- 额外负荷表：`ExtraLoad` 各类别明细
- 计算说明：公式、系数取值来源、截断规则

**数据来源**：`RoomCalcResult` + `RoomLoadByWaterTemp` + `LoadSummary` + `ExtraLoad` + `CityConfig`。

**性能**：NF-011 Excel < 10 秒。

**错误码**：同 §3.1。

### 3.4 GET /api/v1/export/dynamic/{projectId}（确认 CSV）

导出动态仿真逐时数据 CSV（F8-012~F8-014）。

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| room_ids | string | 否 | 逗号分隔的房间 ID；省略=项目级聚合 |
| building_id | int | 否 | 限定建筑 |
| year | int | 否 | 指定年份 |
| aggregation | enum | 否 | `hourly`（默认）/ `daily` / `monthly` |

**响应 202**：同 §3.1 结构，`download_url` 指向生成的 csv。

**CSV 列结构**：`timestamp, project_id, building_id, floor_id, room_id, room_name, outdoor_temp, outdoor_humidity, outdoor_enthalpy, terminal_load_kw, fresh_air_load_kw, total_load_kw`（每房间约 26280 行，hourly）。

**数据来源**：`DynamicLoadHourly` 表。

**性能**：大文件流式生成，配合 TimescaleDB 压缩 chunk，NF-011 CSV < 30 秒（26280 行/房间）。

**错误码**：同 §3.1 + `422 CALCULATION_ERROR`（尚无动态仿真结果）。

## 4. 文件下载

异步导出任务完成后，前端通过 `task_id` 下载。下载 URL 由各导出端点的 `download_url` 字段提供（如 `/api/v1/exports/download/{task_id}`）。

**响应 200**：文件流，`Content-Type` 依格式：
- `application/pdf`（静态报告）
- `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`（设备清单/计算书）
- `text/csv`（动态数据）

**鉴权**：`task_id` 须归属当前用户会话（防越权下载）。

**错误码**：`404 RESOURCE_NOT_FOUND`（task_id 不存在/已过期）、`409 CONFLICT`（任务未完成）。
