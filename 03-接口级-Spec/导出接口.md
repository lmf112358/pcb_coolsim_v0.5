## 1. 概述

导出接口提供异步报告/数据生成能力：静态冷量计算报告（PDF）、设备清单（Excel）、以及生成后文件下载。所有生成类端点的 `project_id` 需与当前用户项目权限匹配。

---

## 2. 端点总览

| 方法 | 路径 | 说明 | 状态 |
|------|------|------|------|
| POST | `/api/v1/exports/static-report/{project_id}/` | 生成静态计算报告 PDF | API总览 §9.1 |
| POST | `/api/v1/exports/equipment-list/{project_id}/` | 生成设备清单 Excel | API总览 §9.2 |
| GET | `/api/v1/exports/download/{task_id}/` | 按任务 ID 下载生成文件 | API总览 §9.3 |
| POST | `/api/v1/exports/simulation-data/{project_id}/` | 仿真逐时数据 CSV 导出 | **待确认**（见 §6） |

---

## 3. 静态计算报告 POST /api/v1/exports/static-report/{project_id}/

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| format | enum | 否 | `pdf`（默认） |
| building_ids | array[int] | 否 | 限定建筑（null=全部） |
| include_details | bool | 否 | 是否含逐房间明细 |
| language | enum | 否 | `zh` / `en` |

```json
{ "format": "pdf", "building_ids": null, "include_details": true, "language": "zh" }
```

**响应 202**：`{task_id, status:"processing", message, estimated_time_seconds:30}`。

**报告内容（对齐 F8-001/F8-003/F8-004，不含冷站）**：项目概述 + 冷负荷计算（方法/边界/各功能区域明细/汇总）+ 冷量构成分析 + 引用标准清单与系数依据来源；支持在线预览（前端以 `download/{task_id}/` 预览或独立预览页）。

**数据来源**：`load_summary`（汇总）、`room_load_summary`（逐房间按水温）、`extra_load`（额外负荷）、`water_temperature_config`（水温档）。

**错误码**：`404 RESOURCE_NOT_FOUND`、`403 INSUFFICIENT_PERMISSIONS`、`422 CALCULATION_ERROR`（尚无计算结果）、`500 EXPORT_FAILED`。

---

## 4. 设备清单 POST /api/v1/exports/equipment-list/{project_id}/

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| format | enum | 否 | `excel`（默认） |
| building_ids | array[int] | 否 | 限定建筑（按水温系统分 sheet，F8-009） |

```json
{ "format": "excel", "building_ids": [1, 2] }
```

**响应 202**：`{task_id, status:"processing"}`。

**内容（对齐 F8-008/F8-009）**：水泵/冷却塔等型号/规格/数量/能效参数；按水温系统分 sheet。

> 说明：设备清单所列设备（水泵/冷却塔/AHU）为通用 HVAC 领域物理名词，非被移除的「冷站配置」模块；本端点仅导出清单数据，不做冷机选型或 P&ID 生成。

**错误码**：同 §3（`500 EXPORT_FAILED`）。

---

## 5. 文件下载 GET /api/v1/exports/download/{task_id}/

**响应 200**：文件流，`Content-Type` 依生成格式：`application/pdf` / `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` / `text/csv`。

**说明**：`task_id` 为上述生成端点返回的异步任务 ID；任务未完成时返回 `409`（或 `202` 带进度，待确认 O-1）。下载不要求项目权限之外的额外校验，但 `task_id` 须归属当前用户会话（防越权下载，见 O-2）。

**错误码**：`404 RESOURCE_NOT_FOUND`（task_id 不存在/已过期）、`409 CONFLICT`（任务未完成）。

---

## 6. 仿真数据 CSV 导出（待确认）

PRD §12.5（F8-012~F8-014）要求导出动态仿真逐时数据 CSV（时间戳+总负荷+新风负荷+末端负荷+室外温度，每房间约 26280 行，支持按房间/楼层/建筑/项目粒度）。但 **API总览 §9 未定义该端点**。

- **提案路径**：`POST /api/v1/exports/simulation-data/{project_id}/`（请求含 `room_ids`/`building_ids`/`aggregation`/`format:"csv"`，返回 task_id；下载复用 §5）。
- **状态**：**待确认**——是否新增、与 §5 下载是否共用 task 体系，需与 API总览 维护者对齐后定稿，本文件不擅自固化契约。

## 7. 待确认 / 开放问题

- **O-1 下载未完成态**：任务未完成时 `download/{task_id}/` 返回 `409` 还是 `202+进度`，待确认。
- **O-2 下载鉴权**：`task_id` 是否绑定用户防越权下载待确认。
- **O-3 F8-005 编号**：任务分配引用 F8-005，但 PRD v0.5.1 导出章节（§12.2~§12.6）无 F8-005 条目；现有为 F8-001~F8-004（静态报告）、F8-008/F8-009（设备清单）、F8-012~F8-014（仿真 CSV）。F8-005 疑为旧版编号或笔误，需与 PRD 维护者确认对齐。
- **O-4 报告在线预览实现**：F8-004「在线预览」是独立预览端点还是复用 `download` 的 inline 渲染，待确认。
