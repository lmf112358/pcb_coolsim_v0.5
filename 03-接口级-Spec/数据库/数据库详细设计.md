## 1. 概述

### 1.1 数据库选型

**主数据库：** PostgreSQL 16 + TimescaleDB 扩展

**选型理由：**
- PostgreSQL：成熟稳定，支持 JSONB、全文搜索、复杂查询
- TimescaleDB：时序数据优化，支持 8760 逐时数据高效存储和查询
- 兼容性：Django ORM 原生支持

**辅助存储：**
- Redis 7：缓存、会话、Celery 消息队列
- MinIO/S3：文件存储（PDF 底图、导出文件）

### 1.2 数据库架构

```
PostgreSQL 16
├── 主数据库：pcb_coolsim
│   ├── accounts app（用户和认证）
│   ├── projects app（项目和层级）
│   ├── calculations app（计算结果）
│   ├── weather app（气象数据）
│   ├── forecasting app（负荷预测）
│   ├── exports app（导出任务）
│   └── settings app（系统配置）
├── TimescaleDB 扩展
│   └── 时序数据表（hypertables）
└── 索引和分区
    ├── B-tree 索引
    ├── GIN 索引（JSONB）
    ├── 复合索引
    └── 时间分区
```

### 2.1 用户和认证模块

#### users 表

```sql
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    password VARCHAR(128) NOT NULL,
    last_login TIMESTAMP WITH TIME ZONE,
    is_superuser BOOLEAN NOT NULL DEFAULT FALSE,
    username VARCHAR(150) UNIQUE NOT NULL,
    first_name VARCHAR(150) NOT NULL DEFAULT '',
    last_name VARCHAR(150) NOT NULL DEFAULT '',
    email VARCHAR(254) UNIQUE NOT NULL,
    is_staff BOOLEAN NOT NULL DEFAULT FALSE,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    date_joined TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),

    -- 自定义字段
    role VARCHAR(20) NOT NULL DEFAULT 'engineer'
        CHECK (role IN ('admin', 'project_manager', 'engineer', 'viewer')),
    phone VARCHAR(20) DEFAULT '',
    company VARCHAR(100) DEFAULT '',
    department VARCHAR(100) DEFAULT '',

    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()

COMMENT ON TABLE users IS '用户表';
COMMENT ON COLUMN users.role IS '系统角色：admin-管理员, project_manager-项目经理, engineer-暖通工程师, viewer-查看者';
```

#### rooms 表

```sql
CREATE TABLE rooms (
    id BIGSERIAL PRIMARY KEY,
    floor_id BIGINT NOT NULL REFERENCES floors(id) ON DELETE CASCADE,
    room_name VARCHAR(100) NOT NULL,
    room_code VARCHAR(50) DEFAULT '',

    -- 第一组：基本信息
    area DECIMAL(10,2) NOT NULL CHECK (area > 0),
    ceiling_height DECIMAL(5,2) NOT NULL CHECK (ceiling_height > 0),

    -- 第二组：温湿度要求
    design_temp VARCHAR(50) DEFAULT '',
    design_humidity VARCHAR(50) DEFAULT '',
    temp_precision VARCHAR(10) DEFAULT ''
        CHECK (temp_precision IN ('±1', '±2', '±3', '±5', '无要求', '')),
    indoor_temp DECIMAL(5,1),
    indoor_humidity DECIMAL(5,1),
    cleanliness_level VARCHAR(20) DEFAULT '',

    -- 第三组：负荷计算参数
    construction_load_index DECIMAL(8,2) NOT NULL CHECK (construction_load_index >= 0),
    lighting_index DECIMAL(8,2) NOT NULL CHECK (lighting_index >= 0),
    occupancy_heat DECIMAL(8,2),
    occupancy_count INTEGER,

    -- 第四组：设备参数
    electric_power DECIMAL(10,2),
    electric_coeff DECIMAL(3,2),
    heat_exhaust_power DECIMAL(10,2),
    heat_exhaust_coeff DECIMAL(3,2),
    heat_no_exhaust_power DECIMAL(10,2),
    heat_no_exhaust_coeff DECIMAL(3,2),

    -- 第五组：风量参数
    heat_exhaust_volume DECIMAL(10,2),
    acid_exhaust_volume DECIMAL(10,2),
    alkali_exhaust_volume DECIMAL(10,2),
    organic_exhaust_volume DECIMAL(10,2),
    dust_exhaust_volume DECIMAL(10,2),
    pressure_diff DECIMAL(5,1),

    -- 第六组：冷冻水配置
    water_grade VARCHAR(10) NOT NULL DEFAULT 'medium'
        CHECK (water_grade IN ('low', 'medium')),

    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
);

COMMENT ON TABLE rooms IS '功能区域表（最小计算单元）';
COMMENT ON COLUMN rooms.water_grade IS '冷冻水档：low-低温(7/12°C), medium-中温(12/17°C)';
```

**索引：**
```sql
CREATE INDEX idx_rooms_floor_id ON rooms(floor_id);
CREATE INDEX idx_rooms_water_grade ON rooms(water_grade);
CREATE INDEX idx_rooms_room_name_gin ON rooms USING gin(to_tsvector('simple', room_name));
```

#### weather_data 表（TimescaleDB Hypertable）

```sql
CREATE TABLE weather_data (
    id BIGSERIAL,
    city_id BIGINT NOT NULL REFERENCES cities(id) ON DELETE CASCADE,
    timestamp TIMESTAMP WITH TIME ZONE NOT NULL,
    year INTEGER NOT NULL,

    -- 气象参数
    outdoor_temp DECIMAL(5,1) NOT NULL,
    outdoor_humidity DECIMAL(5,1),
    wet_bulb_temp DECIMAL(5,1),
    atmospheric_pressure DECIMAL(7,0),
    wind_speed DECIMAL(4,1),
    solar_radiation DECIMAL(6,1),

    -- 元数据
    data_source VARCHAR(20) NOT NULL DEFAULT 'api'
        CHECK (data_source IN ('api', 'manual', 'interpolated')),
    is_interpolated BOOLEAN NOT NULL DEFAULT FALSE,
    fetched_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),

    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),

    PRIMARY KEY (id, timestamp)
);

-- 转换为 TimescaleDB Hypertable
SELECT create_hypertable('weather_data', 'timestamp');

COMMENT ON TABLE weather_data IS '气象数据表（TimescaleDB Hypertable）';
```

**索引：**
```sql
CREATE INDEX idx_weather_data_city_id ON weather_data(city_id);
CREATE INDEX idx_weather_data_year ON weather_data(year);
CREATE INDEX idx_weather_data_city_year ON weather_data(city_id, year);
CREATE INDEX idx_weather_data_timestamp ON weather_data(timestamp DESC);
```

**压缩策略（TimescaleDB）：**
```sql
-- 启用压缩（超过 30 天的数据自动压缩）
ALTER TABLE weather_data SET (
    timescaledb.compress,
    timescaledb.compress_segmentby = 'city_id, year',
    timescaledb.compress_orderby = 'timestamp'
);

-- 添加压缩策略
SELECT add_compression_policy('weather_data', INTERVAL '30 days');
```

## 3. 索引设计策略

### 3.1 索引类型选择

| 索引类型 | 适用场景 | 示例 |
|----------|----------|------|
| B-tree | 等值查询、范围查询、排序 | id, timestamp, status |
| GIN | JSONB 字段查询、全文搜索 | floor_plan_data, name |
| GiST | 地理空间查询 | latitude, longitude |
| Hash | 等值查询（高基数） | email, username |

### 3.2 复合索引设计原则

```sql
-- 1. 最左前缀原则
-- 查询：WHERE simulation_id = ? AND room_id = ? ORDER BY timestamp DESC
CREATE INDEX idx_sim_room_time ON simulation_hourly_results(simulation_id, room_id, timestamp DESC);

-- 2. 覆盖索引（避免回表）
-- 查询：SELECT room_id, total_load_kw FROM ... WHERE simulation_id = ?
CREATE INDEX idx_sim_covering ON simulation_hourly_results(simulation_id) INCLUDE (room_id, total_load_kw);

-- 3. 部分索引（节省空间）
-- 只索引 active 状态的场景
CREATE INDEX idx_active_scenarios ON forecast_scenarios(project_id) WHERE status = 'active';
```

### 3.3 索引维护策略

```sql
-- 定期重建索引（每月）
REINDEX TABLE CONCURRENTLY simulation_hourly_results;

-- 监控索引使用率
SELECT
    schemaname,
    tablename,
    indexname,
    idx_scan,
    idx_tup_read
FROM pg_stat_user_indexes
WHERE idx_scan = 0  -- 未使用的索引
ORDER BY pg_relation_size(indexrelid) DESC;
```

## 4. 分区策略

### 4.1 TimescaleDB 自动分区

**时序数据表分区策略：**

| 表名 | 分区键 | 分区间隔 | 保留策略 |
|------|--------|----------|----------|
| weather_data | timestamp | 1 个月 | 无限期 |
| simulation_hourly_results | timestamp | 1 周 | 1 年 |
| forecast_hourly_results | timestamp | 1 天 | 90 天 |

**配置示例：**
```sql
-- weather_data 分区配置
SELECT create_hypertable('weather_data', 'timestamp',
    chunk_time_interval => INTERVAL '1 month'
);

-- 设置保留策略（1 年后自动删除）
SELECT add_retention_policy('simulation_hourly_results', INTERVAL '1 year');

-- 设置压缩策略（7 天后自动压缩）
SELECT add_compression_policy('simulation_hourly_results', INTERVAL '7 days');
```

### 4.2 常规表分区

**大表分区策略：**

```sql
-- export_tasks 按月份分区
```

## 8. 监控和告警

### 8.1 关键监控指标

```sql
-- 1. 表大小监控
SELECT
    schemaname,
    tablename,
    pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS total_size
FROM pg_tables
WHERE schemaname = 'public'
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC;

-- 2. 索引使用率
SELECT
    indexname,
    idx_scan,
    idx_tup_read
FROM pg_stat_user_indexes
WHERE idx_scan < 10  -- 低使用率索引
ORDER BY idx_scan;

-- 3. 慢查询监控
SELECT
    query,
    calls,
    mean_exec_time,
    total_exec_time
FROM pg_stat_statements
ORDER BY mean_exec_time DESC
LIMIT 10;
```
