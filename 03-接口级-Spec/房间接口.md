> 依赖文档：01-系统级-Spec/API总览.md（§4 建筑、§5 楼层、§6 房间）、02-模块级-Spec/模块-02-数据采集.md、01-系统级-Spec/数据库设计.md（building / floor / room / room_load_parameter / room_air_volume_parameter）

## 1. 概述

房间（room）是系统最小计算单元（数据库设计 §4.4）。本文件覆盖「项目 → 建筑 → 楼层 → 房间」后三级的 CRUD，以及房间 Excel 批量导入（待确认端点）。层级归属严格为：

```
project ──< building ──< floor ──< room
```

所有 room 操作须经由 `floor_id` 上溯其 `building → project`，并受项目级数据隔离约束。

## 3. 建筑（Building）

### 3.1 GET /api/v1/buildings/?project={project_id}

**必填查询参数**：`project`(integer)。可选：`page`、`page_size`。

**响应 200**：`items[]{id, building_name, building_code, description, floor_count, room_count, created_at}` + pagination。

### 3.2 POST /api/v1/buildings/

| 字段 | 必填 | 校验 |
|------|------|------|
| project_id | 是 | 存在且有权限，否则 404 |
| building_name | 是 | 非空 ≤100 |
| building_code | 否 | ≤50 |
| description | 否 | ≤500 |

```json
{ "project_id": 1, "building_name": "2#厂房", "building_code": "B002", "description": "二期生产厂房" }
```

**响应 201**：返回 `{id, project_id, building_name, building_code, description, created_at}`。

## 4. 楼层（Floor）

### 4.1 GET /api/v1/floors/?building={building_id}

**必填查询参数**：`building`(integer)。可选分页。

**响应 200**：`items[]{id, floor_name, room_count, created_at}` + pagination。

### 4.2 POST /api/v1/floors/

| 字段 | 必填 | 校验 |
|------|------|------|
| building_id | 是 | 存在且有权限，否则 404 |
| floor_name | 是 | 非空 ≤50（如 "2F"） |

```json
{ "building_id": 1, "floor_name": "2F" }
```

**响应 201**：返回创建后的楼层对象。

## 5. 房间（Room）

### 5.1 字段与数据库映射

| API 字段 | DB 字段 | 类型 | 必填 | 说明 |
|----------|---------|------|------|------|
| floor_id | room.floor_id → floor.id | int | 是 | 归属楼层 |
| room_name | room.room_name | string(100) | 是 | 房间名称 |
| room_code | room.room_code | string(50) | 否 | 房间编号 |
| area | room.area | decimal(10,2) | 是 | 面积 m²，>0 |
| height | room.height | decimal(5,2) | 是 | 高度 m，>0 |
| volume | room.volume | decimal(12,2) | — | **系统计算** = area × height |
| design_temp_requirement | room.design_temp_requirement | string(50) | 否 | 原文展示（如 "23±2"） |
| design_humidity_requirement | room.design_humidity_requirement | string(50) | 否 | 原文展示 |
| indoor_calc_temp | room.indoor_calc_temp | decimal(5,2) | 否 | 室内计算温度（参与计算） |
| indoor_calc_humidity | room.indoor_calc_humidity | decimal(5,2) | 否 | 室内计算湿度（参与计算） |
| cleanliness_level | room.cleanliness_level | string(50) | 否 | 洁净度（如 ISO7） |
| water_tier_id | room_load_summary / water_temp_config.id | int | 否 | API 别名；DB 为 `water_temp_config_id`，房间默认水温档（见 O-2） |
| status | room.status | enum | 否 | `draft`(对话草稿) / `active`(已确认) |
| load_parameters.* | room_load_parameter.* | — | 部分必填 | 见 §5.3 |
| air_volume_parameters.* | room_air_volume_parameter.* | — | 否 | 见 §5.3 |

### 5.2 GET /api/v1/rooms/?floor={floor_id}

**必填**：`floor`(integer)。可选：`page`、`page_size`、`search`(按 name/code)。

**响应 200**：`items[]{id, room_name, room_code, area, height, volume, indoor_calc_temp, indoor_calc_humidity, cleanliness_level, water_tier, has_calculation, last_calculation_date}` + pagination。

### 5.3 POST /api/v1/rooms/

**请求体**（含负荷/风量参数嵌套对象）

| 子对象字段 | DB 字段（`room_load_parameter`） | 类型 | 必填 |
|-----------|----------------------------------|------|------|
| load_parameters.civil_load_index | civil_load_index | decimal(8,4) | 是 |
| load_parameters.lighting_load_index | lighting_load_index | decimal(8,4) | 是 |
| load_parameters.personnel_load_index | personnel_load_index | decimal(8,4) | 否 |
| load_parameters.personnel_count | personnel_count | int | 否 |
| load_parameters.electric_equipment_power | electric_equipment_power | decimal(10,4) | 否 |
| load_parameters.electric_equipment_factor | electric_equipment_coefficient | decimal(5,4) | 否（API 别名 factor → coefficient） |
| load_parameters.exhaust_heated_equipment_power | heated_equipment_power_with_exhaust | decimal(10,4) | 否 |
| load_parameters.exhaust_heated_equipment_factor | heated_equipment_coefficient_with_exhaust | decimal(5,4) | 否（API 别名） |

| 子对象字段 | DB 字段（`room_air_volume_parameter`） | 类型 | 必填 |
|-----------|----------------------------------------|------|------|
| air_volume_parameters.heat_exhaust_volume | heat_exhaust_volume | decimal(10,2) | 否 |
| air_volume_parameters.acid_exhaust_volume | acid_exhaust_volume | decimal(10,2) | 否 |
| air_volume_parameters.pressure_diff | pressure_diff | decimal(5,2) | 否 |
| （GET 详情另含 alkali/organic/dust_exhaust、total_exhaust_volume、supply_temp_diff、design_ach） | alkali/organic/dust_exhaust_volume、supply_air_temp_diff、air_change_rate | — | 否 |

```json
{
  "floor_id": 1,
  "room_name": "电镀车间",
  "room_code": "R002",
  "area": 800.00,
  "height": 5.00,
  "design_temp_requirement": "25±2",
  "design_humidity_requirement": "50±10",
  "indoor_calc_temp": 25.00,
  "indoor_calc_humidity": 50.00,
  "cleanliness_level": null,
  "water_tier_id": 2,
  "load_parameters": {
    "civil_load_index": 50.00,
    "lighting_load_index": 20.00,
    "personnel_load_index": 120.00,
    "personnel_count": 20,
    "electric_equipment_power": 100.00,
    "electric_equipment_factor": 0.7,
    "exhaust_heated_equipment_power": 50.00,
    "exhaust_heated_equipment_factor": 0.8
  },
  "air_volume_parameters": {
    "heat_exhaust_volume": 2000.00,
    "acid_exhaust_volume": 500.00,
    "pressure_diff": 15.00
  }
}
```

**响应 201**：返回创建后的房间（含自动计算的 `volume`、嵌套 `load_parameters`/`air_volume_parameters`）。

**校验规则**：`area`/`height` 必须 > 0；`civil_load_index`/`lighting_load_index` 必填（数据库设计 §4.8）；`floor_id` 不存在 → 404。

### 5.4 GET /api/v1/rooms/{id}/

**响应 200**：详情含 `floor_id/floor_name`、`building_id/building_name`、`project_id`、`design_*`、`indoor_calc_*`、`water_tier{id,name,supply_temp,return_temp}`、完整 `load_parameters`（含 `no_exhaust_heated_equipment_*`）、`air_volume_parameters`（含 alkali/organic/dust_exhaust、total_exhaust_volume、design_ach、supply_temp_diff）。

### 5.5 PUT /api/v1/rooms/{id}/

请求体同创建（部分更新）。`volume` 在 `area`/`height` 变更时重算。

### 5.6 DELETE /api/v1/rooms/{id}/

**响应 204**：级联删除 `room_load_parameter`、`room_load_result`、`room_air_volume_parameter`、`room_air_volume_result`、`room_load_summary` 中该房间的记录。

## 6. 房间 Excel 导入（待确认端点）

API总览 未定义房间 Excel 导入端点；依据用户故事 US-2.3 / PRD F2-021~F2-025，建议新增：

- **方法/路径（提案）**：`POST /api/v1/rooms/import-excel/`
- **请求**：`multipart/form-data`，字段 `floor_id`(integer,必填) + `file`(Excel/CSV，模板同数据库设计 §8.1 字段)。
- **行为**：服务端按行校验 → 预览/暂存 → 提交；错误定位到「行/列」；万级行 < 30s；关键错误可回滚（US-2.3 验收）。
- **状态**：**待确认**——路径、字段命名、是否分步（先校验预览再写入）需与 API总览 维护者对齐后再定稿，本文件不擅自固化契约。

## 7. 对话式采集接口指引

对话式采集（PRD §6.10，当前特性）是房间/建筑/项目数据的第三录入通道，与 Tab1 树形、Excel 共享同一数据模型（写入 `room` 等表，`room.status='draft'` 暂存）。其 5 个端点不在本文件，详见 **API总览 §12 对话式采集接口**（sessions 创建/恢复、message、状态获取、draft 保存、finalize）。

---

## 8. 鉴权与数据隔离

- 所有端点需 Bearer token；建筑/楼层/房间均上溯 project 做成员权限校验。
- 越权 → `403 INSUFFICIENT_PERMISSIONS`；资源不存在 → `404 RESOURCE_NOT_FOUND`。

---

## 9. 待确认 / 开放问题

- **O-1 建筑/楼层的 update/delete**：API总览 仅定义 list+create；是否补充 `PUT/PATCH/DELETE` 待确认（F2-002 的「编辑/删除」语义需后端端点支撑）。
- **O-2 water_tier_id 存储归属**：API 用 `water_tier_id` 表示房间默认水温档，但 15 表锚点中房间级水温分类落在 `room_load_summary.water_temp_config_id`（按季节×水温多行）。单房间「默认水温档」是否独立字段，或仅以 `room_load_summary` 推导，待确认。
- **O-3 拖拽排序持久化**：F2-003 拖拽排序需排序字段；`building/floor/room` 表锚点无 `order` 字段，排序方案（新增字段 or 按名称/创建时间）待确认。
