## 1. 概述

房间（Room）是系统最小计算单元，**已合并为单表**（PRD附录A：负荷/风量/温湿度/新风配置/末端冷冻水档全在 Room 表 30+ 字段）。已删除 `room_load_parameter`/`room_air_volume_parameter`/`RoomCalcResult` 子表与 `season_config`/`season_id`。

层级归属严格为：

```
Project ──< Building ──< Floor ──< Room（单表，含全部用户输入参数）
```

所有 Room 操作须经由 `floor_id` 上溯其 `Building → Project`，并受项目级数据隔离约束。

### 1.1 端点总览（附录D 权威清单）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/floors/{floorId}/rooms` | 创建房间（含全部参数） |
| GET | `/api/v1/rooms/{id}` | 房间详情 |
| PUT | `/api/v1/rooms/{id}` | 更新房间 |
| DELETE | `/api/v1/rooms/{id}` | 删除房间 |
| POST | `/api/v1/rooms/{id}/copy` | 复制功能区域到同/其他楼层 |

> 建筑/楼层的 CRUD 见 **项目接口.md** §4、§5（含 PUT/DELETE）。

## 2. Room 单表字段映射（30+ 字段，PRD附录A）

Room 表统一承载全部用户输入参数，分 7 组（F2-014 表单分块）。下表为 API 字段与 `Room.*` 列映射，**禁止再引用 `room_load_parameter.*`/`room_air_volume_parameter.*` 子表**。

### 2.1 第一组：基本信息

| API 字段 | DB 字段 | 类型 | 必填 | 说明 |
|----------|---------|------|------|------|
| floor_id | `Room.floor_id` → `Floor.id` | int | 是 | 归属楼层（POST 时由路径提供） |
| room_name | `Room.room_name` | string(100) | 是 | 房间名称 |
| room_code | `Room.room_code` | string(50) | 否 | 房间编号 |
| area | `Room.area` | decimal(10,2) | 是 | 面积 m²，>0 |
| height | `Room.height` | decimal(5,2) | 是 | 高度 m，>0 |
| volume | `Room.volume` | decimal(12,2) | — | **系统计算** = area × height，只读 |
| design_temp_requirement | `Room.design_temp_requirement` | string(50) | 否 | 原文展示（如 "23±2"），不参与计算 |
| design_humidity_requirement | `Room.design_humidity_requirement` | string(50) | 否 | 原文展示 |
| cleanliness_level | `Room.cleanliness_level` | string(50) | 否 | 洁净度（如 ISO7） |

### 2.2 第二组：温控精度与室内计算参数

| API 字段 | DB 字段 | 类型 | 必填 | 说明 |
|----------|---------|------|------|------|
| temp_precision | `Room.temp_precision` | enum | 否 | 温控精度，见 §3 枚举 |
| indoor_calc_temp | `Room.indoor_calc_temp` | decimal(5,2) | 否 | 室内计算温度 ℃，默认 26.00 |
| indoor_calc_humidity | `Room.indoor_calc_humidity` | decimal(5,2) | 否 | 室内计算湿度 %，默认 55.00 |

### 2.3 第三组：负荷参数（土建/照明/人员）

| API 字段 | DB 字段 | 类型 | 必填 | 说明 |
|----------|---------|------|------|------|
| civil_load_index | `Room.civil_load_index` | decimal(8,4) | 是 | 土建指标 W/m²，≥0 |
| lighting_load_index | `Room.lighting_load_index` | decimal(8,4) | 是 | 照明指标 W/m²，≥0 |
| personnel_load_index | `Room.personnel_load_index` | decimal(8,4) | 否 | 人员指标 W/人，≥0 |
| personnel_count | `Room.personnel_count` | int | 否 | 人数，≥0 |

### 2.4 第四组：电动/电热设备

| API 字段 | DB 字段 | 类型 | 必填 | 说明 |
|----------|---------|------|------|------|
| electric_equipment_power | `Room.electric_equipment_power` | decimal(10,4) | 否 | 电动设备功率 kW |
| electric_equipment_coefficient | `Room.electric_equipment_coefficient` | decimal(5,4) | 否 | 电动设备系数 [0,1] |
| heated_equipment_power_with_exhaust | `Room.heated_equipment_power_with_exhaust` | decimal(10,4) | 否 | 有排风电热功率 kW |
| heated_equipment_coefficient_with_exhaust | `Room.heated_equipment_coefficient_with_exhaust` | decimal(5,4) | 否 | 有排风电热系数 [0,1] |
| heated_equipment_power_without_exhaust | `Room.heated_equipment_power_without_exhaust` | decimal(10,4) | 否 | 无排风电热功率 kW |
| heated_equipment_coefficient_without_exhaust | `Room.heated_equipment_coefficient_without_exhaust` | decimal(5,4) | 否 | 无排风电热系数 [0,1] |

### 2.5 第五组：风量参数（五类排风 + 送风温差 + 换气次数 + 压差）

| API 字段 | DB 字段 | 类型 | 必填 | 说明 |
|----------|---------|------|------|------|
| heat_exhaust_volume | `Room.heat_exhaust_volume` | decimal(10,2) | 否 | 热排风 m³/h |
| acid_exhaust_volume | `Room.acid_exhaust_volume` | decimal(10,2) | 否 | 酸性排风 m³/h |
| alkali_exhaust_volume | `Room.alkali_exhaust_volume` | decimal(10,2) | 否 | 碱性排风 m³/h |
| organic_exhaust_volume | `Room.organic_exhaust_volume` | decimal(10,2) | 否 | 有机排风 m³/h |
| dust_exhaust_volume | `Room.dust_exhaust_volume` | decimal(10,2) | 否 | 含尘排风 m³/h |
| supply_air_temp_diff | `Room.supply_air_temp_diff` | decimal(5,2) | 否 | 送风温差 ℃ |
| air_change_rate | `Room.air_change_rate` | int | 否 | 换气次数 次/h |
| pressure_diff | `Room.pressure_diff` | decimal(5,2) | 否 | 功能区域压差 Pa |

> 总排风量 `total_exhaust_volume` 为五类排风之和，**前端实时合计只读展示**（F2-017），不入库。

### 2.6 第六组：新风冷冻水选择

| API 字段 | DB 字段 | 类型 | 必填 | 说明 |
|----------|---------|------|------|------|
| fresh_air_water_mode | `Room.fresh_air_water_mode` | enum | 否 | 见 §3 枚举（single/dual） |
| fresh_air_water_temp_config_id | `Room.fresh_air_water_temp_config_id` | int | 否 | 单水温档 / 两阶段第一段档，FK → `WaterTempConfig.id` |
| fresh_air_water_temp_config_id_2 | `Room.fresh_air_water_temp_config_id_2` | int | 否 | 两阶段第二段档（仅 mode=dual 时有效） |

### 2.7 第七组：末端冷冻水档（ADR-0001）

| API 字段 | DB 字段 | 类型 | 必填 | 说明 |
|----------|---------|------|------|------|
| terminal_water_temp_config_id | `Room.terminal_water_temp_config_id` | int | 否 | 末端冷冻水档，FK → `WaterTempConfig.id`；**空=中温默认**（ADR-0001） |

> 此字段取代旧的 `water_tier_id`。**所有引用一律使用 `terminal_water_temp_config_id`**，禁止再用 `water_tier_id`。

### 2.8 状态字段

| API 字段 | DB 字段 | 类型 | 说明 |
|----------|---------|------|------|
| status | `Room.status` | enum | `draft`（对话草稿）/ `active`（已确认），默认 `active`（Tab1 直接建）或 `draft`（对话采集） |

## 4. 端点详细设计

### 4.1 POST /api/v1/floors/{floorId}/rooms

创建房间，写入 Room 单表全部字段。`floor_id` 由路径提供。

**请求体**（示例，字段全集见 §2）

```json
{
  "room_name": "电镀车间",
  "room_code": "R002",
  "area": 800.00,
  "height": 5.00,
  "design_temp_requirement": "25±2",
  "design_humidity_requirement": "50±10",
  "temp_precision": "±2",
  "indoor_calc_temp": 25.00,
  "indoor_calc_humidity": 50.00,
  "cleanliness_level": "ISO7",
  "civil_load_index": 50.00,
  "lighting_load_index": 20.00,
  "personnel_load_index": 120.00,
  "personnel_count": 20,
  "electric_equipment_power": 100.00,
  "electric_equipment_coefficient": 0.7,
  "heated_equipment_power_with_exhaust": 50.00,
  "heated_equipment_coefficient_with_exhaust": 0.8,
  "heat_exhaust_volume": 2000.00,
  "acid_exhaust_volume": 500.00,
  "pressure_diff": 15.00,
  "fresh_air_water_mode": "single",
  "fresh_air_water_temp_config_id": 2,
  "terminal_water_temp_config_id": 2
}
```

**响应 201**：返回创建后的房间（含自动计算的 `volume`、回显全部字段）。

**校验规则**：
- `area`/`height` 必须 > 0
- `civil_load_index`/`lighting_load_index` 必填
- `temp_precision` 取值必须在枚举内
- `fresh_air_water_mode=dual` 时 `fresh_air_water_temp_config_id_2` 必填
- `terminal_water_temp_config_id` 引用的水温配置须属于同项目
- `floor_id` 不存在 → 404

**错误码**：`400 VALIDATION_ERROR`、`404 RESOURCE_NOT_FOUND`（floorId 不存在）、`403 INSUFFICIENT_PERMISSIONS`。

### 4.2 GET /api/v1/rooms/{id}

**响应 200**：详情含全部 Room 字段 + 展开对象：
- `floor{id, floor_name}`、`building{id, building_name}`、`project{id}`
- `terminal_water_temp_config{id, name, supply_temp, return_temp}`
- `fresh_air_water_temp_config{id, name, supply_temp, return_temp}`（若设置）
- `has_calculation`(bool)、`last_calculation_date`(datetime|null)

**错误码**：`404 RESOURCE_NOT_FOUND`。

### 4.3 PUT /api/v1/rooms/{id}

请求体同创建（部分更新）。`volume` 在 `area`/`height` 变更时由服务端重算。修改 `terminal_water_temp_config_id` 或冷冻水配置时，前端提示「该功能区域按水温分类结果将重新计算」（F2-020）。

**响应 200**：同详情结构。

**错误码**：`400 VALIDATION_ERROR`、`404 RESOURCE_NOT_FOUND`、`403 INSUFFICIENT_PERMISSIONS`。

### 4.4 DELETE /api/v1/rooms/{id}

**响应 204**：级联删除该房间的 `RoomCalcResult`、`RoomLoadByWaterTemp` 及汇总记录；同时清除 2D 平面图中引用该房间的方块关联（方块图形保留，F2 16.1.5）。NF-015 二次确认。

**错误码**：`404 RESOURCE_NOT_FOUND`、`403 INSUFFICIENT_PERMISSIONS`。

### 4.5 POST /api/v1/rooms/{id}/copy（新增，F2-021~F2-023）

复制功能区域到同一楼层或其他楼层。复制全部 Room 参数（不含计算结果），新区域名称默认为「原名称 - 副本」，复制后自动打开编辑表单（前端行为）。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| new_room_name | string | 否 | 新名称，默认「{原名称} - 副本」 |
| target_floor_id | int | 否 | 目标楼层 ID；默认=原楼层（同楼层复制） |

```json
{
  "new_room_name": "电镀车间 - 副本",
  "target_floor_id": 5
}
```

**响应 201**

```json
{
  "success": true,
  "data": {
    "id": 102,
    "floor_id": 5,
    "room_name": "电镀车间 - 副本",
    "room_code": null,
    "area": 800.00,
    "height": 5.00,
    "volume": 4000.00,
    "status": "active",
    "copied_from_room_id": 1,
    "copied_fields": [
      "temp_precision", "indoor_calc_temp", "indoor_calc_humidity",
      "civil_load_index", "lighting_load_index", "personnel_load_index", "personnel_count",
      "electric_equipment_power", "electric_equipment_coefficient",
      "heated_equipment_power_with_exhaust", "heated_equipment_coefficient_with_exhaust",
      "heated_equipment_power_without_exhaust", "heated_equipment_coefficient_without_exhaust",
      "heat_exhaust_volume", "acid_exhaust_volume", "alkali_exhaust_volume",
      "organic_exhaust_volume", "dust_exhaust_volume",
      "supply_air_temp_diff", "air_change_rate", "pressure_diff",
      "fresh_air_water_mode", "fresh_air_water_temp_config_id", "fresh_air_water_temp_config_id_2",
      "terminal_water_temp_config_id", "cleanliness_level",
      "design_temp_requirement", "design_humidity_requirement"
    ],
    "created_at": "2026-07-14T10:00:00Z"
  }
}
```

**复制规则**：
- 复制 §2 全部用户输入参数（第一~第七组）；不复制 `room_name`/`room_code`（用新名称）、`id`、`status`（新建默认 active 或沿用对话草稿态）、计算结果。
- `target_floor_id` 必须属于同一项目（跨项目复制禁止）。
- `terminal_water_temp_config_id`/`fresh_air_water_temp_config_id` 跨楼层复制时若目标楼层所属项目的 WaterTempConfig ID 不同，需校验 ID 仍属同项目，否则清空并提示用户重新选择。
- 复制后 `room.status='active'`（非对话采集场景），可在编辑表单中继续修改。

**错误码**

| HTTP | code | 触发条件 |
|------|------|----------|
| 404 | RESOURCE_NOT_FOUND | 源房间 id 或 target_floor_id 不存在 |
| 400 | VALIDATION_ERROR | new_room_name 为空或超长 |
| 403 | INSUFFICIENT_PERMISSIONS | 跨项目复制、或对目标楼层无写权限 |
| 409 | DUPLICATE_RESOURCE | 目标楼层下已存在同名房间（若启用唯一约束） |

## 5. 房间 Excel 导入

Excel 批量导入由 **导出接口.md** §2（`/api/v1/import/template`、`/api/v1/import/excel/{projectId}`）统一定义，列结构对齐 PRD附录A（30+ 列，含 `temp_precision`、`fresh_air_water_mode`、`terminal_water_temp_config_id` 等）。本文件不重复定义。

## 6. 对话式采集接口指引

对话式采集是房间/建筑/项目数据的第三录入通道，写入同一 Room 单表（`status='draft'` 暂存）。其 6 个端点详见 **对话采集接口.md**（ADR-0007，F2-046~F2-061）。

## 7. 鉴权与数据隔离

- 所有端点需 Bearer token；房间均上溯 Project 做成员权限校验。
- 越权 → `403 INSUFFICIENT_PERMISSIONS`；资源不存在 → `404 RESOURCE_NOT_FOUND`。
