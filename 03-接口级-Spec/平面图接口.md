## 1. 概述

平面图接口支持楼层底图 PDF 上传、平面图 JSON 编辑保存、未关联功能区域查询。底图 PDF 存储于 **MinIO**（对象存储），平面图 JSON 数据存于 `Floor` 表关联字段。

**关键约束（PRD §7.4、F3-011~F3-013）**：
- 底图仅在编辑阶段作为参考，**不随平面图数据持久化到查看组件**（F3-012）
- 底图文件路径保存到 `Floor.floor_plan_file` 字段（F3-013）
- 替换底图需二次确认（NF-015 删除/替换操作二次确认）

### 1.1 端点总览（附录D 权威清单）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/floors/{floorId}/floor-plan/upload` | 上传底图 PDF（替换需二次确认） |
| GET | `/api/v1/floors/{floorId}/floor-plan` | 获取平面图 JSON 数据 |
| PUT | `/api/v1/floors/{floorId}/floor-plan` | 保存平面图编辑结果 |
| GET | `/api/v1/floors/{floorId}/floor-plan/available-rooms` | 获取未关联功能区域列表 |

## 2. 平面图 JSON 数据结构（PRD §7.4）

```json
{
  "version": 1,
  "outline": {
    "points": [{"x": 10, "y": 10}, {"x": 500, "y": 10}, {"x": 500, "y": 300}, {"x": 10, "y": 300}]
  },
  "blocks": [
    {"id": "b1", "x": 120, "y": 200, "width": 80, "height": 60, "room_id": 101}
  ],
  "scale": {"reference_line_pixels": 150, "reference_line_meters": 10, "pixels_per_meter": 15.0},
  "compass": {"north_angle": 0}
}
```

**字段说明**（✚ 为 v1.1 可选扩展字段，旧数据缺失时按默认值处理）

| 字段 | 类型 | 说明 |
|------|------|------|
| version | int | 数据结构版本，当前 1（v1.1 向后兼容扩展可选字段） |
| outline.points | array[{x,y}] | 外墙轮廓顶点坐标 |
| blocks[] | array | 功能区域色块数组 |
| blocks[].id | string | 前端生成的唯一 ID（如 "b1"） |
| blocks[].x/y/width/height | number | 色块位置与尺寸（像素） |
| blocks[].room_id | int \| null | 关联的 `Room.id`；null=未关联方块 |
| ✚ blocks[].vertices | array[{x,y}] | 多边形顶点；矩形时可省略（由 x/y/width/height 推导），不规则形状必填 |
| ✚ blocks[].z_index | int | 图层排序，默认 0 |
| ✚ blocks[].locked | bool | 锁定（不可编辑），默认 false |
| ✚ blocks[].visible | bool | 显隐，默认 true |
| ✚ blocks[].legend_code | string | 图例分类码（如 `cleanliness_iso8`），由 Room 洁净度/温控精度映射，用于工艺编码着色 |
| ✚ blocks[].style | object | 样式覆盖 `{stroke_width, stroke_color, fill_opacity}` |
| scale.reference_line_pixels | number | 比例尺参考线像素长度 |
| scale.reference_line_meters | number | 比例尺参考线实际米数 |
| scale.pixels_per_meter | number | 每米像素数（自动计算） |
| compass.north_angle | number | 指北针角度 |
| ✚ metadata.pdf_page_info | object | PDF 渲染元信息 `{page, mediaBox, cropBox, rotation, userUnit}`，仅编辑期使用 |
| ✚ metadata.render_dpi | int | 底图渲染 DPI（72/150/300），默认 150 |

## 3. POST /api/v1/floors/{floorId}/floor-plan/upload

上传楼层底图 PDF。

**请求**：`multipart/form-data`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | file | 是 | PDF 文件，<50MB |
| confirm_replace | bool | 否 | true=确认替换既有底图；当 floor 已有底图时必填 true |

**响应 200**

```json
{
  "success": true,
  "data": {
    "floor_id": 1,
    "floor_plan_file": "floor-plans/floor-1/20260714-001.pdf",
    "file_url": "https://minio.example.com/pcb-coolsim/floor-plans/floor-1/20260714-001.pdf?X-Amz-Signature=...",
    "file_size_bytes": 5242880,
    "uploaded_at": "2026-07-14T10:00:00Z"
  }
}
```

**行为**：
1. 校验 PDF 格式与大小。
2. 上传至 MinIO（bucket: `pcb-coolsim`，path: `floor-plans/floor-{floorId}/{timestamp}.pdf`）。
3. 更新 `Floor.floor_plan_file` 为 MinIO 对象路径。
4. 若 floor 已有底图且 `confirm_replace != true`，返回 409 要求二次确认（NF-015）。
5. 生成预签名 URL（有效期 1 小时）供前端编辑阶段加载。

**错误码**

| HTTP | code | 触发条件 |
|------|------|----------|
| 400 | VALIDATION_ERROR | 文件格式非 PDF、大小超限 |
| 404 | RESOURCE_NOT_FOUND | floorId 不存在 |
| 403 | INSUFFICIENT_PERMISSIONS | 无写权限 |
| 409 | CONFLICT | 已有底图但未传 confirm_replace=true |
| 500 | STORAGE_ERROR | MinIO 上传失败 |

## 4. GET /api/v1/floors/{floorId}/floor-plan

获取平面图 JSON 数据（查看场景，不含 PDF 底图，F3-012）。

**响应 200**

```json
{
  "success": true,
  "data": {
    "floor_id": 1,
    "floor_name": "1F",
    "floor_plan": {
      "version": 1,
      "outline": { "points": [{"x": 10, "y": 10}, {"x": 500, "y": 10}, {"x": 500, "y": 300}, {"x": 10, "y": 300}] },
      "blocks": [
        {"id": "b1", "x": 120, "y": 200, "width": 80, "height": 60, "room_id": 101, "room_name": "电镀车间"}
      ],
      "scale": {"reference_line_pixels": 150, "reference_line_meters": 10, "pixels_per_meter": 15.0},
      "compass": {"north_angle": 0}
    },
    "has_background": true,
    "updated_at": "2026-07-14T10:00:00Z"
  }
```

> 查看场景返回的 `blocks[].room_name` 等关联信息用于热力图色块标注（F3-018）；底图 URL 不返回（F3-012）。编辑场景如需底图，前端单独调用 `/floor-plan/upload` 或专用预签名 URL 端点（见 O-1）。

**错误码**：`404 RESOURCE_NOT_FOUND`（floorId 不存在或尚无平面图数据）。

## 5. PUT /api/v1/floors/{floorId}/floor-plan

保存平面图编辑结果（F3-011：整层平面图数据以 JSON 提交，覆盖旧数据）。

**请求体**：平面图 JSON 结构（§2）

```json
{
  "version": 1,
  "outline": { "points": [{"x": 10, "y": 10}, {"x": 500, "y": 10}, {"x": 500, "y": 300}, {"x": 10, "y": 300}] },
  "blocks": [
    {"id": "b1", "x": 120, "y": 200, "width": 80, "height": 60, "room_id": 101}
  ],
  "scale": {"reference_line_pixels": 150, "reference_line_meters": 10, "pixels_per_meter": 15.0},
  "compass": {"north_angle": 0}
}
```

**响应 200**

```json
{
  "success": true,
  "data": {
    "floor_id": 1,
    "blocks_count": 15,
    "linked_rooms_count": 12,
    "unlinked_blocks_count": 3,
    "updated_at": "2026-07-14T10:00:00Z"
  }
}
```

**行为**：
- 整体覆盖 `Floor.floor_plan_data`（JSON 字段）。
- 校验 `blocks[].room_id` 引用的 Room 须属于该 floor（跨楼层关联禁止）。
- 面积自动回写：保存时若 block 关联的 room 的多边形面积与 `Room.area` 偏差 >5%，提示用户确认是否更新 `Room.area`（详见数据流设计.md）。

**错误码**

| HTTP | code | 触发条件 |
|------|------|----------|
| 400 | VALIDATION_ERROR | JSON 结构非法、version 不支持 |
| 404 | RESOURCE_NOT_FOUND | floorId 不存在 |
| 403 | INSUFFICIENT_PERMISSIONS | 无写权限 |
| 422 | VALIDATION_ERROR | blocks[].room_id 不属于该 floor |

## 6. GET /api/v1/floors/{floorId}/floor-plan/available-rooms

获取该楼层下未关联到平面图方块的功能区域列表，用于编辑时关联新方块。

**响应 200**

```json
{
  "success": true,
  "data": {
    "floor_id": 1,
    "available_rooms": [
      { "room_id": 105, "room_name": "蚀刻区", "room_code": "R005", "area": 320.50, "status": "active" },
      { "room_id": 106, "room_name": "阻焊区", "room_code": "R006", "area": 280.00, "status": "active" }
    ],
    "total": 2
  }
}
```

**行为**：查询该 floor 下所有 `Room`，排除已出现在 `Floor.floor_plan_data.blocks[].room_id` 中的房间，返回剩余未关联列表。

**错误码**：`404 RESOURCE_NOT_FOUND`（floorId 不存在）。

---

## 7. 删除房间对平面图的影响

删除功能区域时（房间接口.md §4.4），系统自动从 `Floor.floor_plan_data.blocks[]` 中清除引用该 `room_id` 的关联（方块图形保留，标注「未关联」，F3-019 / 16.1.5）。
