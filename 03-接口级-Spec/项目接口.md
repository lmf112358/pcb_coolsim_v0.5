## 1. 概述

项目（Project）是系统的顶层组织实体，承载「项目 → 建筑 → 楼层 → 房间」四级层级（SAC-1）的第一级。本文件覆盖项目资源 CRUD 与城市参数查询端点。

创建项目时的关键副作用（见模块-01 §4.2）：
1. 关联城市 `city_id`（FK → `CityConfig`），自动读取该城市国标室外设计参数供展示与计算使用。
2. 自动生成 2 条默认冷冻水温度配置（`WaterTempConfig`：低温 7/12℃、中温 12/17℃）。
3. 触发 Celery 异步任务 `fetch_weather_data(project_id)` 拉取气象数据（详见气象接口.md）。

### 1.1 端点总览（附录D 权威清单）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/projects` | 项目列表（分页/搜索/状态过滤） |
| POST | `/api/v1/projects` | 创建项目（含城市关联与副作用） |
| GET | `/api/v1/projects/{id}` | 项目详情（含建筑列表、天气态、计算态） |
| PUT | `/api/v1/projects/{id}` | 更新项目 |
| DELETE | `/api/v1/projects/{id}` | 删除项目（级联删除下属层级） |
| POST | `/api/v1/projects/{projectId}/buildings` | 创建建筑（层级归属在路径中表达） |
| PUT | `/api/v1/buildings/{id}` | 更新建筑 |
| DELETE | `/api/v1/buildings/{id}` | 删除建筑（级联楼层/房间） |
| POST | `/api/v1/buildings/{buildingId}/floors` | 创建楼层 |
| PUT | `/api/v1/floors/{id}` | 更新楼层 |
| DELETE | `/api/v1/floors/{id}` | 删除楼层（级联房间） |
| GET | `/api/v1/cities` | 城市列表（国标参数，NF-010 <1s） |
| GET | `/api/v1/cities/{id}` | 城市详情（国标室外设计参数） |

> 层级 POST 采用 `/api/v1/{parentPath}/{parentId}/{child}` 嵌套风格（附录D 权威路径），父级归属在路径中显式表达；PUT/DELETE 用 `/api/v1/{resource}/{id}` 平坦风格。

## 3. 项目端点详细设计

### 3.1 GET /api/v1/projects

**查询参数**：`page`(int,默认1)、`page_size`(int,默认20,最大100)、`search`(string,按 name/code 模糊)、`status`(enum: active|archived)。

**响应 200**：`data.items[]` 含 `id, project_name, project_code, city{id,city_name,province}, location, building_count, total_cooling_load, status, created_at, updated_at`；`data.pagination{page,page_size,total,total_pages}`。

### 3.2 POST /api/v1/projects

**请求体**

| 字段 | 必填 | 校验规则 |
|------|------|----------|
| project_name | 是 | 非空，≤200 |
| city_id | 是 | 必须存在于 `CityConfig`（否则 404 RESOURCE_NOT_FOUND） |
| location | 否 | ≤200 |
| project_code | 否 | ≤50 |
| description | 否 | ≤500 |

```json
{
  "project_name": "深圳宝安 PCB 工厂",
  "project_code": "SZ-BA-2026-001",
  "city_id": 2,
  "location": "宝安区XX街道XX号",
  "description": "大型PCB制造工厂"
}
```

**响应 201**：返回创建后的项目（含自动生成的 `water_temp_configs` 两条、关联 `city` 对象、`created_at`）。

**副作用**：
- 同步：写入 `Project` + 2 条 `WaterTempConfig`。
- 异步：派发 Celery 任务拉取天气（任务 ID 通过气象接口/WebSocket 跟踪）。

**错误码**：`400 VALIDATION_ERROR`、`404 RESOURCE_NOT_FOUND`（city_id 不存在）、`409 DUPLICATE_RESOURCE`（project_code 冲突，若启用唯一约束）。

### 3.3 GET /api/v1/projects/{id}

**响应 200**：详情含 `buildings[]`（id, building_name, floor_count, room_count）、`weather_data_status`(available/pending/missing)、`last_static_calculation`(datetime|null)、`water_temp_configs` 等。

**错误码**：`404 RESOURCE_NOT_FOUND`（id 不存在或无权限）。

### 3.4 PUT /api/v1/projects/{id}

**请求体**：同创建（全部可选，部分更新）。`city_id` 修改需二次确认（F1-023：切换城市将导致国标参数和气象数据失效）。

**响应 200**：同详情结构。

### 3.5 DELETE /api/v1/projects/{id}

**响应 204**：No Content。级联删除下属 `Building → Floor → Room` 及其全部计算结果（NF-015 删除前二次确认，提示受影响子节点数量）。

**错误码**：`404 RESOURCE_NOT_FOUND`、`403 INSUFFICIENT_PERMISSIONS`。

## 4. 建筑端点详细设计（补 PUT/DELETE）

### 4.1 POST /api/v1/projects/{projectId}/buildings

**请求体**（`project_id` 由路径提供，不需在 body 中重复）

| 字段 | 必填 | 校验 |
|------|------|------|
| building_name | 是 | 非空 ≤100 |
| building_code | 否 | ≤50 |
| description | 否 | ≤500 |

```json
{ "building_name": "2#厂房", "building_code": "B002", "description": "二期生产厂房" }
```

**响应 201**：返回 `{id, project_id, building_name, building_code, description, created_at}`。

**错误码**：`404 RESOURCE_NOT_FOUND`（projectId 不存在或无权限）。

### 4.2 PUT /api/v1/buildings/{id}（新增）

更新建筑信息（F2-002 编辑功能）。

**请求体**：`building_name`(可选)、`building_code`(可选)、`description`(可选)。

**响应 200**：返回更新后的建筑对象。

**错误码**：`400 VALIDATION_ERROR`、`404 RESOURCE_NOT_FOUND`、`403 INSUFFICIENT_PERMISSIONS`。

### 4.3 DELETE /api/v1/buildings/{id}（新增）

删除建筑，级联删除下属楼层、房间及计算结果（F2-002 删除功能；NF-015 二次确认提示子节点数量）。

**响应 204**：No Content。

**错误码**：`404 RESOURCE_NOT_FOUND`、`403 INSUFFICIENT_PERMISSIONS`。

> 注：建筑下有已计算的房间时，前端应在二次确认弹窗中展示「将删除 N 楼层 / M 房间 / K 计算结果」。

## 6. 城市端点详细设计（新增，NF-010 <1s）

城市配置为系统预置只读数据（`CityConfig` 表，约 300 城市），用于项目创建时关联国标室外设计参数。本组端点支持城市下拉检索与详情查询，性能须满足 NF-010（<1s）。

### 6.1 GET /api/v1/cities

**查询参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| search | string | 否 | 按 `city_name` / `province` 模糊匹配 |
| province | string | 否 | 按省份精确过滤 |
| page | int | 否 | 默认 1（城市数量少，可一次返回） |
| page_size | int | 否 | 默认 50，最大 200 |

**响应 200**

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "id": 2,
        "city_name": "深圳",
        "province": "广东",
        "station_name": "深圳气象站",
        "latitude": "22°33'",
        "longitude": "114°03'",
        "temp_dry_ac_summer": 33.7,
        "temp_wet_ac_summer": 27.9,
        "pressure_summer": 1003.4,
        "wind_speed_summer": 2.2
      }
    ],
    "pagination": { "page": 1, "page_size": 50, "total": 312, "total_pages": 7 }
  }
}
```

> 列表仅返回查询/下拉所需核心字段（名称、省份、关键气象参数），完整国标参数通过 `/cities/{id}` 详情获取。

**性能**：`CityConfig` 为小表（~300 行）+ `city_name` 索引，常驻 Redis 缓存（TTL 5min），P99 < 200ms（满足 NF-010 <1s）。

**错误码**：`400 VALIDATION_ERROR`（参数非法）。

### 6.2 GET /api/v1/cities/{id}

获取城市完整国标室外设计参数，用于项目创建时的参数预填与静态计算。

**响应 200**

```json
{
  "success": true,
  "data": {
    "id": 2,
    "city_name": "深圳",
    "province": "广东",
    "station_name": "深圳国家气候观象台",
    "station_code": "G4501",
    "latitude": "22°33'",
    "longitude": "114°03'",
    "altitude": 18.20,
    "statistical_years": "1971-2000",
    "pressure_winter": 1014.2,
    "pressure_summer": 1003.4,
    "wind_speed_winter": 3.0,
    "wind_speed_summer": 2.2,
    "temp_dry_ac_summer": 33.7,
    "temp_wet_ac_summer": 27.9,
    "temp_dry_vent_summer": 30.5,
    "temp_dry_ac_winter": 6.0,
    "humidity_ac_winter": 70.0,
    "temp_dry_vent_winter": 9.5
  }
}
```

**字段说明**（对应 `CityConfig` 表 `[SEED]` 字段）

| 字段 | 单位 | 用途 |
|------|------|------|
| temp_dry_ac_summer | ℃ | 夏季空调室外计算干球温度（静态计算最不利工况） |
| temp_wet_ac_summer | ℃ | 夏季空调室外计算湿球温度（焓值计算输入） |
| pressure_summer | hPa | 夏季大气压（psychrolib 输入） |
| wind_speed_summer | m/s | 夏季风速（参考） |
| temp_dry_ac_winter / humidity_ac_winter | ℃ / % | 冬季参数（v0.5 静态主要用夏季） |

**错误码**：`404 RESOURCE_NOT_FOUND`（cityId 不存在）。

> 此端点为只读，所有用户（含 viewer）均可访问；与项目数据隔离无关。

## 7. 鉴权与数据隔离

- 所有端点需 `Authorization: Bearer {access_token}`。
- 项目级数据隔离（F1-026）：仅项目成员可见；列表返回当前用户有权限的项目。
- 越权访问返回 `403 INSUFFICIENT_PERMISSIONS`。
- `/api/v1/cities` 与 `/api/v1/cities/{id}` 为只读公共数据，不受项目隔离限制。

## 9. 待确认 / 开放问题

- **O-1 project_code 唯一性**：是否对 `project_code` 加唯一约束（启用 → 返回 409 DUPLICATE_RESOURCE）待确认。
- **O-2 city_id 可变性与天气重拉**：创建后修改 `city_id` 是否触发气象与既有计算重算（F1-023 弹窗确认机制已定义，重算策略待确认）。
