## 1. 概述

本文档定义前端组件的 **Props / Events / 接口（TypeScript interface）**，供工程师直接实现。组件分两类：

- **通用组件**：DataTable（表格）、FormField（表单）、ChartPanel（图表）、HeatmapViewer（热力图）
- **业务组件**：TreeNav（树形导航）、Editor2D（2D 编辑器）、LoadCurveChart（负荷曲线）、ConversationPanel（对话采集）

所有组件遵循设计系统 §2 色板（`--color-primary` 等 CSS 变量）、§4 间距（`xxs`~`xxl`）、§5 组件规范；对话式采集相关气泡/卡片复用 §5.9，不另起设计语言。标识符用英文：组件与接口用 PascalCase，props/事件用 camelCase，API 字段用 snake_case（与数据库/API 总览一致）。

## 2. 通用组件

### 2.1 DataTable（数据表格）

对应设计系统 §5.3。树形/结果页通用表格。

```typescript
interface TableColumn<T> {
  key: keyof T | string;
  title: string;            // i18n key 或文本
  sortable?: boolean;
  filterable?: 'text' | 'range' | 'select';
  filterOptions?: { label: string; value: string }[];
  width?: number;
  align?: 'left' | 'right' | 'center';
  render?: (record: T) => React.ReactNode;
}

interface DataTableProps<T> {
  columns: TableColumn<T>[];
  dataSource: T[];
  rowKey: keyof T;
  loading?: boolean;
  pagination?: { page: number; pageSize: number; total: number };
  selection?: boolean;                 // 多选
  virtual?: boolean;                  // 虚拟滚动（树 1000 节点 < 2s，架构 §7.1）
  emptyText?: string;
  onRowClick?: (record: T) => void;
  onSortChange?: (key: string, order: 'asc' | 'desc') => void;
  onFilterChange?: (filters: Record<string, unknown>) => void;
  onPageChange?: (page: number, pageSize: number) => void;
  onSelectionChange?: (keys: Array<string | number>) => void;
  onExport?: () => void;               // 导出选中/全部
}
```

**Events**：`onRowClick` / `onSortChange` / `onFilterChange` / `onPageChange` / `onSelectionChange` / `onExport`。
**说明**：行高 48px（紧凑 36px），斑马纹可选，分页默认 20/页；大数据走虚拟滚动。

### 2.2 FormField（表单字段）

对应设计系统 §5.4。封装输入/下拉/数字等，支持防抖校验。

```typescript
type FieldType = 'text' | 'number' | 'select' | 'textarea' | 'switch' | 'date';

interface FormFieldProps {
  name: string;                 // 对应 API 字段（snake_case），如 'civil_load_index'
  label: string;
  type: FieldType;
  value: unknown;
  required?: boolean;
  readonly?: boolean;           // 如 volume 自动计算
  disabled?: boolean;
  placeholder?: string;
  options?: { label: string; value: string | number }[];   // select
  min?: number; max?: number; step?: number;               // number
  unit?: string;                // 如 'W/m²' 'm³/h' '℃'
  helpText?: string;
  error?: string | null;        // 校验错误，防抖后回填
  debounceMs?: number;          // 默认 500（实时预览）
  onChange: (name: string, value: unknown) => void;
  onValidate?: (name: string, valid: boolean, message?: string) => void;
}
```

**Events**：`onChange` / `onValidate`（防抖校验反馈）。

### 2.3 ChartPanel（图表容器）

封装 ECharts 5.x（设计系统 §5.5），统一主题/自适应/导出。

```typescript
type ChartKind = 'line' | 'bar' | 'pie' | 'treemap' | 'duration';

interface ChartPanelProps {
  kind: ChartKind;
  title?: string;
  data: Array<Record<string, unknown>>;
  xField?: string; yField?: string;
  series?: string[];                   // 多系列
  stack?: boolean;                     // 堆叠（按水温档）
  theme?: 'light' | 'dark';            // 跟随设计系统 §6
  loading?: boolean;
  exportable?: boolean;                // PNG/SVG 下载
  onLegendToggle?: (series: string) => void;
  onItemClick?: (payload: Record<string, unknown>) => void;  // 点击联动表格
  onZoom?: (range: [string, string]) => void;                // 缩放（负荷曲线）
}
```

**Events**：`onLegendToggle` / `onItemClick`（如点击柱筛选结果表）/ `onZoom`。

### 2.4 HeatmapViewer（热力图）

Canvas（Fabric.js）渲染（设计系统 §5.6 / 页面设计 §8）。

```typescript
interface HeatmapRoom {
  id: number;
  name: string;
  polygon: number[][];          // 多边形顶点（来自 2D 编辑器或 PDF 解析）
  loadValue: number;            // 着色依据（total_load kW）
  density?: number;             // W/m²
  tier?: string;
}

interface HeatmapViewerProps {
  rooms: HeatmapRoom[];
  backgroundImage?: string;     // 楼层 PDF（可选）
  colorScale?: '5level';        // 设计系统 §2.5 五档
  showLegend?: boolean;
  fitOnMount?: boolean;
  onRoomClick?: (roomId: number) => void;
  onRoomHover?: (roomId: number | null) => void;
  onZoom?: (delta: number) => void;
}
```

**Events**：`onRoomClick`（选中→详情面板/跳转 Tab2）/ `onRoomHover` / `onZoom`。性能：100 房间 < 3s（设计系统 §5.6）。

## 3. 业务组件

### 3.1 TreeNav（树形导航）

四级层级 project→building→floor→room（设计系统 §5.2 / 页面设计 §4 工作台）。

```typescript
type TreeNodeType = 'project' | 'building' | 'floor' | 'room';

interface TreeNode {
  id: number;
  type: TreeNodeType;
  name: string;
  parentId?: number;
  count?: number;              // 子节点数（building_count/room_count）
  status?: 'draft' | 'active'; // room 草稿态
  hasCalculation?: boolean;    // has_calculation
}

interface TreeNavProps {
  projectId: number;
  nodes: TreeNode[];
  selectedId?: number;
  searchable?: boolean;        // 实时过滤高亮
  resizable?: boolean;         // 宽 200~400，默认 280
  onSelect: (node: TreeNode) => void;
  onContextMenu?: (node: TreeNode, action: 'add' | 'edit' | 'delete' | 'copy') => void;
  onReorder?: (nodeId: number, targetId: number) => void;
}
```

**Events**：`onSelect`（点击→右侧详情/内容面板）/ `onContextMenu`（右键增删改）/ `onReorder`（同级拖拽）。
**接口**：数据来自 `GET /api/v1/projects/{id}/`、`GET /api/v1/buildings/?project=`、`GET /api/v1/floors/?building=`、`GET /api/v1/rooms/?floor=`（API 总览 §3~§6）。

### 3.2 Editor2D（2D 编辑器）

Canvas 楼层平面编辑（页面设计 §10 / 设计系统复用 §5.6 画布规范）。

```typescript
interface RoomPolygon {
  id: number | null;           // null=未关联 room
  points: number[][];          // 顶点
  area: number;                // 自动计算 m²
  rotation?: number;
  fillColor?: string;
}

interface Editor2DProps {
  floorId: number;
  backgroundPdf?: string;
  polygons: RoomPolygon[];
  scaleRatio?: number;         // 比例尺（Scale 工具设定）
  northAngle?: number;         // 指北（Compass）
  readOnly?: boolean;
  onPolygonAdd?: (poly: RoomPolygon) => void;
  onPolygonEdit?: (id: number | null, poly: RoomPolygon) => void;
  onPolygonSelect?: (id: number | null) => void;
  onUndo?: () => void; onRedo?: () => void;
  onSave?: (polygons: RoomPolygon[]) => void;   // 保存→回写 room.area
}
```

**Events**：`onPolygonAdd` / `onPolygonEdit` / `onPolygonSelect` / `onUndo` / `onRedo` / `onSave`（面积自动回写 `room.area`）。
**接口**：保存目标为 `PUT /api/v1/rooms/{id}/`（更新 area/height/volume）或批量更新（待确认批量端点）。

### 3.3 LoadCurveChart（负荷曲线）

8760h 逐时负荷曲线（页面设计 §7.3 / 设计系统 §5.5）。

```typescript
interface LoadPoint {
  datetime: string;            // ISO
  loadKw: number;
  outdoorTemp?: number;
}

interface LoadCurveChartProps {
  projectId: number;
  roomId?: number;             // 可选，按房间
  data: LoadPoint[];
  aggregation?: 'hourly' | 'daily' | 'monthly';  // 缩放层级
  showOutdoorTemp?: boolean;   // 背景面积图
  brushSelect?: boolean;       // 框选时间范围
  loading?: boolean;
  onZoomLevelChange?: (level: 'year' | 'month' | 'day') => void;
  onRangeSelect?: (start: string, end: string) => void;
  onExport?: (fmt: 'png' | 'svg') => void;
}
```

**Events**：`onZoomLevelChange` / `onRangeSelect`（框选）/ `onExport`。
**接口**：数据来自 `GET /api/v1/calculations/dynamic/{project_id}/?room_id=&aggregation=`（API 总览 §7.5）。注意逐时数据 26280 点/房间，前端需降采样/分块加载。

### 3.4 ConversationPanel（对话式采集，复用 §5.9）

```typescript
type Stage = 's1_project' | 's2_water_temp' | 's3_building' | 's4_room' | 's5_extra_load' | 's6_summary';

interface ConversationPanelProps {
  projectId: number;
  sessionId?: string;          // 续采时传入
  currentStage: Stage;
  stageStatus: Record<Stage, 'done' | 'pending' | 'active'>;
  draftPayload: Record<string, unknown>;
  onSendMessage: (text: string) => void;        // → POST /conversation/sessions/{id}/message/
  onSaveDraft: (payload: object) => void;       // → PUT /conversation/sessions/{id}/draft/
  onFinalize: () => void;                       // → POST .../finalize/
  onResume: (sessionId: string) => void;        // → GET /conversation/sessions/{id}/
}
```

**Events**：`onSendMessage` / `onSaveDraft` / `onFinalize` / `onResume`。视觉严格复用设计系统 §5.9（Chat Bubble / Tool Card / Summary Card / Chip / Stage Nav / Structured Preview），不另起色板。

## 4. 待确认

1. **Editor2D 批量保存端点**：房间面积批量回写是否复用 `PUT /api/v1/rooms/{id}/` 逐条，或新增批量端点——**待确认**（API 总览未列批量房间更新）。
2. **LoadCurveChart 降采样策略**：26280 点前端展示的降采样粒度（按日/按周）由前端还是后端完成——**待确认**。
3. **HeatmapViewer 多边形来源**：房间多边形由 2D 编辑器绘制还是由 PDF 自动解析——**待确认**（影响 `RoomPolygon.points` 供给）。
4. **TreeNav 数据加载**：四级树是全量一次拉取还是懒加载（点击展开再请求）——影响 `nodes` 结构与接口调用（倾向懒加载，匹配现有 `?project/?building/?floor` 列表端点）。
