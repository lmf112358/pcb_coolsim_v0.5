# 接口级详细设计：计算接口（静态冷量）

> 版本：1.0
> 日期：2026-07-13
> 状态：已完成
> PRD 引用：F4-001（土建冷量）、F4-002（照明冷量）、F4-003（人员冷量）、SAC-2（与 Excel 验算偏差 < 0.1%）
> 依赖文档：01-系统级-Spec/API总览.md（§7.1~§7.3）、02-模块级-Spec/模块-04-静态冷量计算.md、01-系统级-Spec/数据库设计.md（room_load_parameter / room_load_result / room_load_summary / room_air_volume_*）

---

## 1. 概述

静态冷量计算在「设计日最不利工况」下逐房间计算：末端负荷（土建+照明+人员+设备） + 新风冷负荷（按水温档分类）。本文件覆盖 3 个端点：单房间计算、批量计算（异步）、结果查询。计算链路与数据库设计 §6 一致，精度须满足 SAC-2（< 0.1%）。

---

## 2. 端点总览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/rooms/{id}/calculate-static/` | 单房间静态计算（同步，返回逐步明细） |
| POST | `/api/v1/projects/{id}/calculate-static/` | 项目批量计算（异步 Celery，202 + task_id） |
| GET | `/api/v1/calculations/static/{project_id}/` | 静态计算结果查询（按建筑/楼层/水温聚合） |

---

## 3. 单房间计算 POST /api/v1/rooms/{id}/calculate-static/

**请求**：无 body（使用房间当前 `room_load_parameter` / `room_air_volume_parameter` / `room` / `city_config` / `water_temperature_config`）。

**响应 200**：6 步明细（同 API总览 §7.1）：

```json
{
  "success": true,
  "data": {
    "room_id": 1,
    "calculation_date": "2026-07-09T14:00:00Z",
    "steps": {
      "step1_enthalpy": { "indoor_enthalpy": 52.34, "outdoor_enthalpy": 90.12, "enthalpy_diff": 37.78, "status": "success" },
      "step2_terminal_load": { "civil_load": 22500.00, "lighting_load": 9000.00, "personnel_load": 1800.00, "electric_equipment_load": 51200.00, "exhaust_heated_equipment_load": 16800.00, "no_exhaust_heated_equipment_load": 12000.00, "terminal_load": 113300.00, "status": "success" },
      "step3_air_volume": { "total_exhaust_volume": 2000.00, "infiltration_volume": 450.00, "fresh_air_volume": 2450.00, "supply_air_volume": 15000.00, "return_air_volume": 12550.00, "status": "success" },
      "step4_fresh_air_load": { "fresh_air_load": 92561.00, "water_tier": "mid_temp", "status": "success" },
      "step5_total_load": { "terminal_load": 113300.00, "fresh_air_load": 92561.00, "total_load": 205861.00, "status": "success" }
    },
    "summary": { "terminal_load_kw": 113.30, "fresh_air_load_kw": 92.56, "total_load_kw": 205.86, "load_density_w_m2": 411.72 },
    "warnings": []
  }
}
```

**字段与数据库写入映射**

| 步骤字段 | 写入表 | DB 字段 |
|----------|--------|---------|
| step2.civil_load 等 | room_load_result | civil_load, lighting_load, personnel_load, electric_equipment_load, heated_equipment_load, terminal_load |
| step2.terminal_load | room_load_result | terminal_load（[RESULT]） |
| step3.fresh_air_volume 等 | room_air_volume_result | fresh_air_volume, supply_air_volume, return_air_volume, total_exhaust_volume, infiltration_air_volume |
| step1.enthalpy_diff | room_air_volume_result | enthalpy_diff, indoor_enthalpy_calc, outdoor_enthalpy_calc |
| step4/step5 按水温 | room_load_summary | fresh_air_load, terminal_load, total_load（每 water_temp_config 一行） |
| summary.load_density | room_load_result | cold_load_index |

**核心公式（对齐 F4-001~F4-003 与数据库设计 §4.9）**

```
civil_load     = civil_load_index × area / 1000          # F4-001
lighting_load  = lighting_load_index × area / 1000       # F4-002
personnel_load = personnel_load_index × personnel_count / 1000   # F4-003（空值按 0）
electric_equipment_load = electric_equipment_power × electric_equipment_coefficient
heated_equipment_load  = power_with_exhaust × coef_with_exhaust + power_without_exhaust × coef_without_exhaust
terminal_load  = civil + lighting + personnel + electric + heated
fresh_air_load = fresh_air_volume × 1.2 × enthalpy_diff / 3600   # 按水温档
total_load     = fresh_air_load + terminal_load
```

**错误码**：`404 RESOURCE_NOT_FOUND`（房间不存在）、`422 CALCULATION_ERROR`（参数缺失/非法，如缺 civil_load_index）、`422 WEATHER_DATA_MISSING`（城市室外参数缺失）。

## 4. 批量计算 POST /api/v1/projects/{id}/calculate-static/

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| building_ids | array[int] | 否 | 限定建筑范围 |
| floor_ids | array[int] | 否 | 限定楼层范围 |
| room_ids | array[int] | 否 | 限定房间范围 |
| recalculate_all | bool | 否 | 强制重算（覆盖既有结果） |

```json
{ "building_ids": [1, 2], "floor_ids": null, "room_ids": null, "recalculate_all": false }
```

**响应 202**（异步）：返回 `task_id`、`status:"processing"`、`message`、`websocket_url`（ws://.../ws/tasks/{task_id}/）。进度通过 WebSocket（API总览 §11）或轮询跟踪。

**行为**：遍历范围内房间，逐项执行 §3 计算并写入 `room_load_result` / `room_air_volume_result` / `room_load_summary`，再聚合写 `load_summary`（scope=floor/building/project）。跳过无参数的房间并记 `warnings`。

**错误码**：`404`（项目不存在）、`422 CALCULATION_ERROR`（范围为空或无任何可算房间）。

---

## 5. 结果查询 GET /api/v1/calculations/static/{project_id}/

**查询参数**：`building_id`(int)、`floor_id`(int)、`water_tier_id`(int，即 `water_temp_config_id`)。

**响应 200**（同 API总览 §7.3）：`summary{total_rooms, calculated_rooms, skipped_rooms, total_load_kw, by_water_tier{low_temp_7_12, mid_temp_12_17}}` + 树形 `buildings[]{floors[]{rooms[]{terminal_load_kw, fresh_air_load_kw, total_load_kw, water_tier}}}`。

**数据来源**：`room_load_summary`（房间级，按水温）向上聚合成 `load_summary`（楼层/建筑/项目级）。

**错误码**：`404 RESOURCE_NOT_FOUND`、`403 INSUFFICIENT_PERMISSIONS`。

## 6. 验收映射（SAC-2）

| 验收项 | 实现点 |
|--------|--------|
| 与手工 Excel 验算偏差 < 0.1% | 公式严格对齐数据库设计 §4.9/§4.12，系数一致 |
| 结果按水温分类 | room_load_summary 按 water_temp_config 多行 |
| 进度条（批量） | WebSocket progress 消息（§11） |
| 错误带房间标识 | CALCULATION_ERROR 携带 room_id |

## 7. 待确认 / 开放问题

- **O-1 批量计算的同步回查**：202 仅返回 task_id；前端如何判定「全部完成」建议以 WebSocket `completed` 消息 + GET 结果查询双重确认，是否提供轮询 REST 状态端点待确认。
- **O-2 season 维度**：`room_load_parameter` 含 `season_id`；静态计算是否对所有季节各算一遍并分别写 `room_load_result(season_id)`，待确认（影响结果查询是否需 season 过滤）。
- **O-3 no_exhaust 字段 API 命名**：API 单房间响应含 `no_exhaust_heated_equipment_load`，创建房间请求用 `load_parameters.exhaust_heated_equipment_*`，无排风分支需与 `heated_equipment_power_without_exhaust` 对齐命名。
