## 1. 接口概述

### 1.1 功能职责

项目接口负责管理 PCB 冷源仿真平台的核心组织单元——项目。项目是建筑、楼层、功能区域的顶层容器，也是数据隔离的基本单位。

**核心功能：**
- 项目 CRUD（创建、读取、更新、删除）
- 地图首页项目标点展示
- 项目成员管理（邀请、移除、角色分配）
- 项目搜索和筛选

### 1.2 数据模型

**Project 模型：**
```python
class Project(models.Model):
    """
    项目模型

    PRD 引用：F1-015 ~ F1-023
    Spec 引用：项目接口 Section 1.2
    """
    STATUS_CHOICES = [
        ('designing', '设计中'),
        ('completed', '已竣工'),
    ]

    WEATHER_STATUS_CHOICES = [
        ('pending', '待获取'),
        ('fetching', '获取中'),
        ('ready', '已就绪'),
        ('missing', '数据缺失'),
    ]

    id = models.BigAutoField(primary_key=True)
    name = models.CharField(max_length=200, help_text="项目名称")
    project_code = models.CharField(
        max_length=50,
        blank=True,
        help_text="项目编号"
    )
    city = models.ForeignKey(
        'City',
        on_delete=models.PROTECT,
        related_name='projects',
        help_text="所属城市"
    )
    address = models.CharField(
        max_length=500,
        blank=True,
        help_text="详细地址"
    )
    latitude = models.DecimalField(
        max_digits=9,
        decimal_places=6,
        null=True,
        blank=True,
        help_text="纬度"
    )
    longitude = models.DecimalField(
        max_digits=9,
        decimal_places=6,
        null=True,
        blank=True,
        help_text="经度"
    )
    description = models.TextField(blank=True, help_text="项目描述")
    status = models.CharField(
        max_length=20,
        choices=STATUS_CHOICES,
        default='designing',
        help_text="项目状态"
    )
    weather_status = models.CharField(
        max_length=20,
        choices=WEATHER_STATUS_CHOICES,
        default='pending',
        help_text="气象数据状态"
    )
    weather_last_updated = models.DateTimeField(
        null=True,
        blank=True,
        help_text="气象数据最后更新时间"
    )
    created_by = models.ForeignKey(
        'User',
        on_delete=models.SET_NULL,
        null=True,
        related_name='created_projects'
    )
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        db_table = 'project'
        ordering = ['-created_at']
```

### 4.6 业务逻辑

```python
# 项目创建流程
def create_project(data, user):
    """
    PRD 引用：F1-015 ~ F1-023
    Spec 引用：项目接口 Section 4.6
    """
    # 1. 参数校验
    validate_project_data(data)

    # 2. 检查项目编号唯一性（如果提供）
    if data.get('project_code'):
        if Project.objects.filter(project_code=data['project_code']).exists():
            raise ValidationError("项目编号已存在")

    # 3. 获取城市信息并填充国标参数
    city = City.objects.get(id=data['city_id'])
    latitude = city.latitude
    longitude = city.longitude

    # 4. 创建项目
    project = Project.objects.create(
        name=data['name'],
        project_code=data.get('project_code'),
        city=city,
        address=data.get('address'),
        latitude=latitude,
        longitude=longitude,
        description=data.get('description'),
        status='designing',
        weather_status='pending',
        created_by=user
    )

    # 5. 自动预置默认冷冻水配置（PRD: F1-018）
    ChilledWaterConfig.objects.create(
        project=project,
        name='低温',
        supply_temp=7.0,
        return_temp=12.0,
        is_system_default=True
    )
    ChilledWaterConfig.objects.create(
        project=project,
        name='中温',
        supply_temp=12.0,
        return_temp=17.0,
        is_system_default=True
    )

    # 6. 将创建者添加为项目成员（角色：项目经理）
    ProjectMember.objects.create(
        project=project,
        user=user,
        project_role='manager',
        invited_by=user,
        accepted_at=timezone.now()
    )

    # 7. 异步获取气象数据（PRD: F1-019）
    try:
        fetch_weather_data.delay(project.id, city.id)
        project.weather_status = 'fetching'
        project.save()
    except Exception as e:
        # 气象数据获取失败不影响项目创建（PRD: F1-022）
        logger.error(f"气象数据获取任务提交失败: {e}")
        project.weather_status = 'missing'
        project.save()

    # 8. 返回项目详情
    return serialize_project(project)
```

```python
# 更新项目信息
def update_project(project_id, data, user):
    """
    PRD 引用：F1-023
    Spec 引用：项目接口 Section 6.5
    """
    # 1. 获取项目
    project = Project.objects.get(id=project_id)

    # 2. 检查权限
    if not has_project_permission(user, project, 'manager'):
        raise PermissionError("权限不足")

    # 3. 检查城市变更
    city_changed = False
    if 'city_id' in data and data['city_id'] != project.city_id:
        city_changed = True
        new_city = City.objects.get(id=data['city_id'])

    # 4. 更新项目信息
    for field, value in data.items():
        if hasattr(project, field):
            setattr(project, field, value)

    # 5. 如果城市变更，更新经纬度和气象数据状态
    if city_changed:
        project.city = new_city
        project.latitude = new_city.latitude
        project.longitude = new_city.longitude
        project.weather_status = 'pending'

        # 异步重新获取气象数据
        try:
            fetch_weather_data.delay(project.id, new_city.id)
            project.weather_status = 'fetching'
        except Exception as e:
            logger.error(f"气象数据获取任务提交失败: {e}")
            project.weather_status = 'missing'

    project.save()

    # 6. 返回更新后的项目
    result = serialize_project(project)
    if city_changed:
        result['warning'] = "城市已切换，气象数据需要重新获取"

    return result
```

## 7. 删除项目接口

### 7.1 接口定义

- **路径**: `DELETE /api/v1/projects/{id}/`
- **功能**: 删除项目（级联删除所有关联数据）
- **认证**: 需要 Access Token
- **权限**: admin, project_manager

### 7.2 请求规范

**查询参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| confirm | boolean | 是 | 必须为 true 才能删除 |

### 7.3 响应规范

**成功响应（200 OK）：**
```json
{
  "code": 200,
  "message": "删除成功",
  "data": {
    "deleted_stats": {
      "buildings": 3,
      "floors": 15,
      "rooms": 150,
      "calculation_results": 150,
      "export_files": 10
    }
  }
}
```

**错误响应（400 Bad Request）：**
```json
{
  "code": 400,
  "message": "缺少确认参数",
  "errors": {
    "confirm": ["必须设置 confirm=true 才能删除项目"]
  }
}
```

### 7.4 错误码定义

| 错误码 | HTTP 状态码 | 说明 | 处理建议 |
|--------|-------------|------|----------|
| PROJ_012 | 400 | 缺少确认参数 | 添加 ?confirm=true |
| PROJ_013 | 403 | 权限不足 | 联系管理员 |
| PROJ_014 | 404 | 项目不存在 | 检查项目 ID |

### 7.5 curl 示例

