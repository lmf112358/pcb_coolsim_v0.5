## 1. 接口概述

### 1.1 功能职责

房间接口管理四级层级结构（项目→建筑→楼层→功能区域）的 CRUD 操作，是数据采集的核心接口。

**核心功能：**
- 四级层级树结构查询
- 建筑、楼层、功能区域 CRUD
- 功能区域数据采集表单
- Excel 导入导出
- 自动保存

### 1.2 数据模型

**Building 模型：**

## 3. 四级层级树接口

### 6.4 业务逻辑

```python
# 创建功能区域时的参数继承
def create_room(data, user):
    """
    PRD 引用：F9-010
    Spec 引用：房间接口 Section 6.4
    """
    # 1. 获取楼层、建筑、项目
    floor = Floor.objects.get(id=data['floor_id'])
    building = floor.building
    project = building.project

    # 2. 继承默认参数（如果未提供）
    inherited_params = inherit_params_for_new_room(
        project.id, building.id, floor.id
    )

    for param_key, param_info in inherited_params.items():
        if param_key not in data:
            data[param_key] = param_info['value']

    # 3. 计算体积
    data['volume'] = data['area'] * data['ceiling_height']

    # 4. 创建功能区域
    room = Room.objects.create(**data)

    return serialize_room(room)
```

|------|------|------|------|
| room_id | int | 是 | 功能区域 ID |
| data | object | 是 | 需要保存的字段（部分更新） |
| timestamp | datetime | 是 | 客户端时间戳（用于冲突检测） |

### 8.3 响应规范

**成功响应（200 OK）：**
```json
{
  "code": 200,
  "message": "自动保存成功",
  "data": {
    "room_id": 1,
    "saved_at": "2026-07-10T10:00:30Z",
    "server_timestamp": "2026-07-10T10:00:30Z"
  }
}
```

**冲突响应（409 Conflict）：**
```json
{
  "code": 409,
  "message": "数据冲突",
  "data": {
    "conflict": true,
    "server_timestamp": "2026-07-10T10:00:35Z",
    "server_data": {
      "area": 250.0
    },
    "client_timestamp": "2026-07-10T10:00:30Z",
    "client_data": {
      "area": 200.0
    }
  }
}
```

### 8.4 错误码定义

| 错误码 | HTTP 状态码 | 说明 | 处理建议 |
|--------|-------------|------|----------|
| ROOM_007 | 409 | 数据冲突 | 提示用户选择保留哪个版本 |
