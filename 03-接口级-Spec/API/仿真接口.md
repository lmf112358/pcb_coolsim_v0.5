## 1. 接口概述

### 1.1 功能职责

仿真接口负责执行动态负荷仿真计算，基于气象数据驱动，使用比例系数法计算全年 8760 逐时负荷。

**核心功能：**
- 动态仿真计算（气象数据驱动）
- 仿真任务管理（提交、查询、取消）
- 仿真结果查询（逐时、聚合）
- 8760 数据存储与查询（TimescaleDB）

### 1.2 计算原理

```
预测负荷 Q_dynamic(t) = Q_terminal × K(T_outdoor(t), R_production)

其中：
- Q_terminal：末端负荷（静态计算结果）
- K(T,R)：比例系数（室外温度 × 生产负荷率）
- T_outdoor(t)：逐时室外温度（气象数据）
- R_production：生产负荷率（默认 100%）
```

## 3. 提交仿真任务接口

### 3.1 接口定义

- **路径**: `POST /api/v1/projects/{id}/simulate/`
- **功能**: 提交动态仿真计算任务
- **认证**: 需要 Access Token
- **权限**: admin, project_manager, engineer
- **PRD 引用**: F6-001

### 3.2 请求规范

**路径参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | 是 | 项目 ID |

**请求体：**
```json
{
  "simulation_name": "2025年全年仿真",
  "year": 2025,
  "production_rate": 100,
  "room_ids": [1, 2, 3],
  "weather_data_source": "api",
  "options": {
    "aggregation_level": "room",
    "include_statistics": true,
    "save_hourly_data": true
  }
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 | 校验规则 |
|------|------|------|------|----------|
| simulation_name | string | 否 | 仿真名称 | 最大长度 100 |
| year | int | 是 | 仿真年份 | 2020-2030 |
| production_rate | decimal | 否 | 生产负荷率(%) | 10-100，默认 100 |
| room_ids | array | 否 | 功能区域 ID 列表 | 为空则计算所有 |
| weather_data_source | string | 否 | 气象数据来源 | api, manual |
| options | object | 否 | 计算选项 | - |

### 3.3 响应规范

**成功响应（202 Accepted）：**
```json
{
  "code": 202,
  "message": "仿真任务已提交",
  "data": {
    "simulation_id": "SIM-2026-001",
    "project_id": 1,
    "status": "pending",
    "simulation_name": "2025年全年仿真",
    "year": 2025,
    "room_count": 3,
    "estimated_hours": 8760,
    "estimated_time": 120,
    "created_at": "2026-07-10T10:00:00Z"
  }
}
```

**错误响应（400 Bad Request）：**
```json
{
  "code": 400,
  "message": "参数校验失败",
  "errors": {
    "year": ["气象数据不完整，请先获取气象数据"]
  }
}
```

### 3.4 错误码定义

| 错误码 | HTTP 状态码 | 说明 | 处理建议 |
|--------|-------------|------|----------|
| SIM_001 | 400 | 缺少静态计算结果 | 先执行静态计算 |
| SIM_002 | 400 | 气象数据不完整 | 先获取气象数据 |
| SIM_003 | 400 | 功能区域 ID 无效 | 检查功能区域 ID |
| SIM_004 | 409 | 已有运行中的仿真任务 | 等待或取消现有任务 |
| SIM_005 | 500 | 仿真计算失败 | 稍后重试 |

### 3.6 业务逻辑

```python
# 动态仿真计算引擎
class DynamicSimulationEngine:
    """
    PRD 引用：F6-001
    Spec 引用：仿真接口 Section 3.6
    """

    def submit_simulation(self, project_id, params, user):
        """
        提交仿真计算任务
        """
        # 1. 校验静态计算结果
        project = Project.objects.get(id=project_id)
        rooms = Room.objects.filter(floor__building__project=project)

        if params.get('room_ids'):
            rooms = rooms.filter(id__in=params['room_ids'])

        # 检查是否有静态计算结果
        rooms_without_calc = rooms.exclude(
            calculation_results__isnull=False
        )
        if rooms_without_calc.exists():
            raise ValidationError("部分功能区域缺少静态计算结果")

        # 2. 校验气象数据
        weather_summary = WeatherDataSummary.objects.filter(
            city=project.city,
            year=params['year']
        ).first()

        if not weather_summary or weather_summary.status != 'complete':
            raise ValidationError("气象数据不完整")

        # 3. 创建仿真任务
        simulation = SimulationTask.objects.create(
            project=project,
            name=params.get('simulation_name', f"{params['year']}年仿真"),
            year=params['year'],
            production_rate=params.get('production_rate', 100),
            room_count=rooms.count(),
            status='pending',
            created_by=user
        )

        # 4. 异步执行计算
        run_simulation.delay(simulation.id)

        return serialize_simulation(simulation)
```
