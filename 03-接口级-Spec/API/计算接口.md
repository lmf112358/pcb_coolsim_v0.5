## 1. 接口概述

### 1.1 功能职责

计算接口负责执行系统的核心计算功能，包括：

**静态冷量计算（6 步流水线）：**
1. 末端负荷计算（土建、照明、人员、设备）
2. 风量计算（排风、压差渗透、新风）
3. 新风冷负荷计算（焓值、新风冷量）
4. 总负荷计算（末端 + 新风）
5. 安全系数应用
6. 结果聚合（功能区域→楼层→建筑→项目）

**负荷分析与冷站配置：**
- 5 维度负荷分析
- 冷站方案配置与校验
- N+1 冗余分析
- 水蓄冷配置

### 1.2 计算精度目标

| 计算类型 | 精度目标 | 验证方法 |
|----------|----------|----------|
| 静态冷量计算 | < 0.1% 偏差 | 对比 Excel 参考数据 |
| 动态仿真计算 | < 1% 偏差 | 对比参考脚本 |
| 实时预览 | < 500ms 响应 | 性能测试 |

## 3. 静态冷量计算接口

### 3.1 接口定义

- **路径**: `POST /api/v1/rooms/{id}/calculate-static/`
- **功能**: 计算指定功能区域的静态冷负荷
- **认证**: 需要 Access Token
- **权限**: admin, project_manager, engineer
- **PRD 引用**: F4-001 ~ F4-015

### 3.2 请求规范

**路径参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | 是 | 功能区域 ID |

**请求体（可选，覆盖默认值）：**
```json
{
  "indoor_temp": 23.0,
  "indoor_humidity": 55.0,
  "outdoor_temp": 34.6,
  "outdoor_humidity": 55.0,

  "recalculate": true
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 | 校验规则 |
|------|------|------|------|----------|
| indoor_temp | decimal | 否 | 室内计算温度(°C) | 覆盖功能区域设置 |
| indoor_humidity | decimal | 否 | 室内计算湿度(%) | 覆盖功能区域设置 |
| outdoor_temp | decimal | 否 | 室外设计温度(°C) | 覆盖城市设置 |
| outdoor_humidity | decimal | 否 | 室外设计湿度(%) | 覆盖城市设置 |
| safety_factor | decimal | 否 | 安全系数 | 范围 1.0-1.5 |
| recalculate | boolean | 否 | 强制重新计算 | 默认 false |

### 3.6 业务逻辑

```python
# 静态冷量计算引擎
class StaticCalculationEngine:
    """
    PRD 引用：F4-001 ~ F4-015
    Spec 引用：计算接口 Section 3.6
    """

    def calculate(self, room_id, overrides=None):
        """
        执行 6 步流水线计算
        """
        # 1. 获取功能区域数据
        room = Room.objects.select_related(
            'floor', 'floor__building', 'floor__building__project', 'floor__building__project__city'
        ).get(id=room_id)

        # 2. 获取配置参数
        config_service = ConfigOverrideService()
        params = self._prepare_params(room, config_service, overrides)

        # 3. 步骤 1：末端负荷计算
        step1 = self._calculate_terminal_load(params)

        # 4. 步骤 2：风量计算
        step2 = self._calculate_airflow(params)

        # 5. 步骤 3：新风冷负荷计算
        step3 = self._calculate_fresh_air_load(params, step2)

        # 6. 步骤 4：总负荷计算
        step4 = self._calculate_total_load(step1, step3)

        # 7. 步骤 5：安全系数
        step5 = self._apply_safety_factor(step4, params['safety_factor'])

        # 8. 保存结果
        result = self._save_result(room, step1, step2, step3, step4, step5)

        return result

    def _calculate_terminal_load(self, params):
        """步骤 1：末端负荷计算（PRD: F4-001 ~ F4-006）"""
        Q_civil = params['construction_load_index'] * params['area'] / 1000
        Q_lighting = params['lighting_index'] * params['area'] / 1000
        Q_personnel = params['occupancy_heat'] * params['occupancy_count'] / 1000 if params['occupancy_heat'] else 0
        Q_electric = params['electric_power'] * params['electric_coeff'] if params['electric_power'] else 0
        Q_heated = (params['heat_exhaust_power'] * params['heat_exhaust_coeff'] +
                   params['heat_no_exhaust_power'] * params['heat_no_exhaust_coeff'])

        Q_terminal = Q_civil + Q_lighting + Q_personnel + Q_electric + Q_heated

        return {
            'Q_civil': Q_civil,
            'Q_lighting': Q_lighting,
            'Q_personnel': Q_personnel,
            'Q_electric': Q_electric,
            'Q_heated': Q_heated,
            'Q_terminal': Q_terminal
        }

    def _calculate_airflow(self, params):
        """步骤 2：风量计算（PRD: F4-007 ~ F4-009）"""
        # 总排风量
        V_exhaust = (params['heat_exhaust_volume'] + params['acid_exhaust_volume'] +
                    params['alkali_exhaust_volume'] + params['organic_exhaust_volume'] +
                    params['dust_exhaust_volume'])

        # 压差渗透风量
        volume = params['area'] * params['ceiling_height']
        k_coefficient = self._get_infiltration_coefficient(params['pressure_diff'])
        V_infiltration = volume * k_coefficient

        # 新风量
        V_fresh_air = V_exhaust + V_infiltration

        return {
            'V_exhaust': V_exhaust,
            'V_infiltration': V_infiltration,
            'V_fresh_air': V_fresh_air
        }

    def _calculate_fresh_air_load(self, params, airflow):
        """步骤 3：新风冷负荷计算（PRD: F4-010 ~ F4-015）"""
        import psychrolib

        # 设置大气压力
        psychrolib.SetUnitSystem(psychrolib.SI)

        # 室内焓值
        h_indoor = psychrolib.GetMoistAirEnthalpy(
            params['indoor_temp'],
            params['indoor_humidity'] / 100,
            params['atmospheric_pressure']
        )

        # 室外焓值
        h_outdoor = psychrolib.GetMoistAirEnthalpy(
            params['outdoor_temp'],
            params['outdoor_humidity'] / 100,
            params['atmospheric_pressure']
        )

        # 新风冷量
        Q_fresh_air = (params['air_density'] * airflow['V_fresh_air'] *
                      (h_outdoor - h_indoor) / 3600)

        return {
            'h_indoor': h_indoor,
            'h_outdoor': h_outdoor,
            'Q_fresh_air': Q_fresh_air
        }

    def _calculate_total_load(self, terminal, fresh_air):
        """步骤 4：总负荷计算（PRD: F4-014）"""
        Q_total_raw = terminal['Q_terminal'] + fresh_air['Q_fresh_air']
        Q_total = max(Q_total_raw, 0)  # 负值截断

        return {
            'Q_total_raw': Q_total_raw,
            'Q_total': Q_total
        }

    def _apply_safety_factor(self, total_load, safety_factor):
        """步骤 5：安全系数（PRD: F4-018）"""
        Q_design = total_load['Q_total'] * safety_factor

        return {
            'safety_factor': safety_factor,
            'Q_design': Q_design
        }
```

## 4. 实时预览接口

### 4.1 接口定义

- **路径**: `POST /api/v1/calculations/preview/`
- **功能**: 实时计算预览（简化版，用于即时反馈）
- **认证**: 需要 Access Token
- **权限**: admin, project_manager, engineer
- **限流**: 20 次/秒
- **PRD 引用**: F4-016

### 4.2 请求规范

**请求体：**
```json
{
  "room_id": 1,
  "field": "area",
  "value": 250.0,
  "current_params": {
    "area": 200.0,
    "ceiling_height": 3.0,
    "construction_load_index": 150.0,
    "lighting_index": 20.0,
    "indoor_temp": 23.0,
    "indoor_humidity": 55.0
  }
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| room_id | int | 否 | 功能区域 ID（可选，用于获取完整参数） |
| field | string | 是 | 正在修改的字段名 |
| value | any | 是 | 新的字段值 |
| current_params | object | 是 | 当前表单参数 |

### 4.3 响应规范
