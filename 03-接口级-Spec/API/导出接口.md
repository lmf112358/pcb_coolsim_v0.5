## 1. 接口概述

### 1.1 功能职责

导出接口负责生成和下载各类报告和数据文件。

**支持的导出类型：**
- 静态计算报告（PDF）
- 冷站配置报告（PDF）
- 设备清单（Excel）
- 负荷计算书（Excel）
- 仿真数据（CSV）
- 预测数据（CSV）

### 1.2 导出流程

```
用户请求导出
  ├── 参数校验
  ├── 创建导出任务（状态：pending）
  ├── 异步生成文件（Celery）
  │   ├── 状态：processing
  │   ├── 生成文件
  │   └── 状态：completed 或 failed
  └── 下载文件
```

## 3. 导出静态计算报告接口

### 3.1 接口定义

- **路径**: `POST /api/v1/projects/{id}/exports/static-report/`
- **功能**: 生成静态冷量计算报告 PDF
- **认证**: 需要 Access Token
- **权限**: admin, project_manager, engineer
- **PRD 引用**: F8-001

### 3.2 请求规范

**请求体：**
```json
{
  "report_name": "上海松江PCB工厂冷量计算报告",
  "include_sections": [
    "project_overview",
    "load_calculation",
    "load_composition",
    "reference_standards"
  ],
  "building_ids": [1, 2, 3],
  "options": {
    "include_detail_tables": true,
    "include_charts": true,
    "language": "zh"
  }
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 | 校验规则 |
|------|------|------|------|----------|
| report_name | string | 否 | 报告名称 | 最大长度 200 |
| include_sections | array | 否 | 包含章节 | 默认全部 |
| building_ids | array | 否 | 建筑 ID 列表 | 为空则包含所有 |
| options | object | 否 | 导出选项 | - |

**可选章节：**

| 章节代码 | 说明 |
|----------|------|
| project_overview | 项目概述 |
| load_calculation | 冷负荷计算 |
| load_composition | 冷量构成分析 |
| reference_standards | 引用标准清单 |
| coefficient_sources | 系数依据来源 |

### 3.3 响应规范

**成功响应（202 Accepted）：**
```json
{
  "code": 202,
  "message": "导出任务已提交",
  "data": {
    "task_id": "EXPORT-2026-001",
    "export_type": "static_report",
    "status": "pending",
    "estimated_time": 30,
    "created_at": "2026-07-10T10:00:00Z"
  }
}
```

**错误响应（400 Bad Request）：**
```json
{
  "code": 400,
  "message": "缺少计算结果",
  "errors": {
    "detail": "请先进行静态冷量计算"
  }
}
```

### 3.4 错误码定义

| 错误码 | HTTP 状态码 | 说明 | 处理建议 |
|--------|-------------|------|----------|
| EXPORT_001 | 400 | 缺少计算结果 | 先执行静态计算 |
| EXPORT_002 | 400 | 报告章节无效 | 检查章节代码 |
| EXPORT_003 | 409 | 已有运行中的导出任务 | 等待现有任务完成 |
| EXPORT_004 | 500 | 报告生成失败 | 稍后重试 |

### 3.5 curl 示例

```bash
# 导出静态计算报告
curl -X POST http://localhost:8000/api/v1/projects/1/exports/static-report/ \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -d '{
    "report_name": "上海松江PCB工厂冷量计算报告",
    "include_sections": [
      "project_overview",
      "load_calculation",
      "load_composition",
      "reference_standards"
    ],
    "options": {
      "include_detail_tables": true,
      "include_charts": true
    }
  }'

# 预期响应
{
  "code": 202,
  "message": "导出任务已提交",
  "data": {
    "task_id": "EXPORT-2026-001",
    "export_type": "static_report",
    "status": "pending"
  }
}
```

## 13. 性能优化

### 13.1 PDF 生成优化

**目标：** PDF 生成 < 30 秒

**优化方案：**
- 使用 WeasyPrint 或 ReportLab 生成 PDF
- 预加载模板和静态资源
- 使用缓存存储常用数据
- 异步生成（Celery）

### 13.2 Excel 生成优化

**目标：** Excel 生成 < 60 秒

**优化方案：**
- 使用 openpyxl 的 write_only 模式
- 批量写入数据
- 避免逐行写入
- 异步生成（Celery）

### 13.3 CSV 生成优化

**目标：** CSV 生成 < 60 秒

**优化方案：**
- 使用流式写入
- 批量查询数据库
- 避免一次性加载所有数据到内存
- 异步生成（Celery）
