## 1. 接口概述

### 1.1 认证机制

本系统采用 JWT（JSON Web Token）认证机制，包含两个 Token：

- **Access Token**：短期令牌（有效期 30 分钟），用于 API 访问认证
- **Refresh Token**：长期令牌（有效期 7 天），用于刷新 Access Token

### 1.2 认证流程

```
用户登录
  ├── 成功 → 返回 Access Token + Refresh Token
  └── 失败 → 返回 401 错误

API 请求
  ├── 携带有效 Access Token → 正常响应
  ├── Access Token 过期 + Refresh Token 有效 → 自动刷新
  └── 两个 Token 都失效 → 返回 401，跳转登录页

用户登出
  └── 清除 Refresh Token（加入黑名单）
```

### 1.3 Token 存储

- **前端**：Access Token 存储在内存（React Context），Refresh Token 存储在 HttpOnly Cookie
- **后端**：Refresh Token 存储在 Redis 黑名单（登出时）

## 3. 登录接口

### 3.1 接口定义

- **路径**: `POST /api/v1/auth/login/`
- **功能**: 用户通过账号密码登录，返回 JWT 双 Token
- **认证**: 不需要（公开接口）
- **限流**: 5 次/分钟（防暴力破解）

### 3.2 请求规范

**请求头：**
```http
Content-Type: application/json
```

**请求体：**
```json

}
```

| password | string | 是 | 密码 | 最小长度 8，最大长度 128 |

### 3.6 业务逻辑

```python
# 登录处理流程
def login(username, password):
    """
    PRD 引用：F1-001
    Spec 引用：认证接口 Section 3.6
    """
    # 1. 参数校验
    validate_login_params(username, password)

    # 2. 查找用户
    user = User.objects.filter(username=username).first()
    if not user:
        raise AuthenticationError("账号或密码错误")

    # 3. 验证密码
    if not user.check_password(password):
        raise AuthenticationError("账号或密码错误")

    # 4. 检查账号状态
    if not user.is_active:
        raise PermissionError("账号已被禁用")

    # 5. 生成 Token
    access_token = generate_access_token(user)
    refresh_token = generate_refresh_token(user)

    # 6. 更新最后登录时间
    user.last_login = timezone.now()
    user.save()

    # 7. 返回响应
    return {
        "access_token": access_token,
        "refresh_token": refresh_token,
        "token_type": "Bearer",
        "expires_in": 1800,
        "user": serialize_user(user)
    }
```

### 4.6 业务逻辑

```python
# Token 刷新流程
def refresh_token(refresh_token):
    """
    PRD 引用：F1-004, F1-025
    Spec 引用：认证接口 Section 4.6
    """
    # 1. 验证 Refresh Token 格式
    if not is_valid_jwt(refresh_token):
        raise TokenError("Refresh Token 格式错误")

    # 2. 解码 Refresh Token
    try:
        payload = decode_jwt(refresh_token)
    except JWTError:
        raise TokenError("Refresh Token 无效或已过期")

    # 3. 检查 Token 类型
    if payload.get('token_type') != 'refresh':
        raise TokenError("Token 类型错误")

    # 4. 检查 Token 是否在黑名单
    if is_token_blacklisted(refresh_token):
        raise TokenError("Refresh Token 已被撤销")

    # 5. 获取用户
    user = User.objects.get(id=payload['user_id'])
    if not user.is_active:
        raise PermissionError("用户已被禁用")

    # 6. 生成新的 Access Token
    access_token = generate_access_token(user)

    # 7. 返回响应
    return {
        "access_token": access_token,
        "token_type": "Bearer",
        "expires_in": 1800
    }
```

### 4.7 前端自动刷新实现

```typescript
// 前端 Token 自动刷新逻辑
// PRD 引用：F1-004
// Spec 引用：认证接口 Section 4.7

// API 请求拦截器
api.interceptors.response.use(
  (response) => response,
  async (error) => {
    const originalRequest = error.config;

    // 如果是 401 错误且不是刷新请求
    if (error.response?.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;

      try {
        // 尝试刷新 Token
        const refreshToken = getRefreshToken();
        const response = await authApi.refreshToken(refreshToken);
        const { access_token } = response.data.data;

        // 更新 Access Token
        setAccessToken(access_token);

        // 重试原请求
        originalRequest.headers.Authorization = `Bearer ${access_token}`;
        return api(originalRequest);
      } catch (refreshError) {
        // 刷新失败，跳转登录页
        clearTokens();
        window.location.href = '/login';
        return Promise.reject(refreshError);
      }
    }

    return Promise.reject(error);
  }
);
```

### 5.6 业务逻辑

```python
# 登出处理流程
def logout(access_token, refresh_token=None):
    """
    PRD 引用：F1-005
    Spec 引用：认证接口 Section 5.6
    """
    # 1. 验证 Access Token
    if not is_valid_jwt(access_token):
        raise TokenError("Access Token 无效")

    # 2. 解码 Access Token 获取用户信息
    try:
        payload = decode_jwt(access_token)
        user_id = payload['user_id']
    except JWTError:
        raise TokenError("Access Token 无效")

    # 3. 将 Refresh Token 加入黑名单（如果提供）
    if refresh_token:
        add_token_to_blacklist(refresh_token)

    # 4. 清除 Redis 中的用户会话（可选）
    clear_user_session(user_id)

    # 5. 返回成功响应
    return {"message": "登出成功"}
```

```python
# 权限校验装饰器
from functools import wraps
from rest_framework.response import Response
from rest_framework import status

def require_role(allowed_roles):
    """
    角色权限校验装饰器

    PRD 引用：F1-024
    Spec 引用：认证接口 Section 7.2
    """
    def decorator(view_func):
        @wraps(view_func)
        def wrapper(request, *args, **kwargs):
            # 1. 获取当前用户
            user = request.user

            # 2. 检查用户角色
            if user.role not in allowed_roles:
                return Response(
                    {
                        "code": 403,
                        "message": "权限不足",
                        "errors": {
                            "detail": f"需要角色：{', '.join(allowed_roles)}"
                        }
                    },
                    status=status.HTTP_403_FORBIDDEN
                )

            # 3. 执行视图函数
            return view_func(request, *args, **kwargs)

        return wrapper
    return decorator
```

### 7.3 项目级数据隔离

```python
# 项目级数据隔离
class ProjectPermission(BasePermission):
    """
    项目级数据隔离权限

    PRD 引用：F1-026
    Spec 引用：认证接口 Section 7.3
    """

    def has_permission(self, request, view):
        # 1. 获取项目 ID
        project_id = view.kwargs.get('project_id')
        if not project_id:
            return True  # 不涉及项目级操作

        # 2. 检查用户是否有该项目的访问权限
        try:
            project = Project.objects.get(id=project_id)
            return project.members.filter(user=request.user).exists()
        except Project.DoesNotExist:
            return False

    def has_object_permission(self, request, view, obj):
        # 3. 检查对象所属项目
        if hasattr(obj, 'project'):
            return obj.project.members.filter(user=request.user).exists()
        return True
```

## 8. 安全建议

### 8.1 密码安全

- **加密算法**：bcrypt（PRD: F1-006）
- **密码策略**：
  - 最小长度：8 位
  - 必须包含：大写字母、小写字母、数字、特殊字符中的至少 3 种
  - 不能与用户名相同
  - 不能使用常见弱密码（如 12345678、password）

### 8.2 Token 安全

- **Access Token 有效期**：30 分钟
- **Refresh Token 有效期**：7 天
- **Token 存储**：
  - 前端：Access Token 在内存（React Context），Refresh Token 在 HttpOnly Cookie
  - 后端：Refresh Token 在 Redis 黑名单（登出时）
- **Token 传输**：HTTPS 强制

### 8.3 防暴力破解

- **登录限流**：5 次/分钟/IP
- **账号锁定**：连续 5 次失败后锁定 15 分钟
- **验证码**：连续 3 次失败后要求验证码（v0.6 实现）
