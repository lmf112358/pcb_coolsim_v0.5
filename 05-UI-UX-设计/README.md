## 文档职责

### 设计系统

- **职责**：定义设计规范、组件库、主题系统
- **PRD 引用**：F3-001, F7-001
- **核心内容**：
  - 颜色系统（主色、辅助色、中性色、语义色）
  - 字体系统（字体族、字号、行高、字重）
  - 间距系统（基础单位、常用间距）
  - 组件库（导航、表格、表单、图表、热力图、模态框、Toast）
  - 主题系统（亮色主题、暗色主题）
  - 响应式设计

### 页面设计总览

- **职责**：定义 5 个页面的详细布局、交互、组件
- **PRD 引用**：F1-001, F2-001, F3-001, F4-001, F5-001, F6-001, F7-001, F8-001, F9-001
- **核心内容**：
  - 登录页（登录表单、记住密码、忘记密码）
  - 地图主页（项目列表、地图展示、搜索筛选）
  - 项目工作台（5 个 Tab：基础配置、静态计算、动态仿真、2D 展示、负荷预测）
  - 2D 编辑器（工具栏、画布、属性面板、图层管理）
  - 系统设置（用户管理、系统配置、数据管理）
