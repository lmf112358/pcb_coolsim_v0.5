## 1. 页面总览

### 1.1 页面地图

```
Login Page
    ↓ (success)
Map Home Page ←──────────────────────────────────┐
    ↓ (click project)                             │
Project Workbench                                 │
    ├── Tab 1: Basic Configuration                │
    ├── Tab 2: Static Calculation                 │
    ├── Tab 3: Dynamic Simulation                 │
    ├── Tab 4: 2D Visualization                   │
    └── Tab 5: Load Forecast                      │
    ↓ (click edit 2D)                             │
2D Editor Page ──(save/back)─────────────────────┘
    ↓ (click settings)
Settings Page
```

### 1.2 导航流程

| 来源 | 目标 | 动作 | 传递数据 |
|------|-----|--------|-------------|
| 登录 | 地图主页 | 登录成功 | JWT tokens |
| 地图主页 | 工作台 | 点击项目标记 | 项目 ID |
| 工作台 | 2D 编辑器 | 点击"编辑 2D"按钮 | 楼层 ID |
| 2D 编辑器 | 工作台 | 点击"保存"或"返回" | 画布数据 |
| 任意页面 | 设置 | 点击设置图标 | - |
| 任意页面 | 登录 | 令牌过期 | - |

### 3.2 规格说明

**地图区域：**
- 地图库：Leaflet 1.9.x
- 瓦片服务：高德地图（中文）/ OpenStreetMap（英文）
- 默认视图：以中国为中心
- 缩放范围：4-18
- 标记：按项目状态使用自定义 SVG 标记

**项目标记：**
| 状态 | 颜色 | 图标 |
|--------|-------|------|
| 启用 | 绿色 | 工厂图标 |
| 设计中 | 蓝色 | 草稿图标 |

- 宽度：320px
- 位置：右侧，点击标记时滑入

- 防抖：300ms
- 结果：搜索框下方的下拉列表
- 高亮：结果中的匹配文本
- 动作：点击结果平移/缩放地图至项目

- **双击标记：** 进入项目工作台
- **滚动：** 放大/缩小
- **拖拽：** 平移地图

### 5.2 表单规格

**字段分组:**

1. **基础信息**
   - 房间名称（必填）
   - 房间编码（可选）
   - 面积（必填，m²）
   - 高度（必填，m）
   - 体积（自动计算，只读）

2. **热工要求**
   - 设计温度要求（仅显示）
   - 设计湿度要求（仅显示）
   - 室内计算温度（可编辑，默认 26°C）
   - 室内计算湿度（可编辑，默认 55%）
   - 洁净度等级（下拉）

3. **负荷参数**
   - 民用负荷指标（W/m²）
   - 照明负荷指标（W/m²）
   - 人员负荷（W/人）
   - 人员数量
   - 用电设备功率（kW）+ 系数（0-1）
   - 排风热设备功率（kW）+ 系数
   - 非排风热设备功率（kW）+ 系数

4. **风量参数**
   - 热排风量（m³/h）
   - 酸排风量（m³/h）
   - 碱排风量（m³/h）
   - 有机排风量（m³/h）
   - 除尘排风量（m³/h）
   - 总排风量（自动计算，只读）
   - 压差（Pa）
   - 设计换气次数（可选，用于 v0.6）
   - 送风温差（可选，用于 v0.6）

5. **水温配置**
   - 水温层级（下拉：低温 / 中温 / 自定义）

### 5.3 计算预览面板

**位置：** 内容区底部，吸底固定
**高度：** 120px
**更新：** 实时（参数变更后防抖 500ms）

## 12. 页面 6：对话式采集

> Reference: 模块-02 数据采集 §3 对话式采集；PRD v0.5.1 §3.6 / SOP 六阶段

### 12.1 概述

对话式采集是项目工作台的新增采集入口（v0.5.1 起取代原配置型 标签），通过向导式对话补全数据采集所需的工艺 / 负荷信息。用户在地图页创建项目时已录入项目名称、地理位置并关联气象，进入工作台后由对话 SOP 逐步推进采集。

**入口：** 工作台顶部"对话采集"按钮 -> 打开对话面板（右抽屉 / 模态），按 SOP 六阶段顺序推进。

### 12.2 布局

- 左：阶段进度指示器（SOP 六阶段）
  - ① 项目信息确认 -> ② 工艺与设备 -> ③ 负荷特征 -> ④ 运行策略 -> ⑤ 约束条件 -> ⑥ 汇总确认
- 右：对话区（消息流 + 输入区）
- ① 阶段为**展示确认**：直接展示地图页已关联的项目名称 / 地理位置 / 气象，用户确认或修正，不重复录入
- ⑥ 阶段为**汇总确认**：展示结构化 JSON 草稿，用户确认后落库

### 12.3 写入语义

- 逐区域提交 / 保存即落库（与 标签1 基础配置一致）：每个阶段完成后 `Save 草稿` 写入 `conversation_session.draft_payload`
- `conversation_session.current_stage` 记录当前阶段；`stage_status` 以 JSON 记录各阶段完成态
- 刷新 / 重开可 `Resume`：从 `current_stage` 恢复，已填字段回显
- room 草稿态 `status = draft`，正式提交后转 `active`

### 12.4 与其他渠道的关系

- 与 标签1 基础配置：共享同一份结构化数据，对话采集结果写入相同字段（字段定义见数据采集模块）
- 与 Excel 导入：对话采集落库结构与 Excel 模板列一一对应，可互为导入 / 导出
