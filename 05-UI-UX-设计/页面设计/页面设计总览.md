## 1. Page Overview

### 1.1 Page Map

```
Login Page
    ↓ (success)
Map Home Page ←──────────────────────────────────┐
    ↓ (click project)                             │
Project Workbench                                 │
    ├── Tab 1: Basic Configuration                │
    ├── Tab 2: Static Calculation                 │
    ├── Tab 3: Dynamic Simulation                 │
    ├── Tab 4: 2D Visualization                   │
    └── Tab 5: Load Forecast                      │
    ↓ (click edit 2D)                             │
2D Editor Page ──(save/back)─────────────────────┘
    ↓ (click settings)
Settings Page
```

### 1.2 Navigation Flow

| From | To | Action | Data Passed |
|------|-----|--------|-------------|
| Login | Map Home | Login success | JWT tokens |
| Map Home | Workbench | Click project marker | Project ID |
| Workbench | 2D Editor | Click "Edit 2D" button | Floor ID |
| 2D Editor | Workbench | Click "Save" or "Back" | Canvas data |
| Any Page | Settings | Click settings icon | - |
| Any Page | Login | Token expired | - |

### 5.2 Form Specifications

**Field Groups:**

1. **Basic Information**
   - Room Name (required)
   - Room Code (optional)
   - Area (required, m²)
   - Height (required, m)
   - Volume (auto-calculated, readonly)

2. **Thermal Requirements**
   - Design Temp Requirement (display only)
   - Design Humidity Requirement (display only)
   - Indoor Calc Temp (editable, default 26°C)
   - Indoor Calc Humidity (editable, default 55%)
   - Cleanliness Level (dropdown)

3. **Load Parameters**
   - Civil Load Index (W/m²)
   - Lighting Load Index (W/m²)
   - Personnel Load (W/person)
   - Personnel Count
   - Electric Equipment Power (kW) + Factor (0-1)
   - Exhaust Heated Equipment Power (kW) + Factor
   - No-Exhaust Heated Equipment Power (kW) + Factor

4. **Air Volume Parameters**
   - Heat Exhaust Volume (m³/h)
   - Acid Exhaust Volume (m³/h)
   - Alkaline Exhaust Volume (m³/h)
   - Organic Exhaust Volume (m³/h)
   - Dust Exhaust Volume (m³/h)
   - Total Exhaust Volume (auto-calculated, readonly)
   - Pressure Diff (Pa)
   - Design ACH (optional, for v0.6)
   - Supply Temp Diff (optional, for v0.6)

5. **Water Temperature Configuration**
   - Water Tier (dropdown: Low Temp / Mid Temp / Custom)

### 5.3 Calculation Preview Panel

**Position:** Bottom of content area, sticky
**Height:** 120px
**Update:** Real-time (debounced 500ms after parameter change)

## 12. Page 6: Conversation Acquisition

> Reference: 模块-02 数据采集 §3 对话式采集；PRD v0.5.1 §3.6 / SOP 六阶段

### 12.1 Overview

对话式采集是项目工作台的新增采集入口（v0.5.1 起取代原配置型 Tab），通过向导式对话补全数据采集所需的工艺 / 负荷信息。用户在地图页创建项目时已录入项目名称、地理位置并关联气象，进入工作台后由对话 SOP 逐步推进采集。

**入口：** 工作台顶部"对话采集"按钮 -> 打开对话面板（右抽屉 / 模态），按 SOP 六阶段顺序推进。

### 12.2 Layout

- 左：阶段进度指示器（SOP 六阶段）
  - ① 项目信息确认 -> ② 工艺与设备 -> ③ 负荷特征 -> ④ 运行策略 -> ⑤ 约束条件 -> ⑥ 汇总确认
- 右：对话区（消息流 + 输入区）
- ① 阶段为**展示确认**：直接展示地图页已关联的项目名称 / 地理位置 / 气象，用户确认或修正，不重复录入
- ⑥ 阶段为**汇总确认**：展示结构化 JSON 草稿，用户确认后落库

### 12.3 Write Semantics

- 逐区域提交 / 保存即落库（与 Tab1 基础配置一致）：每个阶段完成后 `Save Draft` 写入 `conversation_session.draft_payload`
- `conversation_session.current_stage` 记录当前阶段；`stage_status` 以 JSON 记录各阶段完成态
- 刷新 / 重开可 `Resume`：从 `current_stage` 恢复，已填字段回显
- room 草稿态 `status = draft`，正式提交后转 `active`

### 12.4 Relation to Other Channels

- 与 Tab1 基础配置：共享同一份结构化数据，对话采集结果写入相同字段（字段定义见数据采集模块）
- 与 Excel 导入：对话采集落库结构与 Excel 模板列一一对应，可互为导入 / 导出
