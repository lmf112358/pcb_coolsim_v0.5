## 1. Design Principles

### 1.1 Core Design Philosophy

| Principle | Description | Application |
|-----------|-------------|-------------|
| **Industrial Aesthetic** | Professional, clean, information-dense | HMI/SCADA-style interface |
| **Data-First** | Prioritize data visibility and accessibility | High information density |
| **Contextual Actions** | Actions available where needed | Inline actions, context menus |
| **Progressive Disclosure** | Show essential info first, details on demand | Collapsible sections, tooltips |
| **Consistent Patterns** | Same patterns for same operations | Uniform component behavior |

### 1.2 Accessibility Standards

- **WCAG 2.1 Level AA** compliance
- **Color Contrast:** Minimum 4.5:1 for normal text, 3:1 for large text
- **Keyboard Navigation:** Full keyboard accessibility
- **Screen Readers:** ARIA labels and semantic HTML
- **Focus States:** Clear, visible focus indicators

## 5. Component Specifications

### 5.1 Navigation Bar

**Structure:**
```
┌─────────────────────────────────────────────────┐
│ [Logo] PCB-CoolSim    [Search]  [Lang] [Theme] [User]│
└─────────────────────────────────────────────────┘
```

**Specifications:**
- Height: 56px
- Background: Surface color
- Shadow: 0 2px 8px rgba(0,0,0,0.15)
- Position: Fixed top
- Z-index: 1000

**Components:**
- Logo: 32px height, left-aligned
- Search: 240px width, centered (when applicable)
- Language Switch: Dropdown with 中文/English
- Theme Switch: Toggle button (sun/moon icon)
- User Menu: Avatar + dropdown

### 5.2 Tree Navigation

**Structure:**
```
┌─────────────────────────┐
│ 🔍 Search...            │
├─────────────────────────┤
│ ▼ 项目名称              │
│   ▼ 1#厂房              │
│     ▼ 1F                │
│       ○ 内层曝光区      │
│       ○ 电镀车间        │
│       ○ 洁净走廊        │
│     ▶ 2F                │
│   ▶ 2#厂房              │
└─────────────────────────┘
```

**Specifications:**
- Width: 280px (resizable, min: 200px, max: 400px)
- Background: Surface color
- Border-right: 1px solid border color
- Node height: 36px
- Indentation: 24px per level
- Icons: Folder (open/closed), Room (default)
- Selected state: Primary color background (10% opacity)
- Hover state: Neutral background

**Interactions:**
- Click: Select node, show details in content panel
- Double-click: Expand/collapse
- Right-click: Context menu (Add, Edit, Delete, Copy)
- Drag: Reorder nodes (same level only)
- Search: Real-time filter with highlight

**Specifications:**
- Row height: 48px (default), 36px (compact)
- Header: Background slightly darker, sticky
- Zebra striping: Optional (10% opacity alternating)

- Filter: Dropdown in header or filter panel
- Pagination: Bottom-right, 20 items per page default

## 8. Interaction Patterns

### 8.1 Loading States

**Skeleton Screens:**
- Show during initial page load
- Match layout structure
- Pulse animation

**Spinners:**
- Show during API calls
- Centered in content area
- With optional message

**Progress Bars:**
- Show for long-running operations (calculations, exports)
- With percentage and status message

### 8.2 Empty States

**Structure:**
```
┌─────────────────────────────────────────┐
│                                          │
│           [Illustration]                 │
│                                          │
│          No data yet                     │
│   Click "Add" to create your first item  │
│                                          │
│            [+ Add Item]                  │
│                                          │
└─────────────────────────────────────────┘
```

### 8.3 Error States

**Form Validation:**
- Inline validation on blur
- Error message below field
- Error border color
- Prevent form submission until valid

**API Errors:**
- Toast notification for transient errors
- Error page for critical errors
- Retry button when applicable

### 8.4 Confirmation Dialogs

**Destructive Actions:**
```
┌─────────────────────────────────────────┐
│ ⚠️ Confirm Deletion              [X]    │
├─────────────────────────────────────────┤
│                                          │
│ Are you sure you want to delete          │
│ "Building 1#厂房"?                       │
│                                          │
│ This will also delete:                   │
│ - 3 floors                               │
│ - 45 rooms                               │
│ - All calculation results                │
│                                          │
├─────────────────────────────────────────┤
│              [Cancel]  [Delete]          │
└─────────────────────────────────────────┘
```

### 8.5 Auto-Save Behavior

- **Trigger:** Every 30 seconds if changes detected
- **Indicator:** Subtle "Saving..." → "Saved" indicator
- **Conflict:** Handle concurrent edits gracefully
- **Recovery:** Restore unsaved changes on page reload
