# 分诊标签

工程技能以五个规范分诊角色表述。本文件将这些角色映射到本仓库实际使用的标签字符串。

| 技能中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需评估该 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，可由 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提及某角色（如「应用 AFK-ready 分诊标签」），使用本表中对应的标签字符串。

如需自定义词表，修改右列即可。
