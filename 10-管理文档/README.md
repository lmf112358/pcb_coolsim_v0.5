## 文档体系概览

本文档索引提供 PCB-CoolSim 项目的完整文档导航，基于 SSD（Software Specification Document）方法论构建。

```
pcb_coolsim_v0.5_fuben/
├── 00-PRD/（L0：需求层）────────────────── PRD 是唯一需求源
├── 01-系统级-Spec/（L1：架构层）─────────── 系统架构、数据库、API
├── 02-模块级-Spec/（L2：模块层）─────────── 10 个模块设计
├── 03-接口级-Spec/（L3：接口层）─────────── API、数据库、前端组件
├── 04-实现级-Spec/（L4：实现层）─────────── 计算逻辑、代码模板
├── 05-UI-UX-设计/（设计层）───────────────── 设计系统、页面设计
├── 06-测试文档/（测试层）─────────────────── 测试策略、测试计划
├── 07-质量保障/（质量层）─────────────────── 质量门禁、追溯性矩阵
├── 08-运维文档/（运维层）─────────────────── 部署、监控、故障排查
├── 09-参考文档/（参考层）─────────────────── 术语表、ADR、用户故事
├── 10-管理文档/（管理层）─────────────────── 项目索引、CLAUDE.md
└── config/（配置层）─────────────────────── harness.json
```
