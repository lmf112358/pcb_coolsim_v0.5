## 🚀 Getting Started (30 minutes)

### Prerequisites
- Python 3.11+
- Node.js 18+
- PostgreSQL 16+
- Redis 7+

### Quick Setup
```bash
# Clone and setup
git clone <repo-url>
cd pcb-coolsim

# Backend
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

# Frontend (new terminal)
cd frontend
npm install
npm run dev

# Redis (new terminal)
redis-server

# Celery (new terminal)
cd backend
celery -A config worker -l info
```

## 🔌 API Quick Reference

### Authentication
```bash
# Login
POST /api/v1/auth/login/
Body: {"username": "user", "password": "pass"}

# Refresh token
POST /api/v1/auth/refresh/
Body: {"refresh": "refresh_token"}
```

### Projects
```bash
# List projects
GET /api/v1/projects/

# Create project
POST /api/v1/projects/
Body: {"name": "Project 1", "city_id": 1, "location": "Shanghai"}

# Get project
GET /api/v1/projects/{project_id}/
```

### Rooms
```bash
# List rooms
GET /api/v1/rooms/?floor_id={floor_id}

# Create room
POST /api/v1/rooms/
Body: {"floor_id": 1, "room_name": "Server Room", "area": 100, "height": 3}

# Calculate static load
POST /api/v1/rooms/{room_id}/calculate-static/
```

### Calculations
```bash
# Real-time preview
POST /api/v1/calculations/preview/
Body: {"room_id": 1, "params": {...}}

# Run batch calculation
POST /api/v1/calculations/batch/
Body: {"project_id": 1, "rooms": [1, 2, 3]}

# Get results
GET /api/v1/calculations/{calculation_id}/results/
```

## 💻 Development Patterns

### Backend (Django)
```python
# Model
class Room(models.Model):
    floor = models.ForeignKey('Floor', on_delete=models.CASCADE)
    room_name = models.CharField(max_length=100)
    area = models.DecimalField(max_digits=10, decimal_places=2)
    height = models.DecimalField(max_digits=5, decimal_places=2)

# Serializer
class RoomSerializer(serializers.ModelSerializer):
    class Meta:
        model = Room
        fields = '__all__'

# View
class RoomViewSet(viewsets.ModelViewSet):
    queryset = Room.objects.all()
    serializer_class = RoomSerializer
```

### Frontend (React)
```typescript
// Component
interface Props {
  roomId: number;
  onCalculate: (id: number) => void;
}

const RoomCard: React.FC<Props> = ({ roomId, onCalculate }) => {
  const { data: room } = useQuery(['room', roomId], () => 
    roomService.getById(roomId)
  );

  return (
    <div>
      <h3>{room?.name}</h3>
      <Button onClick={() => onCalculate(roomId)}>Calculate</Button>
    </div>
  );
};
```

## 🆘 Common Issues

### Database Connection Error
```bash
# Check PostgreSQL
sudo systemctl status postgresql

# Restart
sudo systemctl restart postgresql
```

### Redis Connection Error
```bash
# Check Redis
redis-cli ping

# Restart
redis-server
```

### Port Already in Use
```bash
# Find process
lsof -i :8000

# Kill process
kill -9 <PID>
```
