> 版本：0.5
> 状态：Development
> 日期：2026-07-09

---

##概述

**PCB-CoolSim** is a web-based platform for calculating and simulating cooling loads in PCB (Printed Circuit Board) manufacturing factories. It replaces manual Excel-based calculations with an automated, visual, and collaborative tool.

### Key Features

- **Static Load Calculation:** Design-day cooling load calculation
- **Dynamic Simulation:** 8760-hour annual simulation with weather data
- **2D Visualization:** Heatmap visualization of load distribution
- **Load Forecasting:** 7-day ahead load prediction
- **Report Generation:** PDF, Excel, CSV exports

### Target Users

- HVAC Engineers (暖通工程师)
- Project Managers (项目经理)
- System Administrators (系统管理员)
- Reviewers (查看者)

##快速开始

###前置条件

- Python 3.11+
- Node.js 18+
- PostgreSQL 16+
- Redis 7+
- Docker (optional)

###安装

```bash
# Clone repository
git clone <repository-url>
cd pcb-coolsim

#后端 setup
cd backend
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate  # Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser

#前端 setup
cd ../frontend
npm install

# Start development servers
# Terminal 1: Backend
cd backend && python manage.py runserver

# Terminal 2: Frontend
cd frontend && npm run dev

# Terminal 3: Celery worker
cd backend && celery -A config worker -l info
```

### Using Docker

```bash
docker-compose up -d
```

Access: http://localhost:3000

##API Documentation

See [API Design](design/architecture/api-design.md) for complete API specification.

**Base URL:** `/api/v1`

**Key Endpoints:**
- `POST /auth/login/` - User authentication
- `GET /projects/` - List projects
- `POST /rooms/{id}/calculate-static/` - Calculate static load
- `POST /projects/{id}/simulate/` - Run dynamic simulation
